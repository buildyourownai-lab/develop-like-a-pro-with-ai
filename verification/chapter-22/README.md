# 22장 — 로컬 챗봇 검증

2026-09-14 고정판의 로컬 검증 결과입니다. 대화는 기본 ON이며 CHAT_ENABLED=false일 때만 꺼집니다. Source 제공과 챗봇 공개 운영은 별개입니다.

| 확인 항목 | 결과와 범위 |
|---|---|
| 단위 검사 | 152건 통과 |
| 기본 활성화 계약 | 10건 통과; 설정 미지정은 ON, 명시적 false만 OFF |
| 브라우저 검사 | 대화 켜짐 8건·꺼짐 2건 통과; 실제 기기 검증과 구분 |
| 타입·린트·빌드 | 통과. 이후 주석·문서만 정리한 고정판 |
| 실제 공시 질문 | 메인 대상 없이 본문 질문을 보내 HTTP 200, 종목 찾기→공시 조회, 공시 5건과 DART 링크 반환, 가격 자료 없음 |

실제 API 결과는 두 대표 질문의 해당 실행 시점 관찰입니다. 전체 질문의 정확성이나 DART 원문 화면의 시각 검수를 보증하지 않습니다. 테스트 응답을 사용하는 브라우저 검사를 실제 API 호출로 세지 않습니다.

## 남은 확인

새 범위의 독자 요청문 전체 재현, 물리 모바일 기기·키보드·보조기기, 정식 화면 촬영은 완료하지 않았습니다. 따라서 전체 실습 재현 또는 촬영 완료라고 표시하지 않습니다.

이전 원격 운영 프로젝트의 검사 자료는 역사 기록으로 보존하고 현재 결과에서 제외했습니다.

기본 활성화 판본의 타입·린트·빌드도 통과했습니다. 새 기본 활성화 원고의 전체 독자 재현은 미실시입니다.
