# 1장 검증 --- 영화 흥행 Excel 보고서

> **확인 목록 7/7 · 서로 독립된 빈 폴더에서 3회 실행 · 3회 모두 통과**
> KOBIS 공식통계 20편 대조 일치 · 최종 확인 2026-08-29

## 실제로 만들어봤습니다

책에 인쇄된 요청문만으로 보고서를 완성할 수 있는지 확인했습니다.

- 요청문은 책 1장에 나오는 문장을 **글자까지 그대로** 썼습니다.
- **빈 폴더에서 시작**했습니다. 데이터도 코드도 미리 넣지 않았습니다.
- **책에 없는 추가 지시를 보태지 않았습니다.**
- 서로 **독립된 빈 폴더 3개**에서 각각 새 세션으로 돌렸습니다.

1장의 완료 기준은 책이 「눈으로 확인합니다」라고 적은 **확인 목록 7개**입니다.
**세 실행 모두 7개 전부 통과했습니다.**

| | 확인 항목 | 실행 3회 |
|---:|---|---|
| 1 | movie-report-2024.xlsx 파일이 실제로 생겼다 | 통과 |
| 2 | 파일이 정상적으로 열린다 | 통과 |
| 3 | 영화 TOP 20이 보인다 | 통과 |
| 4 | 관객수와 매출액이 보인다 | 통과 |
| 5 | 핵심 요약이 있다 | 통과 |
| 6 | 실제 데이터를 이용한 차트가 있다 | 통과 |
| 7 | KOBIS 출처와 조회 기준 연도, 다시 찾을 수 있는 정보가 있다 | 통과 |

5번은 요약에 적힌 합계를 **상세 표 20행의 합계와 직접 계산해 비교했습니다.** 칸이
있는지만 본 것이 아닙니다. 6번은 **차트가 실제 셀을 참조하는지** 확인했습니다. 그림처럼
보이기만 해서는 통과하지 않습니다.

검사 코드는 시트 이름도 열 번호도 알지 못하고 내용으로 찾습니다. 그래서 보고서 배치가
실행마다 달라도 같은 기준으로 확인됩니다.
