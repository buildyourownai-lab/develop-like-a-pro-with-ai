# 16장 검증 — 주제 한 줄로 Shorts 한 편을 완성했습니다

> **책에 인쇄된 요청문만으로 1080×1920 세로 Shorts를 완성했습니다**
> 완성 영상 53.081초 · 한국어 목소리·음악·한글 자막 포함 · 자동 검사 15건 전부 통과 ·
> 최종 확인 2026-09-06

## 실제로 만들어봤습니다

빈 폴더에서 시작해 주제 한 줄을 정하고, 책 16장의 요청문만 순서대로 입력해 영상 파일이
만들어지는지 확인했습니다. 영상 편집 프로그램은 사용하지 않았습니다.

- 요청문은 책 16장에 나오는 문장을 그대로 썼습니다.
- 사실 확인과 Storyboard를 먼저 받고, 영상 소재와 음악은 사람이 직접 보고 골랐습니다.
- 완성한 MP4는 처음부터 끝까지 재생해 확인하고, 파일 조건은 자동으로 측정했습니다.

이 장의 완료 기준은 여섯 가지입니다.

| | 확인 항목 | 결과 |
|---:|---|---|
| 1 | 50초대 길이의 영상 파일이 만들어진다 | 통과 -- 53.081초 |
| 2 | 1080×1920 세로 화면이다 | 통과 |
| 3 | 한국어 목소리가 들어 있다 | 통과 |
| 4 | 목소리와 배경음악이 함께 들린다 | 통과 |
| 5 | 한글 자막이 화면 안에 들어온다 | 통과 |
| 6 | 파일이 처음부터 끝까지 오류 없이 재생된다 | 통과 |

## 완성된 결과를 공개합니다

이 장에서 만든 영상은 18장에서 실제 채널에 올렸습니다. 완성본은 여기에서 바로 볼 수
있습니다.

| 무엇 | 어디 |
|---|---|
| 완성한 Shorts | [로마 콘크리트는 왜 2천 년을 버틸까?](https://www.youtube.com/shorts/2HkP_1fahLQ) |
| 16장에서 입력하는 요청문 | [chapters/ch16/prompts.md](../../chapters/ch16/prompts.md) |
| PART 5(16~18장)를 끝낸 완성 프로젝트 | [chapters/ch18/source/ai-shorts-maker/](../../chapters/ch18/source/ai-shorts-maker/) |
| 실제 구현 저장소 | [ai-shorts-maker](https://github.com/buildyourownai-lab/ai-shorts-maker) |

Storyboard는 완성 프로젝트의 prototypes/youtube-shorts/chapter-16/storyboard.json에 있고,
사용한 생성 서비스·공식 주소·권리 확인 규칙은 같은 폴더의 assets-manifest.json에
기록해 두었습니다. 영상 파일과 생성 결과는 용량이 크고 계정별 이용 조건이 달라
저장소에 넣지 않았습니다.

## 자동 검사도 해봤습니다

두 번째 영상부터는 이번과 달라질 점만 말하면 됩니다. 그 요청을 실제 제작 조건으로
옮기는 부분을 검사했습니다.

| 무엇을 확인하는가 | 검사 수 |
|---|---:|
| 아무 조건도 말하지 않으면 이번에 확인한 기본값을 그대로 쓴다 | 1 |
| 길이와 목소리만 바꿔 말하면 나머지는 그대로 둔다 | 1 |
| 음악을 빼달라고 하거나 주제를 바꿔 말하면 그것만 바뀐다 | 1 |
| 이 단계에서 다룰 것이 아닌 조건은 받지 않는다 | 1 |
| 맞춤법·띄어쓰기·누락·용어·숫자·자막 일치·사실·출처를 모두 확인한 현재 대본만 통과시킨다 | 2 |
| 대본을 고치면 이전 승인을 무효로 하고 낡은 음성 Cache를 지운다 | 2 |
| 검수 항목이나 출처가 빠진 기록은 통과시키지 않는다 | 1 |
| PASS 검수 전에는 Secret을 읽거나 TTS를 호출하지 않고, 새 검수 양식은 Cache를 지운다 | 2 |
| 음성 만들기만 요청하면 영상 조립 전 일곱 음성 파일까지만 만든다 | 1 |
| 제작 Skill의 이름·범위·승인 순서와 비용·업로드 중단 조건을 지킨다 | 3 |

검사 15건은 **전부 통과했습니다.** 공개한 16장 Source를 빈 폴더에 그대로 놓고 돌린
결과이고, 검사 파일은
[test_part5_basic_maker.py](../../chapters/ch16/source/ai-shorts-maker/tests/test_part5_basic_maker.py)와
[test_script_review.py](../../chapters/ch16/source/ai-shorts-maker/tests/test_script_review.py),
[test_roman_script_review_gate.py](../../chapters/ch16/source/ai-shorts-maker/tests/test_roman_script_review_gate.py),
[test_youtube_shorts_skill_contract.py](../../chapters/ch16/source/ai-shorts-maker/tests/test_youtube_shorts_skill_contract.py)에
함께 공개했습니다. 그 폴더에서 돌아가는 검사 15건은 모두 이 장에서 새로 생긴 것입니다.
PART 5는 새 프로젝트에서 시작하기 때문입니다.

완성한 영상 파일의 길이·해상도·영상·음성 형식은 검사가 아니라 측정으로 확인했습니다.
저자는 완성 MP4를 처음부터 끝까지 다시 읽어 오류가 없는지도 직접 확인했습니다. 측정값과
확인 조건은 [artifacts/video-measurements.json](artifacts/video-measurements.json)에
있습니다.

## 직접 확인해볼 수 있습니다

책의 16장을 그대로 따라 하시면 됩니다. 요청문은
[chapters/ch16/prompts.md](../../chapters/ch16/prompts.md)에 책에 나오는 순서대로
있습니다.

만든 영상이 제대로 나왔는지는 직접 재생해 보고, 파일 조건은 Claude에게 물어보면 됩니다.

```text
방금 만든 영상의 길이와 화면 크기, 영상·소리 형식을 측정해서 알려줘.
```

## 이런 한계가 있습니다

- **영상의 주제와 장면, 목소리, 음악은 실행마다 달라집니다.** 여러분의 결과가 이 영상과
  같아야 하는 것은 아닙니다. 기준은 60초에 조금 못 미치는 세로 영상 한 편이 끝까지
  재생되는 것입니다.
- **길이는 요청한 값과 몇 초 차이가 날 수 있습니다.** 내레이션을 읽는 속도에 맞춰
  장면 길이가 정해지기 때문입니다.
- **생성 서비스의 무료 Credit과 Watermark, 상업 이용 조건은 바뀔 수 있습니다.** 영상을 공개하기 전에
  지금의 사용 조건을 직접 확인하시기 바랍니다.
