# 21장 — 챗봇 기획과 학습 자료 검증

21장은 챗봇의 기능·사용 흐름·디자인·재사용 방법을 기획하는 장입니다. 완료 산출물은 기획서이며, 이 장에서 챗봇 제품 코드를 추가하지 않습니다.

## 확인한 범위

2026-09-14에 아래 튜터 검사를 실행했습니다. 이 결과는 튜터와 Source 연결기의 동작 확인이며 챗봇 구현·실제 API·독자 재현 성공을 뜻하지 않습니다.

| 검사 | 결과 |
|---|---|
| 튜터 자동 검사 | 93건 통과 |
| 장 계약 검사 | 22개 계약·136개 목표 PASS (공개 관련 목표 2개 삭제 후) |
| START·FINISH 파일 대조 | 기존 제품 파일은 같고 FINISH에 기획서 한 파일만 추가 |

## 21장 기획 재현 확인

Claude CLI에서 책 요청문 7개와 추가 교정 요청 1개를 사용해 기획서를 작성했습니다. 교정 뒤 단계 의존성·조회 경계·항목 수 표현·절 참조의 지적이 해소됐고, 제품 코드·Test·추적 설정 변경 없이 기획서 한 파일만 추가된 상태를 확인했습니다. [실행 조건과 한계](reproduction.md)를 함께 확인합니다.

## 아직 확인하지 않은 범위

추가 교정 없이 책 요청문만으로 처음부터 같은 결과가 나오는 재현과 Claude Desktop에서의 실습은 확인하지 않았습니다. 위 CLI 기록은 챗봇 구현·실제 API·촬영 성공을 뜻하지 않습니다. 22장의 실제 챗봇·모바일·공개 시험 결과도 21장 기획 완료와 구분합니다.

## 역사 자료

이전 원격 운영 프로젝트의 README와 검사 JSON은 보존한 뒤 현재 검증 입구에서 제외했습니다. 과거 AI 회사·Worker의 성공 수치와 실행 결과는 개편한 21장의 근거가 아닙니다.

범위 변경 기록: 위 CLI 재현과 연결된 초기 검사 문서는 공개 운영 범위를 삭제하기 전 판본의 역사 기록입니다. 현재 계약 검사는 위 표처럼 136개 목표로 다시 확인했습니다. 현재 원고는 로컬 실제 검증까지만 다루며, 변경 후 독자 재현은 아직 실시하지 않았습니다.
