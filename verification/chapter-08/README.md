# 8장 검증 --- 내가 만든 아파트 찾기를 인터넷에 공개했습니다

> **7장 도착점에서 시작해 8장 요청문만으로 아파트 찾기 화면과 공개까지 도달**
> 프로젝트 전체 Test 43개 통과(이 장에서 새로 생긴 것 19개) · 공개된 주소에서 검색 확인
> 최종 확인 2026-08-30

## 실제로 만들어봤습니다

책에 인쇄된 요청문만으로 7장의 아파트 찾기에 브라우저 화면을 붙이고 인터넷에 공개할 수
있는지 확인했습니다.

- 요청문은 책 8장에 나오는 문장을 **글자까지 그대로** 썼습니다.
- **7장을 끝낸 상태의 프로젝트**에서 시작했습니다.
- **책에 없는 추가 지시를 보태지 않았습니다.**

8장의 완료 기준은 여섯 가지입니다. **전부 통과했습니다.**

| | 확인 항목 | 결과 |
|---:|---|---|
| 1 | 브라우저 화면에서 조건을 입력해 아파트를 찾는다 | 통과 |
| 2 | 실거래 가격 범위가 현재 매물 가격이 아니라는 것을 화면에서 알 수 있다 | 통과 |
| 3 | 결과 0건과 검색이 끝나지 못한 것을 구분해 알려준다 | 통과 |
| 4 | 국토교통부 데이터 오류와 Kakao 데이터 오류를 서로 구분해 알려준다 | 통과 |
| 5 | 두 개의 키가 브라우저로 전달되지 않는다 | 통과 |
| 6 | 7장까지의 검색 규칙이 그대로 유지되고 기존 Test도 계속 통과한다 | 통과 |

**7장의 검색 규칙은 한 줄도 바꾸지 않았습니다.** 8장에서 더한 것은 그 규칙을 사람이
브라우저에서 사용할 수 있게 하는 화면과, 그 화면을 인터넷에서 실행하는 자리입니다.

## 공식 자료와 비교했습니다

검색에 사용한 가격은 부동산 사이트의 매물 호가가 아니라 **국토교통부에 신고된 실제 매매
거래**입니다.

**국토교통부_아파트 매매 실거래가 자료**
https://www.data.go.kr/data/15126469/openapi.do

공개된 서비스가 사용하는 무료 요금제의 범위도 공식 문서에서 확인했습니다.

**Vercel Hobby plan**
https://vercel.com/docs/plans/hobby

지역 이름은 Kakao Local API의 주소 검색으로 확인한 뒤 실거래가 조회에 필요한 법정동으로
연결했습니다. 그래서 법정동 이름뿐 아니라 평소 쓰는 행정동 이름이나 도로명주소를 입력해도
같은 지역으로 연결됩니다. 하나로 정할 수 없으면 임의로 고르지 않고 후보를 보여줍니다.

## 이런 한계가 있습니다

- **실거래가는 과거에 신고된 거래입니다.** 지금 시장에 나와 있는 매물 가격이나 앞으로의
  가격이 아닙니다. 20억~30억원 실거래가 있다는 것은 그 가격에 살 수 있다는 뜻이 아닙니다.
- **최근 1년 동안 거래가 없었던 아파트는 결과에서 빠집니다.** 그 아파트가 조건에 맞지
  않는다는 뜻이 아니라, 판단할 실제 거래가 없다는 뜻입니다.
- **거리는 좌표 사이의 직선거리입니다.** 실제 걷는 거리나 이동 시간과는 다릅니다.
- **초등학교가 가깝다는 것은 통학구역이나 교육환경을 뜻하지 않습니다.**
- **접속하는 날에 따라 결과가 달라집니다.** 실거래 데이터가 계속 추가되고, 신고된 거래가
  나중에 해제될 수도 있습니다.
- **공개된 주소는 무료 요금제로 운영됩니다.** 같은 시간에 많은 사람이 검색하면 응답이
  느려질 수 있습니다.
