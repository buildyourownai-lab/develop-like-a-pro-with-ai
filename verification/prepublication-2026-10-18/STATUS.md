# 출간 전 최종 검사 진행 기록 (2026-10-18)

사용량 한도로 끊겨도 이어서 할 수 있도록 단계마다 갱신하고 커밋합니다.

## 지시
튜터와 프롬프트를 22개 장 모두에서 시험해 Windows와 Mac에서 문제없이 실행되게 한다. 독자의 OS(Windows/Mac)와 AI(Claude/Codex)는 자동으로 감지한다.
1. 독자에게 필요 없는 응답(환경 입력 요구, 불필요한 경고, "잘 모르겠다")이 나오지 않는지 검증
2. 인코딩 문제를 Windows·Mac에서 근본적으로 조치
3. 줄바꿈 문제를 Windows·Mac에서 근본적으로 조치
4. 튜터와 프롬프트를 모든 장에서 시험
5. 구매자가 따라 해도 문제없도록 모든 문제를 수정
6. 본문·웹·프롬프트·튜터 중 문제가 발견된 곳을 고친다

## 범위 규칙
- 본문과 웹은 문제가 발견된 곳만 최소로 고친다. 문제없는 부분은 읽기만 한다.
- 고친 문장에는 윤문을 적용한다 (한 단계에 행동 하나, 짧은 문장, 쉬운 말, 같은 대상은 같은 이름, 새 사실 금지).
- 튜터 런타임의 진도·완료 계약은 바꾸지 않는다.
- 확인하지 못한 것은 "미관찰/미확인"으로 적는다. Claude Desktop 승인 창은 관찰할 수 없다.

## 순서와 감독관
A 수정(튜터·설치기·스크립트) → B 동결 후 manifest 1회 → C 검증 1회 → D 감독관 S1 초보자 / S2 기술·튜터 / S3 일치 점검 병렬 1회 → E 확인된 오류만 수정+윤문 → S4 윤문 전후 대조 → 영향 시험만 재실행 → push → 운영 재확인 → 보고

## 알림
- C: 드라이브 여유 217MB (95G 중 94G 사용). 큰 빌드·클론이 실패할 수 있다. 사용자 파일은 삭제하지 않는다.
- 책 저장소는 push 전 점검이 영문 ASCII 메시지와 Co-Authored-By 금지를 요구한다.
- 수정 허용 범위: 검증에서 나온 초보자 막힘, 기술 문제, 저장소 간 불일치. 고친 문장은 윤문한다.
