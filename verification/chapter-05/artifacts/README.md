# 5장 검증에 사용한 파일

저자가 5장을 확인할 때 실제로 돌린 결과입니다. 실습에 필요한 파일은 아니고, 저자가
어떻게 확인했는지 그대로 보여주기 위한 자료입니다.

| 파일 | 무엇인가 |
|---|---|
| [check-result.json](check-result.json) | 2회 실행의 단계별 결과와 측정 조건 |

5장이 사용하는 검사와 코드, 그리고 이 장에서 남긴 메모는 장별 Source에 있습니다.

[chapters/ch05/source/movie-report/](../../../chapters/ch05/source/movie-report/)

## 두 실행이 같았던 것

| 단계 | 두 실행에서 확인한 것 |
|---|---|
| 기록 전 | 검사 8개를 먼저 실행해 전부 통과를 확인했다 |
| 기록 | 임시 파일을 빼고 무엇을 넣고 무엇을 뺐는지 설명했다 |
| 변경 만들기 | 보고서의 행 높이를 바꾸고 새 메모를 만들었다 |
| 비교 | 바뀐 기존 파일과 새로 생긴 파일을 구분해 설명하고 아무것도 되돌리지 않았다 |
| 되돌리기 | 실행 전에 무엇이 사라지고 무엇이 남는지 먼저 알려준 뒤 보고서만 되돌렸다 |
| 복구 뒤 | 검사 8개가 다시 전부 통과했고 새 메모는 그대로 있었다 |
| 공통 원칙 | 새 원칙 두 개가 기존 원칙을 지우거나 중복하지 않고 더해졌다 |

## Plan mode는 계획만 보여줍니다

큰 변경을 Plan mode에서 요청하면 영향받는 파일과 작업 순서, 확인할 Test, 위험 요소가
담긴 계획이 먼저 나옵니다. 두 실행 모두 계획을 받기 전과 후의 프로젝트 파일 전체를
대조해 **한 파일도 바뀌지 않은 것**을 확인했습니다.

## 완성된 프로젝트 저장소

5장을 끝낸 상태는 [movie-report](https://github.com/buildyourownai-lab/movie-report)
저장소에도 올라가 있습니다. 저장소는 비공개이고, 5장에서 만든 정상 기록이 실제로
올라갔는지까지 확인했습니다.
