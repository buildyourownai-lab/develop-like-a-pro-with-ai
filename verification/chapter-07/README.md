# 7장 검증 — 내가 정한 조건으로 실제 아파트를 찾아냅니다

> **6장 도착점에서 시작해 7장 요청문만으로 아파트 찾기와 Test까지 도달**
> 프로젝트 전체 Test 24개 통과(이 장에서 새로 생긴 것 13개) · 실제 데이터로 검색 확인
> 최종 확인 2026-08-30

## 실제로 만들어봤습니다

책에 인쇄된 요청문만으로 조건에 맞는 아파트를 찾는 기능을 만들 수 있는지 확인했습니다.

- 요청문은 책 7장에 나오는 문장을 **글자까지 그대로** 썼습니다.
- **6장을 끝낸 상태의 프로젝트**에서 시작했습니다.
- **책에 없는 추가 지시를 보태지 않았습니다.**

7장의 완료 기준은 여섯 가지입니다. **전부 통과했습니다.**

| | 확인 항목 | 결과 |
|---:|---|---|
| 1 | 검색 결과의 단위가 아파트 단지다 | 통과 |
| 2 | 최근 1년의 정상 거래만 사용하고 거래 해제 건을 제외한다 | 통과 |
| 3 | 면적과 실거래 가격의 최소값·최대값을 모두 포함한다 | 통과 |
| 4 | 법정동과 행정동 이름을 조회 지역으로 연결한다 | 통과 |
| 5 | 지역을 하나로 정할 수 없으면 임의로 고르지 않고 알려준다 | 통과 |
| 6 | 결과 0건과 지역 입력 오류, 입력 범위 오류를 서로 구분한다 | 통과 |

**가격을 하나로 단정하지 않습니다.** 단지마다 최근 1년 정상 거래 건수와 가격 범위, 가장
최근 거래, 지정한 가격 범위 안의 거래 건수를 함께 보여줍니다. 순위와 종합점수, 매수 추천,
가격 예측은 만들지 않습니다.

## 공식 자료와 비교했습니다

검색에 사용한 가격은 부동산 사이트의 매물 호가가 아니라 **국토교통부에 신고된 실제 매매
거래**입니다.

**국토교통부_아파트 매매 실거래가 자료**
https://www.data.go.kr/data/15126469/openapi.do

거래 해제 정보도 이 자료가 함께 제공합니다. 1년치 2,918건 중 165건이 해제된 거래로
표시되어, 신고 뒤 취소된 거래를 정상 거래와 구분해 가격 판단에서 제외했습니다.

지역 이름은 Kakao Local API의 주소 검색으로 확인한 뒤 실거래가 조회에 필요한 법정동으로
연결했습니다. 동 이름에서 숫자를 지우거나 비슷한 지역을 추측하지 않습니다. 하나로 정할 수
없으면 검색을 진행하지 않고 더 정확한 주소를 알려달라고 답합니다.

주변 지하철역과 초등학교의 거리도 Kakao Local API의 장소 검색 결과로 계산했습니다.

책의 7장을 그대로 따라 하시면 됩니다. 요청문은

두 개의 키는 각자 발급받아야 합니다. 키 없이 검사만 돌려보고 싶으면 7장 Source를 받아
Claude에게 이렇게 말하면 됩니다.

```text
이 프로젝트에서 실제 API를 호출하지 않는 Test만 실행해줘.
결과와 무엇을 확인하는 Test인지 알려줘.
```

내가 정한 조건이 실제로 어떻게 적용되는지도 직접 확인할 수 있습니다.

```text
아파트 찾기가 최근 1년 정상 거래만 사용하는지,
면적과 가격의 최소값과 최대값을 모두 포함하는지
Test로 확인해서 보여줘.
```

## 이런 한계가 있습니다

- **실거래가는 과거에 신고된 거래입니다.** 지금 시장에 나와 있는 매물 가격이나 앞으로의
  가격이 아닙니다. 20억~30억원 실거래가 있다는 것은 그 가격에 살 수 있다는 뜻이 아닙니다.
- **최근 1년 동안 거래가 없었던 아파트는 결과에서 빠집니다.** 그 아파트가 조건에 맞지
  않는다는 뜻이 아니라, 판단할 실제 거래가 없다는 뜻입니다.
- **거리는 좌표 사이의 직선거리입니다.** 실제 걷는 거리나 이동 시간과는 다릅니다.
- **초등학교가 가깝다는 것은 통학구역이나 교육환경을 뜻하지 않습니다.**
- **실행하는 날에 따라 결과가 달라집니다.** 실거래 데이터가 계속 추가되고, 신고된 거래가
  나중에 해제될 수도 있습니다.
