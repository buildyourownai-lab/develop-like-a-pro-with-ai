실제 YouTube 채널에 올렸습니다. 올리기 전에 무엇이 바뀌는지 Preview로 먼저 확인했습니다.

- 업로드 대상과 제목·설명·공개 범위를 먼저 고정하고 파일 하나로 묶었습니다.

  프로덕션으로 게시하고 소유자 계정으로 다시 승인했습니다.
- Preview를 확인한 뒤 실제로 올렸고, YouTube Studio에서 결과를 확인했습니다.

권한 화면에서 오류가 났을 때는 권한을 넓히기 전에 원인부터 확인합니다.

```text
권한 화면에서 오류가 났어.
어떤 오류인지 그대로 보여주고 원인부터 확인해줘.
권한을 더 넓히거나 다른 설정을 바꾸기 전에 무엇이 잘못됐는지 먼저 찾아줘.
```

## 이런 한계가 있습니다

- **올린 영상은 내 컴퓨터에서 파일을 지워도 사라지지 않습니다.** 채널에서 직접
  내려야 합니다. 그래서 공개 범위의 기본값을 비공개로 두었습니다.
- **Google Cloud와 YouTube Studio 화면의 이름과 위치는 Google이 바꿀 수 있습니다.**
  책의 화면과 조금 다르면 같은 뜻의 항목을 찾으면 됩니다.
- **YouTube Studio에 보이는 길이는 파일에서 측정한 값과 반올림 방식이 다를 수 있습니다.**
  53.081초 영상이 `0:53`으로 보였습니다.
- **채널을 처음 만들면 업로드 한도와 확인 절차가 다를 수 있습니다.** 같은 요청에도 채널
  상태에 따라 안내가 달라질 수 있습니다.
- **OAuth 앱의 프로덕션 상태는 채널이나 영상의 공개 상태가 아닙니다.** 테스트 상태의
  갱신 Token이 약 7일 뒤 만료되는 일을 막기 위한 OAuth 운영 설정입니다.
