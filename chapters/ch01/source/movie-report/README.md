# 1장을 끝낸 상태의 movie-report

## 이 Source는 언제 사용하나요?

1장을 끝내면 프로젝트는 이 상태가 됩니다. 실습이 잘 진행되는 동안 먼저 열어보는
정답지가 아닙니다.

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

앞의 두 방법으로도 해결되지 않았을 때 사용하는 마지막 수단입니다. 이 Source로 다시
시작하면 1장의 남은 실습은 건너뛰고 2장부터 이어가게 됩니다.

## 무엇이 들어 있나요?

| 파일 | 무엇인가 |
|---|---|
| build_movie_report.py | movie-report-2024.xlsx를 만듭니다 |

이 코드에는 KOBIS 공식통계에서 조회한 2024년 TOP 20의 순위, 영화명, 개봉일, 관객수,
매출액이 값으로 적혀 있고, 어느 주소에서 어떤 조건으로 조회했는지도 코드 위쪽에
함께 적혀 있습니다. 그래서 자료를 미리 준비하지 않아도 바로 실행됩니다.

## Claude Code에서 이어서 사용하기

이 폴더를 Claude Code에서 열고 아래 요청문을 붙여넣으면 됩니다. 필요한 환경 확인과
실행은 Claude Code가 맡습니다.

```text
이 폴더는 1장을 끝낸 상태의 Source야.
필요한 환경을 확인하고, 이 상태에서 정상적으로 이어서 작업할 수 있게 준비해줘.
```

보고서가 실제로 만들어지는지 확인하고 싶다면 이어서 요청합니다.

```text
이 Source로 보고서를 한 번 만들어서 정상 동작하는지 확인해줘.
```

## 내 결과와 달라도 괜찮습니다

1장에서 이 코드를 타이핑하지 않습니다. 요청을 적으면 Claude Code가 씁니다. 같은 요청을
받아도 시트 이름, 표가 시작하는 위치, 열 순서 같은 세부는 달라집니다. 자료를 값으로
적어두는지 실행할 때마다 KOBIS에서 받아오는지도 달라집니다. 이 폴더의 코드는 저자가
실제로 한 번 실행해서 나온 결과 중 하나입니다.

기준은 코드 모양이 이 Source와 같은지가 아닙니다. 책 1장의 확인 목록 7개가 보이면
제대로 만들어진 것입니다.

## 검증 결과

이 코드를 빈 폴더에 단독으로 두고 돌려 보고서가 만들어지고 확인 목록 7개를 모두
통과하는 것까지 확인했습니다. 자세한 근거는
[verification/chapter-01/](../../../../verification/chapter-01/)에 있습니다.
