# 6장을 끝낸 상태의 apartment-explorer

## 이 Source는 언제 사용하나요?

6장의 두 API 연결까지 만든 상태입니다. 정답지가 아닙니다.

책을 따라가다 막혔을 때 순서는 이렇습니다.

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

이 Source는 마지막 단계입니다. 앞의 두 방법으로도 이어갈 수 없을 때, 7장부터 계속
진행하기 위해 사용합니다. 이 Source로 시작하면 6장의 남은 실습은 건너뛰게 됩니다.

apartment-explorer는 6장에서 시작하는 새 프로젝트입니다. 5장까지 만든 movie-report와는
다른 폴더입니다.

## 무엇이 들어 있나요?

| 무엇 | 어디 |
|---|---|
| 국토교통부 실거래가 응답을 읽는 기능 | src/lib/molit.ts |
| Kakao 주소와 주변 장소 응답을 읽는 기능 | src/lib/kakao.ts |
| 두 API를 실행하는 자리 | src/app/api/ 아래 두 폴더 |
| 두 응답 처리를 확인하는 Test | src/lib/molit.test.ts, src/lib/kakao.test.ts |
| 응답 예시 | src/lib/__fixtures__/ |

두 개의 키는 들어 있지 않습니다. .env.example을 보고 자기 키를 넣으면 됩니다. 키 없이도
저장해둔 응답 예시로 Test를 실행할 수 있습니다.

아파트를 찾는 기능은 아직 없습니다. 그 기능은 7장에서 만듭니다.

## Claude Code에서 이어서 사용하기

이 폴더를 Claude Code에서 열고 그대로 입력하면 됩니다.

```text
이 폴더는 책 6장을 끝낸 상태의 프로젝트야.
실행에 필요한 환경이 준비되어 있는지 확인하고, 없으면 준비해줘.
내 키를 넣을 자리를 알려주고 Test를 실행해서 결과를 보여줘.
```

## 내 결과와 달라도 괜찮습니다

같은 요청문을 입력해도 파일 이름과 함수 이름, 코드 모양은 달라집니다. 기준은 코드가
같은지가 아니라 6장의 완료 조건을 만족하는지입니다.

- TypeScript를 사용하는 Next.js 프로젝트가 준비되어 있습니다.
- 국토교통부에서 실제 아파트 매매 거래와 거래 해제 정보를 가져올 수 있습니다.
- Kakao에서 주소와 위치, 주변 지하철역과 초등학교를 가져올 수 있습니다.
- 두 개의 키가 프로그램 코드와 Git 기록에 들어가지 않습니다.
- 저장해둔 응답 예시로 실행하는 Test가 통과합니다.
