## P06-02 · 새 프로젝트에서도 앞에서 정한 작업 방식은 이어집니다

~~~prompt
앞으로 새로운 프로젝트 폴더에서 작업을 시작하면
먼저 Git으로 관리되고 있는지와
연결된 GitHub 저장소가 있는지 확인해줘.

새 프로젝트이고 앞으로 계속 작업할 프로젝트라면
별도의 Git 기록을 시작하고
프로젝트 폴더와 같은 이름의 비공개 GitHub 저장소를
준비해서 연결해줘.

프로젝트의 첫 정상 상태가 확인되면
그 기록은 연결한 GitHub 저장소에도 한 번 보내고
실제로 올라갔는지 확인해줘.

그 이후의 모든 Git 기록을
자동으로 GitHub에 보내지는 마.

기존 프로젝트라면 새 저장소를 만들지 말고
기존 Git 기록과 GitHub 저장소를 계속 사용해줘.

새 프로젝트인지 기존 프로젝트인지 확실하지 않으면
임의로 만들지 말고 먼저 나에게 확인해줘.

로그인이나 승인처럼 내가 직접 해야 하는 일이 있으면
그 지점에서 기다리고 무엇을 해야 하는지 안내해줘.

이 원칙도 모든 프로젝트에서 사용할
공통 ~/.claude/CLAUDE.md에 추가해줘.
기존 공통 원칙은 지우거나 중복해서 만들지 마.
~~~

## P06-12 · 이제 실제 데이터를 가져옵니다

~~~prompt
이 프로젝트에서 준비한 국토교통부 서비스키를 사용해서 아파트 매매 실거래가 API가 실제로 동작하는지 확인해줘.
TypeScript와 Next.js로 만든 현재 프로젝트에서 앞으로 다시 사용할 수 있게 연결해줘.
테스트할 수 있는 실제 아파트 매매 데이터를 가져와서 사람이 알아볼 수 있게 몇 건만 보여줘.
거래 해제 여부도 확인할 수 있게 해줘.
서비스키 값은 화면과 오류 메시지에 절대 나오지 않게 해줘.
서비스키에 %가 들어 있으면 그대로 써줘. 프로그램이 한 번 더 바꾸면 인증이 실패해.
지금은 아파트 검색 기능을 만들지 말고 실제 데이터를 가져오는 데 성공했는지만 확인해줘.
~~~

~~~prompt

지금은 최종 아파트 검색 기능을 만들지 말고 위치와 주변 장소 데이터를 가져오는 데 성공했는지만 확인해줘.
~~~
