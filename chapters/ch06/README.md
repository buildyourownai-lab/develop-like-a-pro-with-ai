# 6장. 아파트 실거래가와 위치 정보를 가져옵니다

## 이 장에서 만드는 것

PART 2에서 만들 아파트 찾기 서비스의 재료를 준비합니다. 공식 기관과 지도 서비스가
공개한 실제 데이터를 내 프로젝트로 가져오는 것이 이 장의 도착점입니다.

| 무엇 | 어디에서 |
|---|---|
| 아파트 매매 실거래가와 거래 해제 정보 | 국토교통부 (공공데이터포털) |
| 아파트 주소와 위치, 주변 지하철역·초등학교 | Kakao Local API |

apartment-explorer라는 새 프로젝트를 시작하고, 마지막에 웹서비스로 공개할 것을
생각해 TypeScript와 Next.js를 사용합니다.

끝내면 두 API에서 실제 데이터를 가져올 수 있고, 두 개의 키는 프로그램 코드와 Git
기록에서 분리되어 있습니다. 저장해둔 응답 예시로 데이터를 제대로 읽는지 확인하는
Test도 함께 남습니다.

아직 아파트를 찾는 기능은 만들지 않습니다. 그 기능은 7장에서 만듭니다.

## 프롬프트

[prompts.md](prompts.md)에 6장에서 Claude Code에 입력하는 문장이 책의 순서대로
있습니다.

두 개의 키는 독자가 직접 발급받습니다. 발급 화면에서 무엇을 눌러야 하는지는 책
6장에서 화면과 함께 설명합니다.

## 장별 Source

[source/apartment-explorer/](source/apartment-explorer/)에 6장을 끝낸 상태가 있습니다.
apartment-explorer는 6장에서 시작하는 새 프로젝트이므로, 5장까지 만든 movie-report와는
다른 폴더입니다.

이 폴더를 그대로 받아 자기 컴퓨터에서 돌릴 수 있습니다. 두 개의 키는 들어 있지 않으므로
.env.example을 보고 자기 키를 입력하면 됩니다. 키 없이도 저장해둔 응답 예시로 Test를
실행해볼 수 있습니다.

완성된 아파트 찾기 서비스는 8장에서 완결됩니다.

## 검증 결과

저자는 5장 도착점에서 시작해 6장 요청문만으로 두 API 연결과 Test까지 갔습니다. 저장해둔
응답 예시로 실행하는 Test 11개가 모두 통과했고, 두 API가 실제로 돌려주는 데이터도 실제
키로 확인했습니다. 근거는 [verification/chapter-06/](../../verification/chapter-06/)에
있습니다.

## 막혔을 때

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

Git 명령을 외우거나 직접 입력할 필요는 없습니다. 아래 요청문을 그대로 붙여넣으면
Claude Code가 확인하고 처리합니다.

**1. 디버깅** — 먼저 무엇이 어긋났는지 그대로 말하고 고쳐봅니다. 대부분 여기서
해결됩니다.

```text
지금 작업이 책과 다르게 진행됐어.
현재 상태와 화면에 나온 문제를 확인하고 원인을 찾아서 고쳐줘.
```

이 장에서 특히 자주 막히는 자리는 키가 아직 동작하지 않는 경우입니다. 발급 직후에는
바로 사용할 수 없는 키도 있습니다.

```text
국토교통부 API에서 등록되지 않은 서비스키라는 응답이 왔어.
지금 입력한 키가 이 API에서 사용할 수 있는 상태인지 확인하고
무엇을 더 해야 하는지 알려줘.
```

**2. 내 정상 기록으로 복구** — 해결되지 않으면 실습하면서 내 프로젝트에 남겨둔 정상
기록으로 돌아갑니다. 지금까지 한 작업은 먼저 따로 보존합니다.

```text
현재 작업은 잃지 않도록 먼저 별도로 보존해줘.
이 프로젝트에서 마지막으로 정상 동작했던 상태를 찾아 안전하게 복구해줘.
```

**3. 장별 Source로 재시작** — 그래도 이어갈 수 없을 때 사용합니다. 6장의 남은 실습은
건너뛰게 되므로 마지막 수단입니다.

```text
내 현재 작업을 먼저 안전하게 보존해줘.
아래 6장 완성 Source에서 다시 시작해줘.
https://github.com/buildyourownai-lab/develop-like-a-pro-with-ai/tree/main/chapters/ch06/source/apartment-explorer
내 두 개의 키를 입력할 자리를 알려주고
준비가 끝나면 6장을 마친 상태인지 확인해줘.
```
