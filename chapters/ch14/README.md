# 14장. 만든 서비스를 Android 앱으로 만듭니다

## 이 장에서 만드는 것

13장에서 정한 계획대로 ai-stock-briefing을 Android 앱으로 확장합니다. 주식 데이터와 공시,
AI 브리핑을 새로 만들지 않고 기존 서버를 그대로 씁니다. 앱 파일을 만들었다는 것으로 끝내지
않고, 공식 Android Emulator에 설치해 직접 사용하는 것까지가 이 장의 결과물입니다.

이 장에서 확인하는 것은 여섯 가지입니다.

| 무엇 | 어떻게 확인하나 |
|---|---|
| 공식 Android 환경에서 앱이 실행된다 | Emulator에 설치한 앱의 첫 화면이 실제 서버 자료로 채워지는지 확인합니다 |
| 웹서비스의 흐름이 앱에서도 이어진다 | 시장에서 종목을 찾아 차트와 공시, AI 브리핑까지 내려가는지 확인합니다 |
| 공식 원문으로 내려가는 길이 남아 있다 | 공시 한 건에서 dart.fss.or.kr 원문이 열리는지 확인합니다 |
| AI 품질 기준이 앱에서도 유지된다 | 브리핑의 근거와 출처, 알 수 없는 것이 웹과 같은 항목으로 나오는지 확인합니다 |
| 연습용 연결과 실제 서비스 연결이 나뉘어 있다 | Release 앱이 Production HTTPS 주소에서 실제 자료를 받는지 확인합니다 |
| 앱에 Secret과 불필요한 권한이 없다 | 완성된 앱에서 외부 서비스 Secret이 발견되지 않고 인터넷 외의 권한을 요청하지 않는지 확인합니다 |

앱의 화면 배치와 내부 구조는 매번 달라집니다. 완료 기준은 책과 같은 코드가 나오는 것이
아니라 위 여섯 가지를 실제 Emulator에서 확인하는 것입니다.

## 프롬프트

[prompts.md](prompts.md)에 14장에서 Claude Code에 입력하는 문장이 책의 순서대로 있습니다.

## 장별 Source

[source/ai-stock-briefing/](source/ai-stock-briefing/)에 14장을 끝낸 상태가 있습니다.
9장부터 14장까지 만든 파일이 모두 들어 있어 이 폴더만 받아도 자기 컴퓨터에서 돌릴 수
있습니다. 13장 상태와 비교하면 Android 앱 프로젝트와 앱이 읽는 서버 자리가 더해졌습니다.

정상 흐름에서 먼저 열어보는 정답지가 아닙니다. 아래 복구 방법으로도 이어갈 수 없을 때
15장부터 계속 진행하기 위한 마지막 수단입니다.

## 검증 결과

저자는 13장을 끝낸 상태에서 14장 요청문만으로 Android 앱까지 갔습니다. Android 16, API 36
공식 Emulator에 앱을 설치해 시장 화면과 기준일, 상승률 상위·하락률 상위 각 5종목을 확인하고,
SK하이닉스를 검색해 1개월·3개월·1년 차트와 최근 1년 공시를 봤습니다. 공시에서 DART 공식
원문이 열리는 것과 AI 브리핑의 근거·출처·한계가 웹과 같은 항목으로 나오는 것도 확인했습니다.
Release 앱은 Vercel Production HTTPS 주소에서 실제 자료를 받았습니다. Source 안의 Test는
136개이고 이 장에서 새로 생긴 것은 23개입니다. 근거는
[verification/chapter-14/](../../verification/chapter-14/)에 있습니다.

## 막혔을 때

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

Git 명령을 외우거나 직접 입력할 필요는 없습니다. 아래 요청문을 그대로 붙여넣으면
Claude Code가 확인하고 처리합니다.

**1. 디버깅** --- 먼저 무엇이 어긋났는지 그대로 말하고 고쳐봅니다. 대부분 여기서
해결됩니다.

```text
지금 작업이 책과 다르게 진행됐어.
현재 상태와 화면에 나온 문제를 확인하고 원인을 찾아서 고쳐줘.
```

Emulator가 열리지 않거나 앱이 설치되지 않을 때는 환경부터 다시 확인하게 합니다.

```text
공식 Emulator가 실행되지 않아.
현재 컴퓨터에 필요한 Android 도구가 준비됐는지 다시 확인하고,
빠진 것이 있으면 공식 출처와 이유를 알려준 뒤 진행해줘.
```

앱이 열리는데 자료가 비어 있으면 서버 연결을 확인하게 합니다.

```text
앱은 열리는데 시장 자료가 비어 있어.
앱이 어느 주소로 요청하고 있고 그 주소가 지금 응답하는지 확인해서 고쳐줘.
```

앱 화면이 웹과 달라 보이면 무엇이 다른지 대조하게 합니다.

```text
앱 화면이 웹서비스와 다르게 보여.
같은 종목에서 웹과 앱이 보여주는 항목과 숫자를 대조해서
빠지거나 줄여서 표시되는 것이 있으면 고쳐줘.
```

Release 앱이 실제 주소에 연결되지 않으면 배포까지 확인하게 합니다.

```text
Release 앱이 실제 서버에서 자료를 받지 못해.
이번에 앱을 위해 서버에 새로 만든 기능이 배포에 반영됐는지 확인하고
반영되지 않았으면 배포까지 진행해줘.
```

**2. 내 정상 기록으로 복구** --- 해결되지 않으면 실습하면서 내 프로젝트에 남겨둔 정상
기록으로 돌아갑니다. 지금까지 한 작업은 먼저 따로 보존합니다.

```text
현재 작업은 잃지 않도록 먼저 별도로 보존해줘.
이 프로젝트에서 마지막으로 정상 동작했던 상태를 찾아 안전하게 복구해줘.
```

**3. 장별 Source로 재시작** --- 그래도 이어갈 수 없을 때 사용합니다. 14장의 남은 실습은
건너뛰게 되므로 마지막 수단입니다.

```text
내 현재 작업을 먼저 안전하게 보존해줘.
아래 14장 완성 Source에서 다시 시작해줘.
https://github.com/buildyourownai-lab/develop-like-a-pro-with-ai/tree/main/chapters/ch14/source/ai-stock-briefing
내 인증키와 Database, Cache 접속 정보를 입력할 자리를 알려주고
준비가 끝나면 14장을 마친 상태인지 확인해줘.
```
