# 3장을 끝낸 상태의 movie-report

## 이 Source는 언제 사용하나요?

3장은 정상 보고서에 오류 하나를 일부러 넣고 그 원인을 찾아 되돌리는 장입니다. 그래서
3장을 끝낸 상태는 3장을 시작하기 전 상태와 같습니다. 실습이 잘 진행되는 동안 먼저
열어보는 정답지가 아닙니다.

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

앞의 두 방법으로도 해결되지 않았을 때 사용하는 마지막 수단입니다. 이 Source로 다시
시작하면 3장의 남은 실습은 건너뛰고 4장부터 이어가게 됩니다.

연습용 오류가 의도한 자리보다 넓게 들어가 되돌리기 어려워졌을 때가 이 폴더를 쓰는
자리입니다.

## 무엇이 들어 있나요?

3장까지 만든 것이 모두 들어 있습니다. 이 폴더 하나만 받아서 바로 실행할 수 있습니다.

| 파일 | 무엇인가 |
|---|---|
| build_movie_report.py | movie-report-2024.xlsx를 만듭니다 |
| source/kobis-2024-source.xlsx | 보고서를 만들 때 사용한 KOBIS 데이터를 작업 당시 상태로 남긴 기준 자료입니다 |
| tests/conftest.py | 보고서와 기준 자료를 열어주는 준비 코드입니다 |
| tests/test_movie_report.py | 완료 조건 일곱 가지를 확인하는 자동 검사 8개입니다 |

## 실행하기

```text
python3 build_movie_report.py
python3 -m pytest tests/ -v
```

첫 줄이 보고서를 만들고, 둘째 줄이 그 보고서를 검사합니다. 검사 8개가 모두 통과하면
3장의 도착점에 와 있는 것입니다.

## Claude Code에서 이어서 사용하기

이 폴더를 여러분의 movie-report 폴더에 합친 뒤 Claude Code에서 아래 요청문을
붙여넣으면 됩니다.

```text
이 폴더는 3장을 끝낸 상태의 movie-report야.
보고서를 만들고 자동 검사를 실행해서 결과를 알려줘.
하나라도 실패하면 완료했다고 말하지 말아줘.
```

## 내 결과와 달라도 괜찮습니다

**이 검사가 여러분의 보고서에서 그대로 돌아가지 않는 것이 정상입니다.** 검사 코드는
2장에서 여러분이 타이핑한 것이 아니라 조건을 말하면 Claude Code가 쓴 것입니다. 그래서
검사 개수와 이름이 각자 다릅니다.

기준은 코드 모양이 이 Source와 같은지가 아닙니다. 여러분이 정한 완료 조건이 모두 검사에
들어 있고, 실패한 항목이 없으면 제대로 만들어진 것입니다.

## 검증 결과

저자가 2장 도착점에서 시작해 3장 요청문만으로 두 번 돌렸고, 두 번 모두 오류를 찾아
되돌린 뒤 검사 8개가 전부 통과했습니다. 이 폴더를 빈 폴더에 단독으로 놓고 실행해
보고서 생성과 검사 8개 통과까지 확인했습니다. 자세한 근거는
[verification/chapter-03/](../../../../verification/chapter-03/)에 있습니다.
