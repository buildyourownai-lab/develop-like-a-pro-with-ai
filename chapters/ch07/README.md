# 7장. 내 조건에 맞는 아파트를 찾습니다

## 이 장에서 만드는 것

지역과 면적, 실거래 가격 범위, 생활조건을 입력하면 실제 데이터를 확인해 조건에 맞는
아파트 단지를 찾아주는 기능을 만듭니다. 이 책에서는 이 기능을 아파트 찾기라고 부릅니다.

검색 결과 하나는 아파트 단지 하나이고, 단지마다 이런 내용을 확인할 수 있습니다.

| 무엇 | 어떻게 정했나 |
|---|---|
| 최근 1년 정상 거래 건수와 가격 범위 | 실행일 기준 최근 1년, 거래 해제 건은 제외 |
| 지정한 실거래 가격 범위 안의 거래 건수 | 입력한 최소값 이상, 최대값 이하 |
| 가장 가까운 지하철역과 초등학교 거리 | Kakao 좌표로 계산한 직선거리 |

실거래 데이터는 계속 추가되고 변경되므로 실행하는 날에 따라 거래 건수와 결과 아파트가
달라집니다. 완료 기준은 결과가 몇 건인지가 아니라, 우리가 정한 검색 규칙이 실제 데이터에
그대로 적용되는지입니다.

브라우저에서 쓰는 화면은 아직 만들지 않습니다. 그 화면은 8장에서 붙입니다.

## 프롬프트

[prompts.md](prompts.md)에 7장에서 Claude Code에 입력하는 문장이 책의 순서대로 있습니다.

6장까지 만든 것이 모두 들어 있어 이 폴더만 받아도 자기 컴퓨터에서 돌릴 수 있습니다.

정상 흐름에서 먼저 열어보는 정답지가 아닙니다. 아래 복구 방법으로도 이어갈 수 없을 때
8장부터 계속 진행하기 위한 마지막 수단입니다.

## 검증 결과

저자는 6장 도착점에서 시작해 7장 요청문만으로 아파트 찾기와 Test까지 갔습니다. 이 장에서
새로 생긴 Test 13개를 포함해 프로젝트 전체 Test 24개가 통과했고, 실제 데이터로 서울 강남구
대치동을 검색해 조건에 맞는 아파트 단지를 확인했습니다. 근거는
[verification/chapter-07/](../../verification/chapter-07/)에 있습니다.

## 막혔을 때

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

Git 명령을 외우거나 직접 입력할 필요는 없습니다. 아래 요청문을 그대로 붙여넣으면
Claude Code가 확인하고 처리합니다.

**1. 디버깅** — 먼저 무엇이 어긋났는지 그대로 말하고 고쳐봅니다. 대부분 여기서
해결됩니다.

```text
지금 작업이 책과 다르게 진행됐어.
현재 상태와 화면에 나온 문제를 확인하고 원인을 찾아서 고쳐줘.
```

이 장에서 특히 자주 막히는 자리는 지역을 입력했는데 조회 지역으로 연결되지 않는
경우입니다.

```text
내가 입력한 지역이 실거래가 조회 지역으로 연결되지 않았어.
입력한 주소를 어떻게 해석했는지 단계별로 보여주고
어디에서 확인에 실패했는지 알려줘.
```

**2. 내 정상 기록으로 복구** — 해결되지 않으면 실습하면서 내 프로젝트에 남겨둔 정상
기록으로 돌아갑니다. 지금까지 한 작업은 먼저 따로 보존합니다.

```text
현재 작업은 잃지 않도록 먼저 별도로 보존해줘.
이 프로젝트에서 마지막으로 정상 동작했던 상태를 찾아 안전하게 복구해줘.
```

**3. 장별 Source로 재시작** — 그래도 이어갈 수 없을 때 사용합니다. 7장의 남은 실습은
건너뛰게 되므로 마지막 수단입니다.

```text
내 현재 작업을 먼저 안전하게 보존해줘.
아래 7장 완성 Source에서 다시 시작해줘.
https://github.com/buildyourownai-lab/develop-like-a-pro-with-ai/tree/main/chapters/ch07/source/apartment-explorer
내 두 개의 키를 입력할 자리를 알려주고
준비가 끝나면 7장을 마친 상태인지 확인해줘.
```
