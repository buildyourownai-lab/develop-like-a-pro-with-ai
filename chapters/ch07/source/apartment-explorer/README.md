# 7장을 끝낸 상태의 apartment-explorer

## 이 Source는 언제 사용하나요?

7장의 아파트 찾기까지 만든 상태입니다. 정답지가 아닙니다.

책을 따라가다 막혔을 때 순서는 이렇습니다.

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

이 Source는 마지막 단계입니다. 앞의 두 방법으로도 이어갈 수 없을 때, 8장부터 계속
진행하기 위해 사용합니다. 이 Source로 시작하면 7장의 남은 실습은 건너뛰게 됩니다.

## 무엇이 들어 있나요?

6장에서 만든 두 API 연결이 그대로 있고, 여기에 7장의 아파트 찾기가 더해졌습니다.

| 무엇 | 어디 |
|---|---|
| 조건에 맞는 아파트 단지를 찾는 기능 | src/lib/apartmentSearch.ts |
| 평소 쓰는 주소를 실거래가 조회 지역으로 연결하는 기능 | src/lib/region.ts |
| 아파트 찾기를 실행하는 자리 | src/app/api/apartments/search/route.ts |
| 국토교통부 실거래가 응답을 읽는 기능 | src/lib/molit.ts |
| Kakao 주소와 주변 장소 응답을 읽는 기능 | src/lib/kakao.ts |
| 검색 규칙과 두 응답 처리를 확인하는 Test | src/lib 안의 네 개 test 파일 |
| 응답 예시 | src/lib/__fixtures__/ |

두 개의 키는 들어 있지 않습니다. .env.example을 보고 자기 키를 넣으면 됩니다. 키 없이도
저장해둔 응답 예시로 Test를 실행할 수 있습니다.

브라우저에서 쓰는 화면은 아직 없습니다. 화면은 8장에서 붙입니다.

## Claude Code에서 이어서 사용하기

이 폴더를 Claude Code에서 열고 그대로 입력하면 됩니다.

```text
이 폴더는 책 7장을 끝낸 상태의 프로젝트야.
실행에 필요한 환경이 준비되어 있는지 확인하고, 없으면 준비해줘.
내 키를 넣을 자리를 알려주고 Test를 실행해서 결과를 보여줘.
```

## 내 결과와 달라도 괜찮습니다

같은 요청문을 입력해도 파일 이름과 함수 이름, 코드 모양은 달라집니다. 기준은 코드가
같은지가 아니라 7장의 완료 조건을 만족하는지입니다.

- 지역과 면적, 실거래 가격, 생활조건을 입력해 아파트 단지를 찾습니다.
- 최근 1년의 정상 거래만 사용하고 거래 해제 건은 제외합니다.
- 면적과 실거래 가격은 입력한 최소값과 최대값을 모두 포함합니다.
- 법정동뿐 아니라 행정동 이름을 입력해도 조회 지역으로 연결됩니다.
- 결과가 0건인 것과 지역 입력을 확인할 수 없는 것을 구분해 알려줍니다.
- 검색 규칙을 확인하는 Test가 통과합니다.
