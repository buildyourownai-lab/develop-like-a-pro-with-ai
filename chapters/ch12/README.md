# 12장. 더 빠르고 비용은 적게 드는 서비스로 개선합니다

## 이 장을 시작할 때

[Study AI Lab MCP 연결](https://www.studyailab.com/develop/mcp#connect) 후 개발 AI에게 **“12장 시작해”**라고 요청하세요. 별도 튜터 설치는 필요하지 않습니다. AI가 현재 장·판본·작업 폴더를 확인하고 다음 행동 하나를 안내합니다. 앞 장까지 만든 `ai-stock-briefing`과 그 확인 결과를 이어갑니다. 현재 장의 선행 조건을 대조하고 필요한 기능만 추가합니다.

요청문·힌트 조회는 실행이나 완료 확인과 다릅니다. 실제 작업과 진도는 내 컴퓨터에서 확인하며, 필요한 [로컬 지원 파일](https://www.studyailab.com/develop/mcp#support-files)의 명령 옵션은 AI가 처리합니다. 아래 기존 검증 기록은 새 MCP 경로의 장별 전체 재현 완료를 뜻하지 않습니다.

## 이 장에서 만드는 것

12장에서는 새로운 기능을 만들지 않습니다. 11장까지 만든 ai-stock-briefing이 이미 한 일을
덜 반복하게 바꿉니다. 금융위원회에서 받은 주식 데이터는 Supabase Database에 저장해 다시
사용하고, Gemini가 만든 브리핑은 Upstash Redis에 잠시 저장해 빠르게 다시 사용합니다.

이 장에서 확인하는 것은 여섯 가지입니다.

| 무엇 | 어떻게 확인하나 |
|---|---|
| 저장한 데이터를 다시 사용한다 | 같은 주식 데이터를 다시 요청할 때 금융위원회를 다시 부르지 않는지 확인합니다 |
| 오래된 값은 다시 확인한다 | 유효시간이 지나면 저장된 값을 쓰지 않고 원본에서 다시 가져오는지 확인합니다 |
| 같은 조건이면 AI를 다시 부르지 않는다 | 같은 근거·같은 모델이면 저장된 브리핑을 그대로 돌려주는지 확인합니다 |
| 조건이 바뀌면 새로 만든다 | 근거나 모델, 주요 프롬프트가 바뀌면 이전 결과를 쓰지 않는지 확인합니다 |
| 한도에 도달하면 멈춘다 | 사용량 한도에 도달한 동안 추가 호출이 나가지 않고 버튼이 막히는지 확인합니다 |
| 품질 기준은 그대로다 | 빨라진 뒤에도 11장에서 정한 근거 안의 설명 기준이 유지되는지 확인합니다 |

응답시간은 컴퓨터와 네트워크, 서비스 상태에 따라 달라집니다. 완료 기준은 책과 같은
숫자가 나오는 것이 아니라, 두 번째 요청에서 외부 호출과 AI 생성이 실제로 줄어드는
것입니다.
