## P17-02 · 제작 스킬이 지금 할 일을 하나씩 꺼내게 합니다

입력 대상: **현재 프로젝트의 AI**

~~~prompt
이 작업 프로젝트에 독자용 제작 스킬 book-shorts-build를 새로 만들어줘.
아래 명세만으로 작성하고 다른 사람의 스킬이나 비공개 자료를 찾아 복사하지 마.

지원된다면 그 위치에 SKILL.md와 필요한 공개용 출력 양식을 만들어줘.

다음부터 그 파일을 읽게 하는 직접 요청문을 알려줘. 지원되지 않는 호출 구문을 만들지 마.
다른 스킬이나 전역 설정은 덮어쓰지 마.

없는 정보는 만들어 채우지 않고 필요한 항목을 짧게 묻는다.
현재 프로젝트에서 선택한 소재·대상·샷 카드·수량·모델과 실제 자산표를 우선한다.

실제 결과로 계획이 바뀌면 이유와 영향 항목만 갱신한다.

소작업은 다음 다섯 개로 나눠줘.
1. 대상: 필요한 반복 대상의 종류와 수, 기준 이미지 생성 명령,
   별도 이름과 Character info, 등록 후 실제 참조 선택 절차를 준비한다.
2. 원화: 장면별 번호·저장 이름·실제 참조·구도·각도·광원·색·재질·

3. 수정: 실제 결과에서 관찰한 결함과 아직 추측인 원인을 나누고,
   영향 있는 자산만 수정한다. 좋은 구도·외형·빛은 보존한다.
4. 영상: 실제 원화에 맞춰 시작 프레임, 필요할 때만 끝 프레임,
   카메라 시작/가속/공개/감속/체류와 대상 동작을 구체화한다.
   모델·직접 생성 해상도·출력 비율·길이·개수의 실제 지원을 확인하게 한다.
5. 편집: 실제 내려받은 클립에서 사용할 원본 구간과 순서·속도를 정하고,
   영상 중심 러프컷과 재편집 가능한 프로젝트를 만든다.

공통 판단:
- 생성하려는 문장과 실제 생성한 파일을 구분한다.
- 주요 대상의 불변 특징을 유지하고, 장면마다 새로운 시각적 사건을 준다.
- 같은 원경을 조금 확대하거나 색만 바꾼 반복을 피한다.
- 시대·공간·접촉·가림·크기·재질과 화면의 의미를 함께 살핀다.
- 유사한 원화라도 방향·인물·장치가 다르면 연속 시작/끝 쌍을 강제하지 않는다.
- 가려진 내부나 보이지 않은 부품을 정밀 복원했다고 쓰지 않는다.
- 실제 생성은 내가 Flow에서 한다. AI가 입력·클릭·생성 호출을 대신하지 않는다.
- 로컬 편집은 내가 맡긴 범위에서 수행한다. 도구가 없으면 공식 설치 경로와
  필요한 이유를 먼저 알려주고, 실행하지 않은 편집본을 만들었다고 하지 않는다.

출력 계약:
대화에서는 이번 작업/고려할 점/결과물/다음 인계를 존댓말로 짧게 보고한다.
Flow용 한국어 생성 명령은 간결한 지시형으로 쓴다.
현재 단계의 복사용 명령은 프로젝트 FLOW-COPY-PASTE.txt 하나에 저장하고
수정 때 같은 파일을 덮어쓴다. 이전 판본은 별도 이력으로 보존한다.
파일에는 지금 실행할 명령만 두고 설명·감독 기록·다음 단계 예고를 섞지 않는다.
각 자산 바로 앞에 번호가 있는 저장 이름과 실제 참조 선택을 적는다.
실행을 나눠야 하면 '1번 실행 시작'과 '1번 실행 끝'처럼 범위만 나눈다.
독립 작업은 함께 전달하고 선행 결과가 필요한 작업은 같은 명령 안에 순서를 명시한다.
실제 선행 자산이 없으면 그 후속 작업만 멈추게 한다.

보존할 결과:
번호/역할/실제 파일/참조/채택 버전/관찰한 문제를 적은 자산표,
영상별 원본 길이와 사용 in/out·재생 속도·편집 위치,
러프컷과 편집 명세, 다음 단계에 남길 음향·발화 창과 미확인 목록.
계정 정보와 개인 절대경로는 공개용 결과에 넣지 않는다.
업로드·공개 설정 변경은 이 스킬의 작업에 포함하지 않는다.

만든 뒤 지원되는 실제 호출 방법과 저장 위치를 알려줘.
아직 Flow용 생성 명령이나 영상을 만들지 말고 스킬 준비까지만 해줘.
~~~
