# 17장. 올리기 전에 AI가 영상을 검사합니다

## 이 장에서 만드는 것

정상 원본과 손상 사본을 같은 기준으로 검사하고 전편 확인 근거와 함께 다음 장에 인계합니다.

파일 기술 검사와 화면·동작·실제 음성 청취를 구분합니다. 원본을 보존하고 정상 원본 → 의도적 손상 사본 → 정상 원본을 같은 기준으로 검사합니다. UPLOAD READY는 필요한 검사와 사람 확인의 결과이며 업로드 허가가 아닙니다.18장에서 계정·메타데이터·공개 범위와 게시 승인을 확인합니다.

## 프롬프트와 참고 자료

[prompts.md](prompts.md)에 본문 순서의 요청문을 제공합니다. 현재 사용하는 Claude/Codex와 서비스 입력 위치를 구분하세요. 실제 사용 가능한 연결·계정·모델 조건을 확인합니다.

기존 [Source](source/ai-shorts-maker/)는 이전 제작 경로의 참고 자료입니다. 현재 로켓 제작·검수의 새 완성 구현이나 실제 재현 증거를 뜻하지 않습니다. 현재 프로젝트를 보존하고 [튜터 명세](../../tutor/chapters/ch17/README.md)와 제공 자료의 확보 상태를 확인하세요.
