# 17장. 캐릭터와 원화로 움직이는 장면을 만듭니다

기획을 같은 대상의 기준 이미지, 장면 원화, 실제 영상 클립과 러프컷으로 만들고 후반 작업에 넘깁니다.

## 이번 장의 과정

- **제작 준비:** book-shorts-build를 공개 명세로 만들고 현재 기획 및 Flow의 실제 모델·직접 해상도·길이·개수·비용·참조 지원을 확인합니다.
- **반복 대상 기준:** 필요한 대상만 캐릭터로 산정하고 이름·Character info·불변 특징·실제 기준 이미지와 참조 선택을 연결합니다.
- **장면 원화:** 장면 번호별 독립 원화와 실제 파일을 대응시키고 구도·시점·광원·색·재질·배경·움직일 공간·문자 없는 출력을 확인합니다.
- **수정과 연결 판단:** 관찰한 결함과 추측을 나누고 좋은 결과를 보존하며 문제 자산만 수정합니다. 시작·끝의 실제 연속성을 확인해 독립 클립 여부를 결정합니다.
- **영상 클립:** 채택 원화를 시작 Frames로 연결하고 지원 설정 안에서 카메라 가감속·시차·관찰 시간을 가진 실제 클립을 확보해 원화 번호와 대응합니다.
- **러프컷과 인계:** 실제 다운로드 클립의 번호·채택 버전·길이·사용 구간·러프컷을 확인하고 발화 가능 창·음향 의도·미확인을 18장에 넘깁니다.

## 입력과 도움

[prompts.md](prompts.md)에서 본문 순서의 입력을 복사합니다. 개발 AI용 요청과 Google Flow용 생성 입력은 입력 위치가 다릅니다. 실제 계정·모델·비용·해상도는 현재 화면에서 확인합니다.
