# 11장. 주가부터 공시까지, AI가 한 번에 브리핑합니다

## 이 장에서 만드는 것

11장에서는 10장까지 만든 ai-stock-briefing에 AI 브리핑을 붙입니다. AI에게 종목을 알아서
조사하게 하지 않습니다. 금융위원회와 OpenDART에서 이미 확인한 자료만 건네고, Gemini는 그
안에서 읽기 쉬운 한국어로 정리합니다.

이 장에서 확인하는 것은 여섯 가지입니다.

| 무엇 | 어떻게 확인하나 |
|---|---|
| 근거 안에서만 설명한다 | 브리핑에 나오는 사실이 모두 그 화면의 시세·지수·공시 자료 안에 있는지 확인합니다 |
| 사실과 설명을 나눈다 | 프로그램이 계산한 숫자와 AI가 정리한 문장이 화면에서 구분되는지 확인합니다 |
| 숫자는 프로그램이 계산한다 | 현재가와 기간 등락, 최고가·최저가, 거래일 수, 공시 건수가 AI의 계산값이 아닌지 확인합니다 |
| 모르는 것은 모른다고 한다 | 현재 근거만으로 알 수 없는 것이 따로 표시되고, 투자 판단이나 목표주가가 나오지 않는지 확인합니다 |
| 결과를 다시 확인한다 | 근거 밖의 숫자나 인과관계가 섞인 답이 화면에 나오지 않고 걸러지는지 확인합니다 |
| 실패해도 나머지는 남는다 | Gemini 호출이 실패했을 때 가격과 차트, 공시가 그대로 보이는지 확인합니다 |

AI가 만드는 문장은 같은 자료로도 매번 달라집니다. 완료 기준은 문장이 같은지가 아니라,
브리핑이 우리가 준 근거 안에 머무는지와 사실·설명·알 수 없는 것이 구분되는지입니다.

## 검증 결과

저자는 10장을 끝낸 상태에서 11장 요청문만으로 AI 브리핑까지 갔습니다. 프로젝트 전체 Test
102개가 통과했고 그중 54개가 이 장에서 새로 생겼습니다. 실제 Gemini 호출로 SK하이닉스
브리핑을 만들어 화면의 숫자가 프로그램 계산값과 같은지 대조하고, 근거 밖의 숫자와 투자
판단, 확인되지 않은 인과관계를 넣은 답이 모두 거부되는 것도 확인했습니다. Gemini API Key를
일부러 잘못된 값으로 바꿔 호출을 실패시킨 뒤에도 가격과 차트, 공시가 그대로 보이는 것을
확인했습니다. 근거는
[verification/chapter-11/](../../verification/chapter-11/)에 있습니다.

## 막혔을 때

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

Git 명령을 외우거나 직접 입력할 필요는 없습니다. 아래 요청문을 그대로 붙여넣으면
Claude Code가 확인하고 처리합니다.

**1. 디버깅** --- 먼저 무엇이 어긋났는지 그대로 말하고 고쳐봅니다. 대부분 여기서
해결됩니다.

```text
지금 작업이 책과 다르게 진행됐어.
현재 상태와 화면에 나온 문제를 확인하고 원인을 찾아서 고쳐줘.
```

브리핑만 만들어지지 않을 때는 API Key 문제와 호출 한도, 일시적인 오류를 갈라야 합니다.

```text
AI 브리핑만 만들어지지 않아.
Gemini가 돌려준 상태 코드와 오류 내용을 확인해서 API Key 문제인지,
호출 한도인지, 일시적인 오류인지 구분해줘.
실제 키 값은 출력하지 마.
```

브리핑에 이상한 숫자가 보이면 계산에 넣은 자료부터 확인합니다. 거래가 정지된 날은 시가와
고가, 저가, 거래량이 0으로 제공될 수 있습니다.

```text
브리핑의 최고가나 최저가가 실제 가격과 달라.
계산에 넣은 일별 시세 가운데 거래가 없었던 날이 섞이지 않았는지 확인하고,
실제로 거래된 날만 계산에 쓰게 고쳐줘.
```

Test가 실행할 때마다 다르게 실패하면 실제 API 호출이 한꺼번에 몰렸을 수 있습니다.

```text
Test가 실행할 때마다 다른 곳에서 실패해.
실제 API를 부르는 Test가 동시에 몰려서 거절당하는 것인지 확인하고,
차례로 실행되게 맞춰줘.
```

**2. 내 정상 기록으로 복구** --- 해결되지 않으면 실습하면서 내 프로젝트에 남겨둔 정상
기록으로 돌아갑니다. 지금까지 한 작업은 먼저 따로 보존합니다.

```text
현재 작업은 잃지 않도록 먼저 별도로 보존해줘.
이 프로젝트에서 마지막으로 정상 동작했던 상태를 찾아 안전하게 복구해줘.
```

**3. 장별 Source로 재시작** --- 그래도 이어갈 수 없을 때 사용합니다. 11장의 남은 실습은
건너뛰게 되므로 마지막 수단입니다.

```text
내 현재 작업을 먼저 안전하게 보존해줘.
아래 11장 완성 Source에서 다시 시작해줘.
https://github.com/buildyourownai-lab/develop-like-a-pro-with-ai/tree/main/chapters/ch11/source/ai-stock-briefing
내 인증키를 입력할 자리를 알려주고
준비가 끝나면 11장을 마친 상태인지 확인해줘.
```
