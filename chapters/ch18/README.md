# 18장. 만든 영상을 실제 YouTube에 올립니다

## 이 장에서 만드는 것

17장에서 `UPLOAD READY`가 된 영상을 실제 YouTube 채널에 올립니다. 앞의 두 장은 내 컴퓨터
안에서 파일을 만들고 검사했지만, 이번에는 프로그램이 외부 서비스의 상태를 바꿉니다.
그래서 올리기 전에 무엇이 바뀌는지 먼저 확인합니다.

```text
업로드 대상을 고정한다
→ 제목·설명·공개 범위를 Preview로 본다
→ Google OAuth로 권한을 받는다
→ 비공개로 올린다
→ YouTube Studio에서 확인한다
```

16장에서 만든 같은 프로젝트에서 이어서 진행합니다. 이 장에서는 Reviewer와 별도로
Publisher 역할을 만듭니다. Reviewer는 합격 여부를 판단하고, Publisher는 그 결과를 실제
계정에 반영합니다. 기본값은 비공개 업로드입니다. 공개를 선택하면 비공개로 올린 뒤 같은 영상 ID의 공개 범위만 바꾸며, 상태 변경에 필요한 OAuth 권한을 별도로 확인합니다. 실행 전에 시험 응답으로 두 단계와 실패·재시도를 검증합니다.

## 프롬프트

[prompts.md](prompts.md)에 18장에서 입력하는 문장이 책의 순서대로 있습니다. 모두 Claude
Code에 입력합니다.

## 장별 Source

[source/ai-shorts-maker/](source/ai-shorts-maker/)에 PART 5(16~18장) 전체를 끝낸 완성
상태가 있습니다. 실제
[ai-shorts-maker](https://github.com/buildyourownai-lab/ai-shorts-maker) 저장소에는 책을
마친 뒤 만든 실험용 영상 스크립트가 더 있지만, 이 Source에는 18장 완료에 필요한 파일만
있습니다. 정상 흐름에서 먼저 열어보는 정답지가 아니라, 아래 복구
방법으로도 해결하지 못했을 때 쓰는 마지막 수단입니다.

## 검증 결과

2026-09-22 공개 Source의 자동 검사에서 93건이 통과했고, 배포하지 않는 영상 파일이 필요한 3건은 건너뛰었습니다. 현행 두 단계 업로드는 Mock으로 확인했으며 실계정 재검증은 남아 있습니다. 2026-09-06 직접 공개 업로드 기록은 과거 구현의 근거로 구분합니다. 상세 결과는
[verification/chapter-18/](../../verification/chapter-18/)에 있습니다.

OAuth 앱은 이 장에서 프로덕션으로 게시합니다. 이것은 YouTube 채널이나 영상을 공개하는
설정이 아니며, 테스트 상태에서 갱신 Token이 약 7일 뒤 만료되는 일을 막기 위한 설정입니다.

## 막혔을 때

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

명령어를 외우거나 직접 입력할 필요는 없습니다. 아래 요청문을 그대로 붙여넣으면 Claude
Code가 확인하고 처리합니다.

**1. 디버깅** — 먼저 무엇이 어긋났는지 그대로 말하고 고쳐봅니다. 대부분 여기서
해결됩니다.

```text
지금 작업이 책과 다르게 진행됐어.
현재 상태와 화면에 나온 문제를 확인하고 원인을 찾아서 고쳐줘.
```

이 장에서 특히 자주 막히는 자리는 권한 화면에서 오류가 나는 경우입니다.

```text
권한 화면에서 오류가 났어.
어떤 오류인지 그대로 보여주고 원인부터 확인해줘.
권한을 더 넓히거나 다른 설정을 바꾸기 전에 무엇이 잘못됐는지 먼저 찾아줘.
```

**2. 내 정상 기록으로 복구** — 해결되지 않으면 실습하면서 내 프로젝트에 남겨둔 정상
기록으로 돌아갑니다. 지금까지 한 작업은 먼저 따로 보존합니다.

```text
현재 작업은 잃지 않도록 먼저 별도로 보존해줘.
이 프로젝트에서 마지막으로 정상 동작했던 상태를 찾아 안전하게 복구해줘.
```

**3. 장별 Source로 재시작** — 그래도 이어갈 수 없을 때 사용합니다. PART 5의 마지막
장이므로, 이 수단을 쓰면 PART 5 실습을 마친 것으로 보고 넘어가면 됩니다.

```text
내 현재 작업을 먼저 안전하게 보존해줘.
아래 PART 5 완성 Source에서 다시 시작해줘.
https://github.com/buildyourownai-lab/develop-like-a-pro-with-ai/tree/main/chapters/ch18/source/ai-shorts-maker
내가 직접 넣어야 하는 설정과 인증정보가 무엇인지 알려줘.
```
