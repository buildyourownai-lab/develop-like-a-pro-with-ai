# 18장. 음성·음향·자막을 합쳐 영상을 완성합니다

선택한 언어의 음성·음향·동적 자막을 합성한 MP4와 편집 소스, 표지·게시 자료를 완성합니다. 실제 업로드는 별도 선택입니다.

## 이번 장의 과정

- **완성 스킬과 음향:** book-shorts-finish를 공개 명세로 만들고 원음 유지·감소·제거·교체를 판단합니다. 음악·효과음의 정확한 곡명·제공자·링크·이용 조건·수령 파일을 기록합니다.
- **대본과 음성:** 실제 화면과 조사 근거에 맞는 대본을 확정하고 Charon 대표 샘플을 들어 채택한 뒤 선택 언어의 실제 WAV와 문장을 대응합니다.
- **실제 길이와 배치:** 실제 WAV 길이를 측정해 장면 사건·발화 창·침묵에 맞게 배치하고 원본과 단일 편집 명세·언어별 배치표를 보존합니다.
- **동적 자막:** 첫 질문과 끝 결론의 상단 배치, 중간 하단 설명, 두 줄의 좌우 진입·독서 시간·퇴장과 페이드, 중복·가림 방지를 실제 영상으로 확인합니다. 원·설명선은 사용하지 않습니다.
- **합성과 시청:** 채택한 음향을 보존해 선택 언어의 MP4·SRT·편집 소스를 출력합니다. 기술 확인과 사람이 전편을 보고 들은 범위를 구분하고 미확인·문제 구간을 남깁니다.
- **표지와 게시 준비:** 실제 기준 이미지로 표지·제목·설명·출처·게시 조건을 저장합니다. 현재 공식 안내와 계정 조건으로 언어·시청자·AI 재현 공개·Shorts 표지를 판단하며 실제 게시 없이 제작 학습을 마칠 수 있습니다.
