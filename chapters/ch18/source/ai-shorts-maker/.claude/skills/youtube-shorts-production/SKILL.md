# YouTube Shorts Production

입력: `$ARGUMENTS`

이 Skill은 한 번에 영상을 뽑는 명령이 아니다. 아래 단계의 산출물을 순서대로 만들고,
사람 승인이 필요한 지점에서 반드시 멈추는 제작 절차다. 새 작업은 별도
`artifacts/<작업명>/` 폴더를 사용하며 기존 완성본을 덮어쓰지 않는다.

## 고정 순서

| 단계 | 먼저 만드는 것 | 다음 단계로 가는 조건 |
|---:|---|---|
| 1 | 소재 후보 3개와 비교표 | 사람이 소재 하나 승인 |
| 2 | 원 논문·연구기관 해설 조사와 50초대 시나리오 | 사실·과장 표현 검사와 사람 승인 |
| 3 | 장면별 화면·내레이션·자막·이미지 설명·움직임 설명 | 사람이 장면 구성표와 화풍 승인 |
| 4 | 생성 서비스의 현재 조건과 한 서비스·조합 방식 비교 | 사람이 제작 방식과 서비스를 승인 |
| 5 | 기준 이미지 계획과 예상 무료 이용량 | 사람이 무료 이용량 사용 승인 |
| 6 | 기준 이미지 비교 화면 | 사람이 사용할 이미지 승인 |
| 7 | 영상 후보 계획과 예상 무료 이용량 | 사람이 무료 이용량 사용 승인 |
| 8 | 영상 후보 비교와 장면별 선택안 | 사람이 최종 장면 승인 |
| 9 | 현재 대본 검사와 음성·음악·효과음 | 검사 통과 뒤 사람이 소리 파일과 기록 승인 |
| 10 | 자막과 영상 조립 결과 | MP4·시나리오·장면 구성표·출처·권리·측정값 반환 |

승인 메시지가 오기 전에는 다음 단계로 넘어가지 않는다. “좋다”, “이게 낫다”처럼
대상과 행동이 불명확한 말은 승인으로 추정하지 않는다.

## 입력과 기본값

- 사용자가 말한 주제, 길이, 화풍, Voice, 음악, 자막 조건만 우선 적용한다.
- 생략한 값은 검증된 Roman Golden Path를 참고해 제안하되 승인 없이 확정하지 않는다.
- 기본 길이는 50~55초, 화면은 1080×1920 세로 H.264/AAC다.
- 기본 경로는 Kling·Vidu·Hailuo·PixVerse 중 현재 무료 조건과 화풍이 맞는 한
  서비스를 고른다. 여러 서비스를 섞는 것은 선택안이다.
- Roman Golden Path의 기준 이미지는 Kling AI Images의 Image 3.0에서 장면마다
  한 장씩 만든다. 영상은 장면 1 Vidu, 장면 3 Kling+Hailuo, 장면 4·6 Hailuo,
  장면 5 PixVerse, 장면 2·7 기준 이미지의 느린 확대를 사용한다.
- 짧은 생성 영상은 처음부터 반복하지 않는다. 장면 길이에 맞게 조금 느리게 하거나
  마지막 화면을 유지한다.
- 사용자에게 JSON, 내부 파라미터, Script 이름을 외우게 하지 않는다. Claude가 자연어
  요청을 작업 파일로 옮긴다.

## 대본 Gate

TTS보다 먼저 `script-review.json`을 만든다. 다음 다섯 항목이 모두 `true`이고,
`status`가 `PASS`이며, 출처와 검수자 기록이 있고, 현재 Storyboard·내레이션의
SHA-256이 기록과 같아야 한다.

1. 맞춤법·띄어쓰기·누락
2. 숫자·단위·용어
3. 내레이션·자막 의미 일치
4. 사실
5. 출처

하나라도 다르면 Secret을 읽거나 TTS API를 호출하지 않는다. 대본이나 Storyboard가
바뀌면 이전 음성 Cache를 폐기하고 다시 검수한다.

Roman 기준 실행은 다음 순서다.

```bash
python3 scripts/make_roman_concrete_short.py review
# script-review.json의 다섯 항목·출처·검수자와 Digest를 확인해 PASS 승인
python3 scripts/make_roman_concrete_short.py voice
# 생성한 일곱 음성을 듣고 승인
python3 scripts/make_roman_concrete_short.py all
```

## 생성·비용·권리 확인

- 기준 이미지를 먼저 보여주고 장면 중복, 현대 물건, 의미 없는 글자, 기형 형태,
  자막 공간을 확인한다.
- 실행하는 날 각 서비스 공식 화면에서 무료 이용량, 생성 길이·해상도, 서비스 로고,
  다운로드와 상업 이용 조건을 확인해 기록한다.
- 무료 이용량 사용 전 사람 승인을 받는다. 결제, 유료 전환, 새 Secret·OAuth가 필요하면 멈춘다.
- 화면은 생성형 시각화임을 밝히고, 출처 자료의 그림·문장을 복제하지 않는다.
- BGM은 권리 조건이 확인된 파일만 사용하고 곡명·아티스트·출처를 기록한다.
- Roman 효과음은 선택한 Vidu·Kling·Hailuo·PixVerse 영상의 원래 소리에서
  장면에 맞는 주변음만 사용한다. 생성된 음악·사람 목소리는 버리고 장면 2·7은
  무음으로 둔다. 내레이션 중에는 효과음과 BGM을 낮춘다.

## 제작 완료 조건

제작 단계의 출력은 다음 여섯 가지다.

1. 최종 MP4 경로와 SHA-256
2. 최종 시나리오와 장면 구성표
3. `script-review.json`
4. 사용한 생성 결과와 권리 확인 기록
5. 길이·해상도·화면비·영상·음성 형식·음량·검은 화면·전체 읽기 측정값
6. 사람이 직접 볼 항목: 장면 누락·중복, 흔들림, 형태 변형, 자막 오타, 화면과
   내레이션 일치, 목소리·효과음·음악 균형

제작은 MP4와 기록 반환에서 끝난다. MP4를 만들었다고 `UPLOAD READY`라고 쓰지 않는다. 독립 판정은
`video-upload-review`, YouTube 업로드는 `youtube-publisher`가 담당한다.
