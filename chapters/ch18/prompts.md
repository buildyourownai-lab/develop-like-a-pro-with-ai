## P18-06 · OAuth 앱을 프로덕션으로 준비합니다

~~~prompt
이 OAuth 앱의 브랜딩 화면에서 사람이 입력해야 할 필수 정보와 준비할 주소를 알려줘.
홈페이지, 개인정보처리방침, 승인 도메인을 내가 입력하면 값이 맞는지 확인해줘.
그다음 잠재고객 화면에서 내가 앱을 프로덕션으로 게시할 수 있게 순서대로 안내해줘.
이 설정은 YouTube 채널이나 영상을 공개하는 일이 아니라는 점을 먼저 알려줘.
미검증 자체 앱 경고가 나오면 고급 경로를 열고 멈춰서,
내가 계정과 앱 이름을 확인한 뒤 직접 승인하게 해줘.
게시 버튼과 미검증 자체 앱 경고의 최종 승인은 내가 직접 하게 해줘.
비밀 값은 화면이나 로그에 출력하지 마.
~~~

## P18-08 · 공개를 선택하면 같은 영상의 상태를 바꿉니다

~~~prompt
Publisher에서 대상이 분명한 공개 업로드 요청은 비공개 업로드와 동일 영상의 공개 전환을 함께 승인한 것으로 처리해줘.
비공개 업로드에서 받은 영상 ID를 먼저 기록하고 그 ID의 상태만 바꿔.
현재 Token에 상태 변경 권한이 있는지 공식 API 문서로 확인하고 부족할 때만 필요한 승인을 안내해.
플랫폼의 프로젝트 검증·공개 제한도 확인하고, 제한을 우회하지 마.
업로드 성공 후 공개 전환만 실패하면 비공개 업로드 성공·공개 미완료를 나눠 알려줘.
재시도할 때 다시 업로드하지 말고 같은 영상 ID의 상태 변경만 이어가.
API 응답이 불명확하면 실제 상태를 확인하기 전 추가 업로드하지 마.
이 요청은 구현 지시야. 지금 영상을 올리거나 공개하지 말고, 시험 응답으로 두 단계와 실패·재시도를 검증해줘.
~~~
