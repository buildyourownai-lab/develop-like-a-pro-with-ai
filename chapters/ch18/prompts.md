~~~prompt

목표: 실제 러프컷에 음향·낭독·음성·자막을 배치하고 편집 가능한 원본, 언어별 MP4, 표지와 게시 자료를 만든다. 업로드는 별도 선택이다.

입력: 원본 클립, 선택 구간과 배속을 기록한 단일 편집 명세, 러프컷, 장면 사건/사실 근거/표현 한계, 실제 수령 음원과 라이선스, 확정 대본과 WAV. 없는 파일은 만들었다고 가정하지 않는다. 어떤 언어를 만들지 먼저 확인하고 한국어만 선택하면 영어를 필수 완료 조건에 넣지 않는다.

소작업을 음향, 대본, 음성, 배치, 자막, 합성, 게시준비로 구분해. 현재 요청한 작업만 수행한다.
- 음향: 실제 원음을 관찰 가능한 범위에서 확인하고 유지/감소/제거/교체 이유를 기록한다. 음악/효과음 후보의 곡명·작가·공식 링크·조회일·사용 조건을 제안하고 실제 수령 파일을 대응시킨다.
- 대본: 실제 편집 영상의 사건과 발화 가능 창으로 언어별 낭독문을 쓴다. 사실을 과장하지 않고 화면 감상과 침묵을 남긴다.

- 배치: WAV의 실제 길이, 문장, 사건, 호흡으로 언어별 위치를 정한다. 길면 대본 축약이나 국소 편집을 먼저 제안하고 배속을 숨기지 않는다.
- 자막: 정보를 덜어내고 첫 질문/끝 결론은 상단, 본문은 하단을 출발안으로 삼는다. 두 줄이 반대쪽에서 등장해 정지하고 읽힌 뒤 후퇴/페이드하게 한다. 글자·외곽선을 함께 처리하고 같은 순간 위아래에 같은 정보를 중복하지 않는다. 점·선·추적 라벨은 이번 기본 완성안에서 만들지 않는다.
- 합성: 영상·언어별 음성·음악·효과음·자막을 결합한다. 승인한 음향은 자막 수정만으로 다시 만들지 않는다. 실제 필요 구간의 음악을 낮추고 끝말과 엔딩 여운을 보존한다.
- 게시준비: 실제 완성 영상에 맞는 표지·제목·설명·출처·언어·합성 공개·시청자 설정 후보를 준비한다. 조회수나 추천을 보장하지 않는다.

파일 계약: 프로젝트 상대경로를 사용한다. 기존 원본을 보존하고 폴더/파일 이름은 먼저 현재 구조에 맞춘다. 편집 명세, 확정 대본, 실제 WAV, 언어별 음성 배치, 음향 큐/권리, 자막 이벤트가 서로 같은 장면 번호를 사용하게 해. 최종 MP4와 편집 가능한 소스, 재생성 방법, 필요 도구/폰트와 사용 조건을 남긴다. 고정된 개인 컴퓨터 경로·브라우저 접속 포트·비공개 프로필·임시 폰트에 의존하지 않는다. 음원 원본은 공개 배포 묶음에 넣지 않는다.

출력: 사용자 보고는 이번 작업/고려 사항/산출물/다음 인계를 존댓말로 짧게 쓴다. 외부 서비스에 붙일 파일에는 지금 단계의 실행 명령만 넣고 각 항목 앞에 번호 저장 이름과 실제 참조 선택을 적는다. 한국어 생성 명령은 간결한 지시형으로 쓴다. 의존 실행이 여러 묶음이면 각 묶음만 '1번 실행 시작/1번 실행 끝'처럼 나누고 설명을 섞지 않는다.

판단: 파일 존재·길이 측정·실제 재생/청취·권리 확인·업로드를 따로 기록한다. 못 본 화면과 못 들은 소리를 통과시키지 않는다. 기술 확인은 현재 결과를 여는 데 필요한 범위로 하고 전권 테스트나 다른 장 변경을 추가하지 않는다. 사용자가 직접 선택할 음색과 공개 범위를 대신 결정하지 않는다.

재개: 현재 작업, 사용한 파일/판본, 완료/미확인, 다음 행동 하나를 프로젝트에 저장한다. 생성 대기와 오류를 완료로 표시하지 않는다. 지금은 스킬과 출력 양식을 만들고 인식된 입력/누락을 알려준 뒤 멈춰줘. 아직 미디어를 생성하거나 업로드하지 마.
~~~
