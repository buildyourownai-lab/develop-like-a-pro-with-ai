# 16장. 질문 하나로 영상 제작을 설계합니다

선택한 소재의 질문·결론, 근거, 화면 설계, 자산 수와 잠정 시간을 제작 인계로 묶습니다.

## 이번 장의 과정

- **기획 스킬:** 공개 본문 명세만으로 book-shorts-plan을 프로젝트 로컬에 만들고 실제 호출법 또는 일반 지침 대안을 확인합니다.
- **소재 선택:** 후보의 중심 질문·결론·시각 사건·추천 제목을 비교하고 독자가 선택한 소재와 언어를 저장합니다.
- **근거와 표현 한계:** 직접 읽은 출처와 조회일·근거 위치를 보존하고 사실·차이·미확인·허용 재현·금지 요소를 구분합니다.
- **장면 설계:** 시각적 공개 사건, 카메라 경로와 가감속·관찰 시간, 빛·색·재질·음향 의도·자막 여백을 장면별로 정하고 반복 구도를 비교합니다.
- **수량과 잠정 시간:** 반복 대상의 수·이름·불변 특징과 기준 이미지·원화·클립·편집 구간을 구분해 수량과 잠정 시간을 산정합니다.
- **제작 인계:** 선택 내용·출처·장면 카드·수량·잠정 시간·참조 관계·미확인을 제작인계.md에 연결하고 17장에 넘깁니다.

## 입력과 도움

[prompts.md](prompts.md)에서 본문 순서의 입력을 복사합니다. 개발 AI용 요청과 Google Flow용 생성 입력은 입력 위치가 다릅니다. 실제 계정·모델·비용·해상도는 현재 화면에서 확인합니다.

[튜터 수업 자료](../../tutor/chapters/ch16/README.md)는 새 장의 목표·힌트·완료 기준을 담습니다. 공개 본문 명세로 독자용 스킬을 만들며 비공개 저자 자료는 필요하지 않습니다. 기존 [Source](source/)는 구판 비교 자료로, 새 제작 경로의 완성 구현이나 독자 실재현 증거가 아닙니다. 현재 프로젝트를 보존하세요.
