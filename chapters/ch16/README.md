# 16장. AI와 YouTube 영상을 만듭니다

## 이 장에서 만드는 것

주제 한 줄에서 시작해 60초에 조금 못 미치는 YouTube Shorts 한 편을 완성합니다. 영상
편집 프로그램을 배우지 않고, 무엇을 이야기할지와 어떤 소재·음악을 쓸지만 정합니다.
실제 MP4를 만드는 일은 Claude가 맡습니다.

```text
주제를 정한다
→ 사실을 확인하고 Storyboard를 받는다
→ 영상 소재와 음악을 고른다
→ Claude가 MP4를 만든다
→ 처음부터 끝까지 재생해서 확인한다
```

PART 5는 ai-shorts-maker라는 새 프로젝트에서 시작합니다. 이 장을 끝내면 1080×1920 세로
화면에 한국어 목소리와 음악, 한글 자막이 들어간 MP4 한 편과, 다음 영상에서 다시 쓰는
제작 절차 Skill이 생깁니다. 두 번째 영상부터는 이번과 달라질 점만 말하면 됩니다.

## 프롬프트

[prompts.md](prompts.md)에 16장에서 입력하는 문장이 책의 순서대로 있습니다. 모두 Claude
Code에 입력합니다.

## 장별 Source

16장을 끝낸 상태는 [source/ai-shorts-maker/](source/ai-shorts-maker/)에 있습니다. 정상
흐름에서 먼저 열어보는 정답지가 아니라, 아래 복구 방법으로도 해결하지 못했을 때 쓰는
마지막 수단입니다. 이 Source로 다시 시작하면 16장의 남은 실습을 건너뛰고 17장부터
이어가게 됩니다. PART 5(16~18장)를 모두 끝낸 완성 상태는
[ch18/source/ai-shorts-maker/](../ch18/source/ai-shorts-maker/)에 있습니다.

## 검증 결과

저자는 이 장의 절차대로 실제 Shorts MP4를 만들고 처음부터 끝까지 재생해 확인했습니다.
길이와 화면 비율, 영상·음성 형식은 자동 검사로도 확인했습니다. 근거는
[verification/chapter-16/](../../verification/chapter-16/)에 있습니다.

## 막혔을 때

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

명령어를 외우거나 직접 입력할 필요는 없습니다. 아래 요청문을 그대로 붙여넣으면 Claude
Code가 확인하고 처리합니다.

**1. 디버깅** — 먼저 무엇이 어긋났는지 그대로 말하고 고쳐봅니다. 대부분 여기서
해결됩니다.

```text
지금 작업이 책과 다르게 진행됐어.
현재 상태와 화면에 나온 문제를 확인하고 원인을 찾아서 고쳐줘.
```

이 장에서 특히 자주 막히는 자리는 영상 소재를 내려받는 단계입니다. 응답을 그대로
확인합니다.

```text
소재를 받아오는 단계에서 멈췄어.
요청 주소와 응답 코드, 응답 본문을 그대로 보여주고 원인을 찾아줘.
소재를 임의로 다른 것으로 바꾸거나 검사를 건너뛰지는 마.
```

**2. 내 정상 기록으로 복구** — 해결되지 않으면 실습하면서 내 프로젝트에 남겨둔 정상
기록으로 돌아갑니다. 지금까지 한 작업은 먼저 따로 보존합니다.

```text
현재 작업은 잃지 않도록 먼저 별도로 보존해줘.
이 프로젝트에서 마지막으로 정상 동작했던 상태를 찾아 안전하게 복구해줘.
```

**3. 장별 Source로 재시작** — 그래도 이어갈 수 없을 때 사용합니다. PART 5 실습을 마친
것으로 보고 다음으로 넘어가게 되므로 마지막 수단입니다.

```text
내 현재 작업을 먼저 안전하게 보존해줘.
아래 16장 완성 Source에서 다시 시작해줘.
https://github.com/buildyourownai-lab/develop-like-a-pro-with-ai/tree/main/chapters/ch16/source/ai-shorts-maker
내가 직접 넣어야 하는 설정과 인증정보가 무엇인지 알려줘.
```
