# 16장 요청문

본문 순서대로 사용합니다. 생성·선택·조립 승인은 실제 계획과 파일을 확인한 뒤 진행합니다. 승인한 배치 안에서 같은 허락을 반복하지 않습니다.

## 시작 전 확인

```text
16장 시작해.
```

## 1. 영상으로 만들 소재를 찾습니다

```text
역사와 과학이 만나는 50초대 YouTube Shorts 소재를 세 개 제안해줘.

각 소재를 다음 기준으로 비교해.
- 제목만 봐도 궁금한가
- 50초대 안에 질문 하나와 답 하나를 설명할 수 있는가
- 서로 다른 장면을 만들 수 있는가
- 원 논문이나 대학·연구기관의 해설을 찾을 수 있는가
- 생성형 이미지와 영상으로 표현하기 좋은가

아직 시나리오를 쓰거나 영상을 만들지 말고 비교표만 보여줘.
내 선택을 기다려.
```

## 2. Claude가 조사한 결과로 시나리오를 씁니다

로마 콘크리트를 소재로 선택한 경우에 사용합니다.

```text
세 후보 중 로마 콘크리트로 진행할게.

먼저 이 소재가 50~55초 과학 Shorts에 적합한지 조사해줘. 연구진이 직접 쓴
원 논문을 우선 찾고, 대학이나 연구기관의 해설로 내용을 다시 확인해.

조사한 뒤 다음 순서로 보여줘.
1. 자료 제목, 발표 기관, 발표 연도, 주소
2. 여러 자료에서 확인된 핵심 사실
3. 아직 확실하지 않거나 영상에서 과장하면 안 되는 부분
4. 일반 시청자가 이해할 한 가지 질문과 결론
5. 확인된 사실만 사용한 50~55초 한국어 시나리오

자료의 문장이나 그림을 복제하지 말고 우리말로 새로 써. 한 가지 발견으로
로마 콘크리트의 모든 내구성을 설명하지 마. 조사 결과와 시나리오를 보여준 뒤
내 승인을 기다리고, 아직 장면이나 이미지와 영상은 만들지 마.
```

## 3. 시나리오를 검사하고 승인합니다

```text
방금 작성한 시나리오를 다시 검사해줘.

- 맞춤법, 띄어쓰기, 빠진 문장
- 숫자와 과학 용어의 표기
- 각 문장을 뒷받침하는 자료
- 원 논문보다 과장하거나 단정한 표현
- 보통 속도로 읽었을 때 50~55초에 들어오는지

문제가 있으면 고친 최종 시나리오와 수정 이유를 보여줘. 각 항목을 통과 또는
수정 필요로 표시하고 내 승인을 기다려. 아직 장면을 만들지 마.
```

조사와 시나리오를 확인한 다음 승인합니다.

```text
조사 결과와 검사한 최종 시나리오를 승인해.
이제 이 시나리오를 7개 장면으로 나눠줘.

각 장면마다 재생 시간, 화면 내용, 내레이션, 짧은 한글 자막,
이미지 생성 사이트에 넣을 화면 설명, 영상 생성 사이트에 넣을 움직임 설명을 써.
장면마다 구도와 움직임이 달라야 하고, 화면에 글자를 그려 넣지는 마.
결과를 표로 보여주고 내 승인을 기다려. 아직 생성 사이트는 실행하지 마.
```

## 4. 일곱 장면을 확인합니다

장면 구성표를 직접 확인한 다음 승인합니다.

```text
일곱 장면의 화면, 움직임, 내레이션, 자막과 공통 화풍을 모두 확인했어.
이 장면 구성표를 승인해. 다음 서비스 선택에서 이 구성을 기준으로 사용해줘.
아직 이미지나 영상은 만들지 마.
```

## 5. Kling의 제작 조건과 예산을 확인합니다

```text
승인한 일곱 장면의 기준 이미지와 영상 후보를 Kling에서 만들 계획이야.
먼저 공식 화면과 내 계정에서 현재 제작 조건을 확인해줘.

다음 항목을 구분해 표로 보여줘.
- 확인 날짜, 공식 주소와 이용 조건을 확인한 위치
- 현재 플랜, 구독 요금, 갱신 주기와 자동 갱신 여부, 남은 크레딧을 각각 다른 칸에 표시
- 이미지와 이미지로 영상 만들기에 선택 가능한 모델
- 모델별로 선택 가능한 화면 비율, 해상도와 영상 길이
- 이번 설정에서 생성 한 번에 차감되는 크레딧과 한 번에 나오는 결과 수
- 워터마크, 다운로드와 상업 이용 조건

확인하지 못한 항목은 미확인으로 표시해. 화면을 볼 수 없으면 내가 확인해서
전달해야 할 항목을 알려줘. 미확인 조건을 추측해 생성 계획을 확정하지 마.
기준 이미지 7장과 움직이는 다섯 장면의 후보에 필요한 임시 설정을 정리해.
목표 파일 수, 과금되는 생성 횟수, 회당 차감량과 합계를 구분하고,
재생성 여유는 선택 항목으로 따로 표시해. 잔량과 비교하되 비용이 미확인이면
예산을 임의로 추천하지 마. 아직 크레딧을 쓰거나 결제하지 마.
```

현재 이용 조건을 확인하고 <전체 크레딧 상한>을 수치로 바꿉니다.

```text
현재 플랜과 이용 조건을 확인했어. 이번 영상의 이미지와 영상 생성은
Kling에서 진행하고, 전체 크레딧 차감 상한은 <전체 크레딧 상한>으로 정할게.

기준 이미지, 영상 후보와 다시 만드는 작업의 차감량을 모두 이 상한 안에서
합산해. 각 단계의 설명, 모델, 설정, 생성 횟수와 예상 차감량을 보여주고
내가 그 계획을 승인한 뒤에만 생성해.

추가 구매, 플랜 변경과 별도 결제는 하지 마. 상한이나 잔량이 부족하거나
확인한 비용과 조건이 달라지면 멈추고 알려줘. 아직 생성하지 마.
```

## 6. 기준 이미지를 먼저 만들고 승인합니다

```text
Kling의 공식 이미지 생성 화면에서 현재 사용할 수 있는 모델을 확인해.
승인한 일곱 장면의 이미지 설명과 공통 화풍에 맞는 모델을 제안하고,
세로 9:16 기준 이미지를 장면마다 한 장씩 만들 계획을 보여줘.

장면 번호, 이미지 설명, 모델, 화면 설정, 생성 횟수, 결과 수와 예상 크레딧
차감량을 표로 정리해. 화면 안에 글자를 그려 넣지 말고 아래쪽 자막 공간을 남겨.

원하는 한 장을 얻는 것과 생성 한 번에서 여러 결과가 나오는 것을 구분해.
설정별 차감량을 확인하지 못했거나 예산이 부족하면 알려주고 멈춰.
브라우저를 조작할 수 없으면 실행했다고 보고하지 말고 내가 할 일을 안내해.
```

```text
전체 예산과 이 단계 상한 안에서 방금 승인한 계획만 실행해줘.
```

## 7. 영상 후보를 만들고 고릅니다

```text
승인한 기준 이미지와 장면별 움직임 설명으로 Kling 영상 후보 계획을 세워줘.

- 장면 1: 선택한 로마 건축 외관의 형태를 유지하며 빗물이 떨어지고 카메라가 천천히 다가감
- 장면 3: 로마 시대 작업장에서 증기가 오르고 재료가 천천히 섞임
- 장면 4: 물방울이 균열 안으로 흐름
- 장면 5: 결정이 천천히 자라 틈을 메움
- 장면 6: 한쪽은 물 흐름이 멈추고 다른 쪽은 계속 흐름
- 장면 2와 7: 영상 생성 없이 기준 이미지에 조립 단계에서 느린 확대 적용

공식 화면에서 현재 사용할 수 있는 이미지로 영상 만들기 모델을 확인하고,
각 장면에 맞는 모델과 설정을 제안해.
구도·대상별 색상·질감·광원 방향·초점과 카메라를 구체적으로 지정하고,
움직임은 시작 상태·변화 위치와 방향·종료 상태로 나눠 적어.
제출 전에 대본과의 일치, 카메라 지시의 충돌, 고체와 물의 표현,
기준 이미지의 형상과 앞뒤 장면 연결을 자체 리뷰하고 수정 이유를 보여줘. 영상이 필요한 다섯 장면의 후보 배치
계획을 보여줘. 장면 3에 두 후보가 필요하다고 판단하면
그 이유와 추가 비용을 따로 제안하고 승인 전에는 늘리지 마.

장면별 입력 이미지, 움직임 설명, 모델, 화면 비율과 해상도, 생성 길이,
생성 횟수, 원래 소리의 생성 여부와 예상 크레딧 차감량을 표로 보여줘.
내레이션의 예상 호흡에 맞춰 충분한 생성 길이를 골라. 실제 화면에서 지원하면
8초나 10초 등을 검토하고, 5초 영상을 극단적으로 느리게 하거나 화면을 오래
멈춰 늘리는 계획은 피해야 해. 원본 생성 길이, 잘라 쓸 원본 구간,
조립 후 장면 길이와 속도 조정·끝 화면 유지 계획을 각각 적어.
장면 2와 7에도 예상 조립 시간을 적어.

장면 1·3·4·5·6은 native audio(영상과 함께 생성하는 소리)를 켜는 계획으로 비용을 확인해.
비·증기·혼합·물 흐름과 장면에 맞는 주변 소리만 요청하고 생성 음악과 대사는
넣지 마. 이번 단계의 예상 합계, 지금까지 쓴 양과 전체 예산에서 남을 양도 보여줘.

세로 9:16로 조립할 수 있는지 확인하고, 최종 1080×1920 화면과 원본 영상의
해상도를 구분해. 설정이나 비용을 확인하지 못하면 멈추고 알려줘.
아직 생성하지 마.
```

영상 계획을 확인하고 <영상 단계 크레딧 상한>을 수치로 바꿉니다.

```text
영상 후보의 설명, 모델, 설정, 생성 횟수와 예상 차감량을 확인했어.
영상 단계의 크레딧 상한은 <영상 단계 크레딧 상한>이야.
전체 예산과 이 단계 상한 안에서 방금 승인한 후보만 만들어줘.

카메라는 고정하거나 아주 천천히 움직이게 해. 후보 파일을 장면 번호로
정리하고, 실제 설정과 차감량, 내려받기 결과를 제작 기록에 남겨줘.
실패하거나 조건과 비용이 달라지면 멈추고 알려줘.
자동 재생성, 후보 추가, 추가 구매와 플랜 변경은 하지 마.
브라우저 접근이 없으면 내가 생성·다운로드할 순서를 안내해.
아직 최종 장면을 선택하거나 조립하지 마.
```

실제 후보를 재생한 뒤 선택한 파일과 사용 구간을 전달합니다.

```text
후보를 재생해 형태와 움직임을 확인했어. 내가 선택한 후보 파일과 사용 구간을
장면별로 정리해서 보여줘. 아직 선택하지 못한 장면은 추측해서 채우지 마.

장면 2와 7은 승인한 기준 이미지에 아주 느린 확대만 적용할 계획으로 적어줘.
짧은 영상을 처음부터 반복하지 말고 내레이션 길이에 맞출 계획을 보여줘.
필요하면 자연스러운 범위의 속도 조정이나 짧은 끝 화면 유지를 제안하되,
극단적인 감속·긴 프레임 동결이 필요하면 후보 수정안을 보여줘.
원본 생성 길이와 최종 사용 시간을 구분하고, 일곱 장면의 예상 시작·끝과
합계를 보여줘. 아직 조립하지 마.
```

파일·사용 구간·정지 이미지의 확대 계획을 확인한 다음 승인합니다.

```text
장면별 파일과 사용 구간, 장면 2와 7의 느린 확대 계획을 확인했어.
이 표를 최종 장면 구성으로 승인해. 선택하지 않은 후보는 사용하지 마.
원래 소리는 다음 단계에서 따로 확인하고 승인할게. 아직 최종 영상은 조립하지 마.
```

## 8. 목소리와 소리를 준비합니다

```text
음성을 만들기 전에 현재 내레이션과 자막을 최종 검사해줘.

맞춤법·띄어쓰기·빠진 문장, 숫자와 용어 표기, 내레이션과 자막의 뜻이 맞는지,
```


## 10. 확인한 제작 순서를 다음 영상에 재사용합니다

```text
이번에 실제로 완성하고 기록을 확인한 Kling 기반 Shorts 제작 과정을
`youtube-shorts-production`이라는 재사용 가능한 Skill로 정리해줘.
미실시 단계나 확인하지 못한 결과를 완료한 절차처럼 쓰지 마.

소재 탐구 → 근거 조사와 시나리오 작성 → 사람 승인 → 장면 구성 → Kling 조건과
전체 크레딧 예산 확인 → 기준 이미지 계획·생성 승인 → 기준 이미지 승인 →
영상 후보 계획·생성 승인 → 최종 장면 승인 → 대본 최종 검사 → 목소리·음악·
효과음 확인과 승인 → MP4 조립 순서를 지켜.
```
