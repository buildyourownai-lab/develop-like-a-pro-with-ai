## P16-02 · 반복할 판단을 기획 스킬로 만듭니다

입력 대상: **현재 프로젝트의 AI**

~~~prompt
현재 영상 프로젝트 안에 book-shorts-plan이라는 기획 스킬을 만들어줘. 아래 공개 명세만으로 독립적으로 쓸 수 있게 작성해. 다른 사람의 비공개 스킬이나 운영 자료를 읽거나 복사하지 마.

목적
짧은 세로 영상의 소재를 고르고, 근거를 조사하고, 영상미를 고려한 장면과 제작 수량을 설계해서 다음 제작 단계에 넘긴다. 지금은 이미지·영상·음성을 생성하지 않는다.

설치와 사용
- 먼저 현재 영상 프로젝트와 이 AI가 지원하는 프로젝트 로컬 스킬 형식을 확인해. 기존 스킬과 설정은 보존하고, 지원되는 위치에 SKILL.md와 꼭 필요한 보조 양식만 만들어.
- 전역 설정을 바꾸지 마. 스킬을 지원하지 않는 환경이라면 프로젝트에 같은 명세를 담은 일반 텍스트 파일을 만들고, 그 파일을 읽어 동일한 소작업을 수행하는 호출문을 알려줘.
- 이름, 설명, 목적, 입력, 소작업별 절차, 판단 기준, 산출물, 멈출 지점, 재개 방법을 빠짐없이 써줘.
- 호출법은 현재 AI가 실제로 지원하는 방식으로 안내해. 파일 작성과 새 대화에서의 스킬 발견 여부는 구분해 보고해.

입력
사용자의 관심 소재와 목적, 원하는 언어, 현재 프로젝트의 기획 자료, 사용자가 이미 선택한 내용과 실제 생성 결과가 있으면 읽는다. 없는 입력은 추측해서 확정하지 않는다. 제작 언어는 한국어를 기본으로 하고, 영어판은 사용자가 선택했을 때만 목표와 완료 조건에 포함한다. 아직 소재가 없으면 소작업 '소재'부터 시작한다.

소작업은 소재 / 조사 / 설계 / 인계 네 가지다. 사용자가 지정한 소작업 하나만 수행하고, 다음 소작업은 사용자의 진행 요청을 받은 뒤 시작한다.

1. 소재
후보 3개를 시각적 반전, 카메라 이동으로 공개할 공간, 속도와 규모를 보여 줄 가능성, 신뢰할 출처 확보 가능성, 제작 난도로 비교한다. 각 후보에 중심 질문, 한 문장 결론, 실제로 보여 줄 사건, 추천 제목 3개를 제시한다. 제목은 사실보다 과장하지 않는다. 가장 적합한 후보와 이유를 먼저 추천하고 사용자의 선택을 받는다. 이때 영상 길이를 확정하지 않는다.

2. 조사
선택한 질문을 설명하는 데 필요한 주장부터 정한다. 공식 기관·원문·전문 자료를 우선해 직접 내용을 읽고, 제목·저자 또는 기관·URL·발행 시점·조회일·근거 위치를 기록한다. 확인할 수 있는 범위에서 원문이나 발췌와 출처를 보존한다. 읽지 못한 자료와 검색 결과의 요약을 직접 확인한 근거처럼 쓰지 않는다.
주장별로 직접 확인한 사실, 자료 사이의 차이, 미확인, 영상에서 허용할 재현, 넣으면 안 되는 요소를 구분한다. 설명용 재현과 실측 복원을 구분하고, 불확실한 숫자·경로·단일 원인을 확정하지 않는다. 화면에 그릴 수 없는 주장은 빼거나 표현 수위를 낮춘다.

3. 설계
핵심 질문과 결론 사이를 시각적 사건으로 연결한다. 먼저 보이는 것, 가려진 것, 카메라가 움직인 뒤 드러나는 것, 관객이 알게 되는 내용을 정한다. 설명 대본부터 길게 쓰지 않는다.
각 장면에 목적, 대상 상태, 구도와 촬영 거리·높이·각도, 전경·중경·배경, 카메라 경로, 가속·감속과 관찰 시간, 대상의 실제 동작, 광원 방향·빛의 성질·색감·재질, 음향 의도, 짧은 발화 또는 침묵 창, 자막이 가리지 않을 공간을 기록한다.
장면끼리 거리·높이·이동 방향·전경·시각 사건을 대조해 비슷한 구도가 반복되지 않게 한다. 매번 회전하거나 가속하는 방식 대신 속도 장면과 안정적인 관찰 장면을 교차한다. 빠른 카메라 때문에 설명할 대상이 보이지 않으면 감속하거나 샷을 나눈다. 영상미는 '영화처럼' 같은 추상어 대신 실제 생성 명령으로 옮길 수 있는 조건으로 쓴다.
반복 등장해 외형을 유지해야 할 대상과 일회성 배경을 나눈다. 필요한 캐릭터의 수·이름·역할·불변 특징을 먼저 안내한다. 캐릭터 기준 이미지, 장면 원화, 생성 클립, 편집 구간을 구분해서 수량과 근거를 정한다. 여러 시점이 필요하다는 이유만으로 캐릭터를 중복 등록하지 않는다.
장면을 구성한 뒤 각 사건의 공개 시간, 관찰 시간, 예상 발화와 침묵으로 잠정 길이를 계산한다. 잠정 편집 길이와 생성 클립의 요청 길이를 구분하고, 실제 원화·영상·음성을 받은 후 바뀔 조건을 남긴다. 일반적인 권장 초수를 먼저 정해서 장면을 억지로 끼워 넣지 않는다.
생성 이미지에는 글자·라벨·선·화살표를 그리게 하지 않는다. 이후 편집에서 설명이 나타날 위치와 대상을 가리지 않을 여백만 설계한다. 동적 자막의 최종 효과와 시간은 실제 영상·음성에 맞춰 후반 단계에서 정한다.

4. 인계
현재까지 사용자가 선택한 내용만 확정으로 표시한다. 질문·결론·제목, 출처와 사실 한계, 장면 카드, 반복 대상, 원화·영상 수량, 잠정 길이, 참조 관계, 남은 선택과 미확인을 제작용 입력으로 묶는다.
캐릭터 외형을 유지하기 위한 참조와 장면 구도를 이어 붙이기 위한 참조를 구분한다. 시작·끝 원화의 연속성이 확인되기 전에는 한 클립으로 연결된다고 단정하지 않는다. 실제 원화나 영상이 들어오면 영향을 받은 수량·참조·시간만 갱신하고 좋은 결과는 보존한다.
현재 Flow가 지원하는 모델·화면비·출력 개수·해상도와 참조 기능은 다음 제작 단계에서 실제 설정을 확인할 항목으로 남긴다. 지금 지원 여부나 생성 성공을 꾸며 쓰지 않는다.

산출물과 재개
프로젝트의 planning 폴더에 소재선택.md, 출처와표현한계.md, 장면설계.md, 수량과시간.md, 제작인계.md를 소작업에 맞춰 작성·갱신해. 기존 내용은 필요한 부분만 갱신하고 결정 이유와 미확인을 보존해. 자료마다 출처와 기준 시점을 남겨.
재개할 때는 이 파일들을 읽고 마지막 완료 소작업, 확정 선택, 미완료, 다음 행동 하나를 알려줘. 계획이 있다는 이유로 생성·다운로드·재생이 끝났다고 하지 마.

보고와 외부 행동
사용자에게는 존댓말로 이번 작업 / 고려 사항 / 산출물 / 다음 인계를 짧게 보고해. 일상적인 선택은 최선안을 추천하고, 소재 변경처럼 사용자의 의도가 필요한 선택만 물어봐.
계정 로그인, 유료 생성, 실제 Flow 등록·생성·재생성, 다운로드 조작, 업로드·공개 전환은 수행하지 마. 이 스킬은 기획까지만 맡는다.

만든 뒤 파일 위치와 현재 환경의 실제 호출법을 짧게 알려주고 멈춰줘. 아직 소재 조사는 시작하지 마.
~~~

## P16-05 · 설명보다 먼저 보이는 사건을 배치합니다

입력 대상: **현재 프로젝트의 AI**

~~~prompt
book-shorts-plan의 '설계'를 실행해줘. 저장된 소재 선택과 출처와표현한계를 읽고 현재 선택한 소재를 9:16 세로 영상으로 설계해줘.

먼저 중심 질문에서 결론까지 관객이 알아야 할 시각적 사건을 정해줘. 각 장면에서 처음 보이는 것, 카메라가 움직인 뒤 드러나는 것, 새로 이해할 것을 연결해. 첫 장면에 핵심 사건의 일부를 훅으로 쓰는 안도 비교해서 추천하되 답을 처음부터 전부 설명하지 마.

각 장면에 구도·각도·거리, 전경과 시차, 카메라 경로와 가속·감속·관찰 시간, 대상 동작, 광원과 색감·재질, 짧은 말 또는 침묵, 음향 의도, 자막 여백을 써줘. 움직임과 빛은 해당 장면의 정보가 잘 보이는 이유를 함께 적어. 비슷한 구도나 같은 속도의 회전·단순 확대를 반복하지 마. 사실 조건과 물리적 관계도 고려해줘.

함선 사례라면 막힌 물길 → 숲속 선체 → 육상 운반 → 항만 안쪽 → 우회 결론이 이해의 뼈대야. 저수면 접근, 나무 전경을 지나 선체 공개, 상승하는 공간 공개, 받침을 보는 저각, 항만에서 후퇴하는 구도를 후보로 검토해. 다른 소재라면 이 지형과 장비를 넣지 말고 그 소재의 질문을 보여 주는 공간과 움직임으로 바꿔줘.
~~~
