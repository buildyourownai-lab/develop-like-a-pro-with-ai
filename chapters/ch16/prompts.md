
~~~prompt

'우주에서 로켓은 무엇을 미는가'라는 질문 하나에 답하도록 구성해.

발사장→엔진 아래→점화→상승→구름 위→단 분리→우주 전경→
내부 구조→가스 배출과 두 힘→넓은 우주로 이어지는 시각 시나리오를 써줘.
한 컷에서 다음 컷으로 갈 때 새로 보게 될 것과 시선의 연결을 적어.
단 분리 자체를 배기가스 추진의 설명으로 쓰지 마.
탱크의 위치만 보고 물질을 임의로 배정하지 마.

사실, 첫 화면의 호기심, 장면의 차이, 설명 가독성, 제작 난점을 검토해.
참고 영상이 있으면 실제 볼 수 있었던 범위만 비교하고,
어떤 도구로 만들었는지 화면만 보고 단정하지 마.
수정한 구성과 남은 불확실성을 보여주고 내 확인을 기다려.
~~~

## P16-04 · 3. 물체·배경·조명을 정하고 기준 이미지를 만듭니다

~~~prompt
승인한 시각 시나리오를 기준 이미지 제작안으로 바꿔줘.
각 장면마다 물체 형태·재질, 공간과 배경, 구도·거리·렌즈감,
빛의 방향·색온도·명암, 색감, 설명용 여백을 구체적으로 적어.
외형 정본과 참조 이미지를 정하고 단계별 기체 상태를 구분해.

먼저 이미지 생성 서비스의 현재 모델·장당 출력 수·비율·해상도,
비용, 워터마크와 상업적 이용 조건을 실제 화면·공식 안내로 확인해.
확인일과 미확인을 남기고 예상 총량을 보여줘.
내가 허용한 비용 범위가 없으면 유료 생성 직전에 확인을 받아.

이미지는 번호별 독립 9:16 자산으로 만들고 한 장에 여러 컷을 넣지 마.
일괄 입력을 지원하면 각 번호의 독립 출력 여부부터 확인해.
한 장을 먼저 확인하고 승인된 설정으로 나머지를 진행해.
정확한 한글 설명·선·화살표는 원화에 생성하지 마.
완성 후 실제 파일과 번호를 대조하고 누락·중복·형태 차이를 보고해.
~~~

## P16-05 · 4. 실제 이미지에 맞춰 스토리보드를 고칩니다

~~~prompt
만든 실제 이미지와 승인한 시나리오로 스토리보드를 작성해줘.
번호별 실제 파일/자산 ID와 판본, 대상의 시작 상태·동작·끝 상태,
카메라의 시작·이동·감속·체류·끝, 다음 컷의 시선 연결을 적어.

설명은 후합성이지만 지금 설계해. 각 점의 부착 대상, 선이 나올 방향,
짧은 문구와 언어, 등장→추적/체류→퇴장, 가려짐 때의 처리를 정해.
글자가 움직임을 가리지 않게 여백과 읽을 시간을 확보해.
힘은 엔진이 받는 힘과 가스가 받는 힘을 서로 다른 대상에 붙이고,
같은 크기·반대 방향으로 동시에 표시해. 시점이 바뀌면 축을 보정해.

효과음·원본 배경음·말 없는 순간도 적어.
구도 반복, 물리적 순서, 잘못된 단정, 추적 난점을 검토하고 고쳐.
계획한 사용 시간과 모델 원본 생성 길이는 별도 열로 적어.
실제 모델 지원 길이를 아직 확인하지 않았다면 확정하지 마.
스토리보드를 보여주고 영상 생성은 기다려.
~~~

## P16-06 · 5. 가장 어려운 영상과 설명부터 시험합니다

~~~prompt
지금 사용할 영상 서비스의 실제 모델·지원 길이·출력 수·비율,
원본 해상도와 업스케일 여부, 크레딧·워터마크·상업 이용 조건을 확인해.
확인한 화면/공식 안내와 날짜를 기록하고 원본 총량·예상 비용을 보여줘.
유료 실행은 내가 허용한 범위 안에서만 해.

일괄 생성 전에 카메라 이동과 대상 추적이 어려운 대표 한 컷을 골라줘.
승인한 이미지를 시작 프레임으로 쓰고 영상은 글자·숫자·자막·라벨·
설명선·화살표·로고 없이 만들어. 내레이션·대사도 생성하지 마.
자연스러운 효과음과 은은한 환경음은 허용하되 큰 음악을 강제하지 마.
카메라와 물체·배경의 움직임을 각각 구체적으로 지시해.

그 클립에 임시 점·선·짧은 문구를 실제로 합성해 추적과 가독성을 시험해.
정지화면만으로 움직임 성공을 판정하지 마. 짧은 재생본을 보여줘.
대상 이탈·가려짐·글자 겹침이 있으면 보정 방식을 비교하고,
내가 대표 영상과 설명을 확인한 뒤 나머지 생성으로 넘어가.
~~~

## P16-09 · 8. 확정된 화면에 맞춰 대본과 음성을 만듭니다

~~~prompt
컷별 발화 시작/끝과 말 없는 여백, 화면과 대응하는 내용을 보여줘.
영어판을 만들면 직역보다 같은 화면 안에서 읽히는 자연스러운 문장으로 써.
먼저 내가 대본을 확인하게 하고 아직 음성은 생성하지 마.

대본 승인 뒤 AI Studio 브라우저의 현재 음성 모델·Charon 선택과
이용 조건을 확인해. API 호출로 임의 전환하지 마.
음성을 생성하고 실제 길이·발음·존댓말·문장 끝 잘림을 확인해.
직접 듣지 못한 경우 청취 완료라고 하지 말고 내가 들을 파일을 제시해.
~~~

## P16-10 · 9. 움직이는 점·선·설명과 소리를 합칩니다

~~~prompt
확정 영상·대본·음성으로 동적 설명과 소리를 합성해줘.
한글을 정확히 그릴 수 있는 편집 레이어를 쓰고 생성 영상에 글자를 맡기지 마.
점→선 확장→짧은 문구→추적/체류→퇴장의 순서를 컷 안에서 조절해.
실제 영상에서 부착 위치를 측정하고 흔들림·가려짐·화면 이탈을 보정해.

엔진이 받는 앞 방향 힘과 가스가 받는 뒤 방향 힘은 동시에 등장시켜.
같은 크기의 반대 화살표를 서로 다른 물체에 붙여.
가스 라벨은 가스, 엔진 라벨은 엔진을 가리키게 하고 글자와 선을 겹치지 마.
시점이 바뀌면 엔진 축을 기준으로 방향을 다시 맞춰.

원본 효과음·은은한 배경음은 살리고 내레이션을 가리는 구간만 조절해.

마지막에는 주황색 바가 늘어나고 문구가 페이드인되게 하되
마지막 말과 소리가 끊기지 않게 해. 위아래 앱 UI와 썸네일 잘림을 고려해.
선택한 언어판을 출력하고 실제 길이·해상도를 확인해.
추가 언어판을 요청했다면 각각 별도 출력·검수해.
내가 전체 합성본을 보고 듣기 전에는 최종 검수 완료로 쓰지 마.
~~~

## P16-11 · 10. 커버를 고르고 다음 제작에 쓸 기록을 남깁니다

~~~prompt

선택한 배경에 읽기 쉬운 큰 질문과 짧은 분류 라벨을 배치해.
위아래 UI·가운데 썸네일 크롭을 고려하고 실제 크기로 확인하게 해.
언어별 제목·설명·참고 출처도 영상 파일과 같은 납품 폴더에 정리해.
아직 업로드하지 마.

이번 제작을 다음에도 반복할 역할별 프로젝트 스킬 7개로 정리해줘.
소재 탐구→조사·시나리오→장면 설계→영상 제작→게시 준비→
최종 검수·업로드→성과 복기의 역할과 입력·산출물·넘어갈 조건을 나눠.
현재 도구가 지원하는 위치·형식과 실제 발견 여부를 확인해.
각 스킬에 같은 제작 절차와 승인 질문을 반복해서 넣지 마.
검수 모드와 게시 모드는 분리하고 검사 통과를 업로드 허가로 쓰지 마.
실제 게시 전에는 성과 수치를 만들지 말고 복기 방법만 준비해.

원화·영상은 Google Flow, 음성은 AI Studio 브라우저 Charon을 기준으로 해.

이번 로켓의 16장·81초·모델명은 사례 설정으로 분리해.

이미지·영상에 실제 입력한 프롬프트와 순서, 수정 이유, 자산 대응표,
원본·선택 구간·설명 좌표·대본·음성·소리·커버·출력 명령을 보존해.
설정과 파일 해시, 도구 버전, 사용 조건의 확인일도 기록해.

기록만 있는 것과 실제 재생성·렌더로 확인한 것을 구별해.
~~~
