# 10장. 이 회사는 최근 무엇을 공시했을까?

## 이 장을 시작할 때

[Study AI Lab MCP 연결](https://www.studyailab.com/develop/mcp#connect) 후 개발 AI에게 **“10장 시작해”**라고 요청하세요. 별도 튜터 설치는 필요하지 않습니다. AI가 현재 장·판본·작업 폴더를 확인하고 다음 행동 하나를 안내합니다. 앞 장까지 만든 `ai-stock-briefing`과 그 확인 결과를 이어갑니다. 현재 장의 선행 조건을 대조하고 필요한 기능만 추가합니다.

요청문·힌트 조회는 실행이나 완료 확인과 다릅니다. 실제 작업과 진도는 내 컴퓨터에서 확인하며, 필요한 [로컬 지원 파일](https://www.studyailab.com/develop/mcp#support-files)의 명령 옵션은 AI가 처리합니다. 아래 기존 검증 기록은 새 MCP 경로의 장별 전체 재현 완료를 뜻하지 않습니다.

## 이 장에서 만드는 것

10장에서는 9장에서 만든 ai-stock-briefing에 공시를 붙입니다. 금융감독원 전자공시시스템
DART의 OpenDART에서 회사가 직접 제출한 자료를 가져와, 주가 차트와 같은 기간에 회사가
무엇을 발표했는지 한 화면에서 보고 필요하면 DART 원문까지 내려갑니다.

이 장에서 확인하는 것은 여섯 가지입니다.

| 무엇 | 어떻게 확인하나 |
|---|---|
| 최근 공시부터 본다 | 종목 화면에서 최근 공시 5건과 조회 기간, 그 기간의 전체 건수가 함께 보이는지 확인합니다 |
| 수백 건을 나눠 본다 | 전체 공시 화면에서 한 페이지에 100건씩, 페이지를 넘기며 그 기간의 공시를 모두 볼 수 있는지 확인합니다 |
| 공식 유형으로 좁혀 본다 | 정기공시·주요사항보고·지분공시 같은 OpenDART 공식 유형과 각 유형의 실제 건수를 확인합니다 |
| 차트에서 공시 시점을 본다 | 최근 1년 차트에 정기공시와 주요사항보고의 시점만 표시되고, 표식을 눌러 접수일과 보고서명을 확인합니다 |
| 원문까지 내려간다 | 보고서명을 눌러 실제 DART 원문이 새 창에서 열리는지 확인합니다 |
| 0건과 실패를 구분한다 | 공시가 없는 경우와 OpenDART 요청이 실패한 경우가 화면에서 다르게 표시되는지 확인합니다 |

공시는 계속 새로 접수되므로 화면의 건수는 실행하는 날에 따라 달라집니다. 완료 기준은
건수가 같은지가 아니라, 공시 목록의 조회 기간이 주가 차트와 같은지와 그 기간에서 빠진
공시가 없는지입니다.
