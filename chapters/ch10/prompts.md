~~~

## P10-07 · 최근 공시부터 보여줍니다

~~~prompt
SK하이닉스 상세 화면에는 최근 공시 5건만 먼저 보여줘.

영역 제목은 「이 회사 관련 공시」로 적어줘. 각 공시는 접수일, 보고서명,
제출인을 위에서 아래로 읽는 구분선 목록으로 만들고, 보고서명은 검정색으로
보여줘. 이 영역은 흰색 배경, 검정 보고서명, 회색 날짜·제출인·구분선으로
구성하고 다른 강조색은 쓰지 마.

이 기간의 전체 공시 건수와 조회 기간을 함께 적고, 전체 목록으로 들어갈
수 있는 길을 만들어줘.

공시가 없거나 OpenDART 요청이 실패한 경우를 구분해 알려줘. 공시 요청이
실패해도 기존 주가 화면은 그대로 볼 수 있게 해줘.
~~~

## P10-08 · 수백 건은 나눠서 살펴봅니다

~~~prompt
전체 공시 화면을 따로 만들어줘.

종목 상세의 「이 회사 관련 공시」와 같은 흰 카드, 검정 보고서명, 회색
구분선, 글자 간격을 유지해줘. 전체 화면에는 여기에 공시 유형 필터와 페이지
이동을 더해줘.

조회 기간은 최근 공시와 같은 최근 1년으로 맞추고, 그 기간의 공시는 하나도
빼지 말고 모두 보여줘.

한 화면에 수백 건을 모두 쌓지 말고 한 페이지에 100건씩, OpenDART가
제공하는 페이지 정보에 맞춰 나눠 보여줘.

접수일, 보고서명, 제출인, 비고를 표시하고, 보고서명을 누르면 실제 DART
원문이 새 창에서 열리게 해줘.
~~~

## P10-09 · 공시 유형으로 좁혀 봅니다

~~~prompt
최근 1년 공시는 목록에서 하나도 빼지 말고 모두 보존해줘.

공시를 좁혀 볼 때는 OpenDART의 공식 공시 유형을 사용하고, Claude가
제목을 보고 중요도를 판단하거나 새로운 분류를 만들지 마.

각 유형의 실제 건수를 함께 보여줘.
~~~

## P10-10 · 차트에는 두 유형만 표시합니다

~~~prompt
최근 1년 주가 차트에 공시 시점을 표시해줘.

전체 공시는 목록에 모두 보존하고, 차트에는 OpenDART 공식 공시 유형
가운데 정기공시와 주요사항보고만 표시해줘.

AI가 중요도를 판단하거나 순위를 매기지 않았다는 기준도 화면에 밝혀줘.

가격 차트를 가리지 않도록 공시 시점은 차트 아래의 별도 띠에 표시해줘.
휴장일 공시는 그 뒤 첫 거래일 위치에 묶고, 표식을 누르면 접수일·공시
유형·제출인·보고서명과 DART 원문 링크를 글자로 확인할 수 있게 해줘.
~~~

## P10-11 · 화면에서 DART 원문까지 확인합니다

~~~prompt
모든 공시의 접수번호로 실제 DART 원문 주소를 만들어줘.

보고서명을 누르면 원문이 새 창에서 열리게 하고, 링크 모양만 확인하지
말고 실제로 접근되는지도 검사해줘.
~~~

## P10-12 · 새로 붙인 공시 기능을 확인합니다

~~~prompt
이번 장에서 추가한 공시 기능을 Test해줘.

SK하이닉스 종목코드와 OpenDART 고유번호 연결, 공시 응답 처리, 최근
공시와 전체 목록, 공식 유형 필터, 여러 페이지 이동을 확인해줘.

같은 날짜의 여러 공시가 사라지지 않는지, 공시가 없는 경우와 API 오류를
구분하는지도 확인해줘.

차트에는 정기공시와 주요사항보고만 표시되는지, DART 원문 링크가 실제로
열리는지, API Key가 브라우저에 노출되지 않는지도 검사해줘.

9장에서 만든 검사도 함께 다시 돌려줘. 공시가 붙으면서 기존 검사가 깨지지
않았는지 확인하고, 깨졌다면 원인을 찾아 고쳐줘.
~~~
