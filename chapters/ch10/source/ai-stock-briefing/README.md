# 10장을 끝낸 상태의 ai-stock-briefing

## 이 Source는 언제 사용하나요?

금융위원회 공식 주식 데이터로 시장 화면과 종목 화면, 최근 1년 차트를 만들고, 금융감독원
OpenDART의 공시까지 붙여 DART 원문으로 내려갈 수 있는 상태입니다. 정답지가 아닙니다.

책을 따라가다 막혔을 때 순서는 이렇습니다.

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

이 Source는 마지막 단계입니다. 앞의 두 방법으로도 이어갈 수 없을 때, 11장부터 계속
진행하기 위해 사용합니다. 이 Source로 시작하면 10장의 남은 실습은 건너뛰게 됩니다.

9장부터 10장까지 만든 파일이 모두 들어 있습니다. 6~8장의 아파트 프로젝트는
chapters/ch08/source/apartment-explorer에 따로 있습니다.

인증키는 들어 있지 않습니다. .env.local.example을 보고 자기 인증키를 넣으면 됩니다.
주식시세정보와 지수시세정보, KRX상장종목정보 세 API가 공공데이터포털 인증키 하나를 함께
사용하고, 공시는 OpenDART 인증키를 따로 사용합니다.

이 프로젝트의 Test는 실제 금융위원회와 OpenDART 응답까지 확인하므로, Test를 실행하려면
자기 인증키가 필요합니다.

인증키는 서버에서만 사용합니다. 브라우저가 받아가는 파일에는 인증키 이름도 값도 들어가지
않습니다.

## Claude Code에서 이어서 사용하기

이 폴더를 Claude Code에서 열고 그대로 입력하면 됩니다.

```text
이 폴더는 책 10장을 끝낸 상태의 프로젝트야.
실행에 필요한 환경이 준비되어 있는지 확인하고, 없으면 준비해줘.
내 인증키를 넣을 자리를 알려주고 Test를 실행해서 결과를 보여줘.
그다음 브라우저에서 시장 화면과 종목의 공시까지 확인할 방법도 알려줘.
```

## 내 결과와 달라도 괜찮습니다

같은 요청문을 입력해도 파일 이름과 함수 이름, 화면 모양은 달라집니다. 화면에 보이는
숫자는 실행하는 날의 데이터에 따라 달라집니다. 기준은 코드가 같은지가 아니라 10장의 완료
조건을 만족하는지입니다.

- 시장 화면에서 기준일과 코스피·코스닥 현황, 상승률 상위와 하락률 상위를 봅니다.
- 등락률 순위 목록이나 검색으로 종목 화면에 들어가 현재가, 기준가 대비 등락,
  시가·고가·저가, 거래량, 거래대금을 봅니다.
- 종목의 최근 1년 흐름을 시가·고가·저가·종가와 거래량으로 봅니다.
- 종목 화면에서 최근 공시와 조회 기간, 그 기간의 전체 건수를 함께 봅니다.
- 전체 공시 화면에서 100건씩 페이지를 넘기고 OpenDART 공식 유형으로 범위를 좁힙니다.
- 최근 1년 차트에서 공시 시점을 보고, 보고서명을 눌러 DART 원문을 엽니다.
- 공시가 0건인 경우와 요청이 실패한 경우가 화면에서 다르게 보입니다.
- 모든 숫자에 기준일이 붙어 있고, 순위를 어떤 조건으로 뽑았는지 화면에 적혀 있습니다.
- 인증키가 브라우저로 전달되지 않습니다.
