# 4장을 끝낸 상태의 movie-report

## 이 Source는 언제 사용하나요?

실습이 잘 진행되는 동안 먼저 열어보는 정답지가 아닙니다.

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

앞의 두 방법으로도 해결되지 않았을 때 사용하는 마지막 수단입니다. 이 Source로 다시
시작하면 4장의 남은 실습은 건너뛰고 5장부터 이어가게 됩니다.

## 무엇이 들어 있나요?

4장까지 만든 것이 모두 들어 있습니다. 이 폴더 하나만 받아서 바로 실행할 수 있습니다.

| 파일 | 무엇인가 |
|---|---|
| CLAUDE.md | 영화 보고서 프로젝트에서만 참고하는 규칙입니다 |
| docs/debug-procedure.md | 문제가 생겼을 때 따르는 자세한 확인 절차입니다 |
| build_movie_report.py | movie-report-2024.xlsx를 만듭니다 |
| source/kobis-2024-source.xlsx | 보고서를 만들 때 사용한 KOBIS 데이터를 작업 당시 상태로 남긴 기준 자료입니다 |
| tests/conftest.py | 보고서와 기준 자료를 열어주는 준비 코드입니다 |
| tests/test_movie_report.py | 완료 조건 일곱 가지를 확인하는 자동 검사 8개입니다 |

모든 프로젝트에서 참고하는 공통 작업 원칙은 이 폴더에 없습니다. 그 파일은 특정
프로젝트가 아니라 여러분의 컴퓨터 전체에 자리하는 ~/.claude/CLAUDE.md이고, 4장의
요청문으로 여러분이 직접 만들게 됩니다.

## Claude Code에서 이어서 사용하기

이 폴더를 여러분의 movie-report 폴더에 합친 뒤 Claude Code에 아래 요청문을 넣으면
됩니다.

```text
이 폴더는 4장을 끝낸 상태의 movie-report야.
보고서를 만들고 자동 검사를 실행해서 결과를 알려줘.
하나라도 실패하면 완료했다고 말하지 말아줘.
```

공통 작업 원칙은 이 폴더에 없으므로, 아직 만들지 않았다면
[chapters/ch04/prompts.md](../../prompts.md)의 첫 요청문을 먼저 사용하세요.

## 내 결과와 달라도 괜찮습니다

**두 CLAUDE.md와 절차 문서의 문장이 여기와 다른 것이 정상입니다.** 세 파일은 여러분이
타이핑한 것이 아니라 조건을 말하면 Claude Code가 쓴 것입니다. 그래서 소제목과 문장이
각자 다릅니다.

기준은 문서 모양이 이 Source와 같은지가 아닙니다. 어디서나 지킬 원칙이 공통 쪽에,
영화 보고서에만 필요한 규칙이 프로젝트 쪽에 나뉘어 있고, 두 곳에 같은 내용이 중복돼
있지 않으면 제대로 만들어진 것입니다.

## 검증 결과

저자가 3장 도착점에서 시작해 4장 요청문만으로 두 번 돌렸고, 두 번 모두 두 규칙이
중복 없이 나뉘었으며 제목 변경만 요청했는데도 Claude가 검사 8개를 스스로 실행해 전부
통과를 확인한 뒤 완료를 보고했습니다. 이 폴더를 빈 폴더에 단독으로 놓고 실행해 보고서
생성과 검사 8개 통과까지 확인했습니다. 자세한 근거는
[verification/chapter-04/](../../../../verification/chapter-04/)에 있습니다.
