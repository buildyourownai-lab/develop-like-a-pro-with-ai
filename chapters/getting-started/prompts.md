## 먼저 자료를 받고 연결합니다

~~~prompt
공식 자료에서 내 책 판본에 맞는 튜터와 장별 참고 자료를 확인해줘.
https://www.studyailab.com/develop/getting-started
출처와 판본, 받은 자료의 SHA-256을 공식 배포 기록과 대조해줘.
확인하지 못한 자료나 배포 기록은 만들어 채우지 말고 알려줘.

현재 사용 중인 AI와 작업 폴더를 확인하고, 튜터 연결에 필요한 변경을 먼저 보여줘.
범위를 확인한 뒤 제공된 설치 도우미로 이 폴더에만 book-tutor를 연결해줘.
다른 AI의 설정, 기존 사용자 지침, 실습 코드와 진도는 보존해줘.

이 환경에서 검증된 경우에만 Study AI Lab MCP도 연결할지 물어봐.
내가 선택하면 기존 연결을 먼저 확인하고, 등록 위치와 변경 내용을 보여준 뒤 적용해줘.
같은 공식 연결은 재사용하고 다른 서버나 설정은 덮어쓰지 마.
지원이 확인되지 않거나 연결이 실패하면 튜터와 웹 자료로 계속할 수 있게 해줘.

연결을 적용한 뒤 새 대화를 여는 방법과 확인할 요청을 알려줘.
새 대화를 열기 전에는 실제 동작을 확인했다고 말하지 마.
새 대화에서 튜터 규칙을 실제로 읽는지와 MCP 공개 자료 조회가 되는지 각각 확인해줘.
MCP를 선택하지 않은 경우에는 튜터만 확인해줘.
개인 파일·키·진도를 MCP로 보내지 말고, 예제 프로그램이나 Hook은 실행하지 마.
실습 결과물을 미리 만들거나 완성본으로 덮어쓰지 마.
~~~

## 준비됐다는 말보다 연결 상태를 봅니다

~~~prompt
book-tutor의 연결 상태를 확인해줘.
현재 작업 폴더, 튜터 규칙 파일, 자료의 판본과 실제 위치를 알려줘.
장별 설명·완성 소스·화면 예시는 있는 것과 빠진 것을 따로 보여줘.
파일을 확인한 것과 프로그램을 실제 실행한 것도 구분해줘.
지금은 실습 프로그램을 실행하거나 결과물을 만들지 마.
~~~
