# 8장. 누구나 사용할 수 있는 아파트 찾기 서비스를 만듭니다

## 이 장을 시작할 때

[Study AI Lab MCP 연결](https://www.studyailab.com/develop/mcp#connect) 후 개발 AI에게 **“8장 시작해”**라고 요청하세요. 별도 튜터 설치는 필요하지 않습니다. AI가 현재 장·판본·작업 폴더를 확인하고 다음 행동 하나를 안내합니다. 앞 장에서 만든 `apartment-explorer`의 파일과 확인 결과를 이어갑니다. 필요한 계정·권한·실제 응답은 현재 환경에서 확인합니다.

요청문·힌트 조회는 실행이나 완료 확인과 다릅니다. 실제 작업과 진도는 내 컴퓨터에서 확인하며, 필요한 [로컬 지원 파일](https://www.studyailab.com/develop/mcp#support-files)의 명령 옵션은 AI가 처리합니다. 아래 기존 검증 기록은 새 MCP 경로의 장별 전체 재현 완료를 뜻하지 않습니다.

## 이 장에서 만드는 것

7장까지 만든 아파트 찾기는 내 컴퓨터에서만 동작했습니다. 8장에서는 여기에 브라우저에서
쓰는 화면을 붙이고, 인터넷 주소를 가진 웹서비스로 공개합니다. 주소를 아는 사람은 누구나
자기 브라우저에서 조건을 입력해 아파트를 찾을 수 있게 됩니다.

이 장에서 확인하는 것은 세 가지입니다.

| 무엇 | 어떻게 확인하나 |
|---|---|
| 브라우저에서 조건을 입력해 결과를 본다 | 화면에서 지역과 면적, 실거래 가격, 생활조건을 입력하고 아파트 찾기를 누릅니다 |
| 두 개의 키가 브라우저로 나가지 않는다 | Claude가 브라우저의 파일·응답에 실제 키 값이 없는지 검사한 결과를 확인합니다 |
| GitHub에 올리면 공개 주소가 자동으로 갱신된다 | 안내 문구 하나를 고쳐 올리고 공개 주소에서 바뀐 것을 확인합니다 |

검색 결과는 실행하는 날의 실거래 데이터에 따라 달라집니다. 완료 기준은 결과 건수가 아니라,
내 컴퓨터에서 확인한 것과 같은 규칙이 공개된 주소에서도 그대로 동작하는지입니다. 아직 확인하지 못한 단지가 남았다면, 확인된 단지가 0개여도 정상 검색 0건과 구분합니다.
