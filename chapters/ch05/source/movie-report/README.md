# 5장을 끝낸 상태의 movie-report

## 이 Source는 언제 사용하나요?

실습이 잘 진행되는 동안 먼저 열어보는 정답지가 아닙니다.

```text
디버깅 → 내 정상 기록으로 복구 → 장별 Source로 재시작
```

앞의 두 방법으로도 해결되지 않았을 때 사용하는 마지막 수단입니다. 5장은
movie-report 프로젝트의 마지막 장이므로, 이 Source로 다시 시작하면 PART 1을 마친
것으로 보고 6장의 새 프로젝트로 넘어가면 됩니다.

## 무엇이 들어 있나요?

1장부터 5장까지 만든 것이 모두 들어 있습니다. 이 폴더 하나만 받아서 바로 실행할 수
있습니다.

| 파일 | 무엇인가 |
|---|---|
| CLAUDE.md | 영화 보고서 프로젝트에서만 참고하는 규칙입니다 |
| docs/debug-procedure.md | 문제가 생겼을 때 따르는 자세한 확인 절차입니다 |
| build_movie_report.py | movie-report-2024.xlsx를 만듭니다 |
| source/kobis-2024-source.xlsx | 보고서를 만들 때 사용한 KOBIS 데이터를 작업 당시 상태로 남긴 기준 자료입니다 |
| tests/conftest.py | 보고서와 기준 자료를 열어주는 준비 코드입니다 |
| tests/test_movie_report.py | 완료 조건 일곱 가지를 확인하는 자동 검사 8개입니다 |
| notes/next-ideas.md | 5장에서 되돌리지 않고 남긴 메모입니다 |
| .gitignore | Git 기록에서 제외할 임시 파일을 적어둔 파일입니다 |

Git 기록 자체는 이 폴더에 없습니다. Git 기록은 여러분의 컴퓨터에서 여러분의 이름으로
남기는 것이고, 5장의 요청문으로 직접 만들게 됩니다. 모든 프로젝트에서 참고하는 공통
작업 원칙도 이 폴더에 없습니다. 그 파일은 여러분의 컴퓨터 전체에 자리하는
~/.claude/CLAUDE.md입니다.

## Claude Code에서 이어서 사용하기

이 폴더를 여러분의 movie-report 폴더에 합친 뒤 Claude Code에 아래 요청문을 넣으면
됩니다.

```text
이 폴더는 5장을 끝낸 상태의 movie-report야.
보고서를 만들고 자동 검사를 실행해서 결과를 알려줘.
하나라도 실패하면 완료했다고 말하지 말아줘.
```

Git으로 돌아갈 기준을 아직 남기지 않았다면
[chapters/ch05/prompts.md](../../prompts.md)의 두 번째 요청문을 이어서 사용하세요.

## 내 결과와 달라도 괜찮습니다

**두 CLAUDE.md와 절차 문서, 메모의 문장이 여기와 다른 것이 정상입니다.** 여러분이
타이핑한 것이 아니라 조건을 말하면 Claude Code가 쓴 것이기 때문입니다.

Git 기록의 개수와 각 기록의 설명도 다릅니다. 기준은 기록의 모양이 아니라, Test를
통과한 상태만 기록으로 남았는지와 필요한 파일만 골라 되돌릴 수 있는지입니다.

## 검증 결과

저자가 4장 도착점에서 시작해 5장 요청문만으로 두 번 돌렸고, 두 번 모두 Test 8개
통과를 확인한 뒤 정상 기준을 기록했고, 보고서만 그 기준으로 되돌리고 새 메모는 남기는
데까지 갔습니다. 이 폴더를 빈 폴더에 단독으로 놓고 실행해 보고서 생성과 검사 8개
통과까지 확인했습니다. 자세한 근거는
[verification/chapter-05/](../../../../verification/chapter-05/)에 있습니다.
