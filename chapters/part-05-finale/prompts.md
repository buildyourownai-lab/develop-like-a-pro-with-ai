# PART 5 마무리 · 복사용 요청문

## P-PART05-01

입력 대상: 현재 프로젝트의 AI

~~~prompt
이번 영상에서 배운 판단 순서로 새 소재를 기획하고 싶어.

먼저 새 프로젝트가 독립된 작업 공간인지 확인해줘.
내가 공개 본문으로 만든 book-shorts-plan을 가져왔다면 현재 AI가 지원하는
프로젝트 로컬 위치에 등록하고 실제로 발견되는지 확인해줘.
없으면16장의 생성명세를 내가 전달할 때까지 멈춰줘.
스킬 미지원이면 저장한 공개 명세 파일을 읽는 방법을 알려줘.
다른 사람의 비공개 스킬·계정·이전 진행 상태는 가져오지 마.

준비되면 book-shorts-plan으로 호기심과 시각적 사건이 강한 소재를 추천해줘. 실제 조사 가능한 근거, 카메라가 공개할 공간과 움직임, 반복 등장 대상, 음악과 효과음의 가능성을 함께 비교해줘.

지난 영상의 장수와82초를 그대로 적용하지 말고 새로운 이야기 구성을 본 뒤 수량과 잠정 길이를 산정해. 기존 프로젝트와 원본은 바꾸지 마. 내가 소재와 제목을 선택할 후보까지 보여주고 멈춰줘.
~~~

## P-PART05-02

입력 대상: 현재 프로젝트의 AI

~~~prompt
다음19장은 댓글 조회와 답글 초안 준비를 배우려는 거야.
새18장에서는 완성 파일과 게시 자료만 만들었고 OAuth나 업로드는 필수로 하지 않았어.

내 채널에서 댓글을 허용한 기존 영상이 있는지 내가 알려줄 정보를 먼저 정리해줘.
없으면 새 영상을 게시할지 내 선택을 기다려. 댓글 조회 실습에 필요한
Google Cloud/YouTube API 인증과 Gemini API 준비는 별도로 점검해줘.
기존 프로젝트가 있다고 가정하거나 다른 프로젝트의 인증 파일을 복사하지 마.

현재 지원되는 공식 준비 경로와 내가 할 로그인/승인을 알려줘.
Secret과 토큰은 대화나 공개 파일에 넣지 말고 로컬 설정으로만 다뤄줘.
아직 실제 업로드·댓글 전송·자동화 활성화는 하지 마.
읽기와 초안까지만 진행할 수 있도록 준비된 것/없는 것/다음 행동 하나를 알려줘.
~~~
