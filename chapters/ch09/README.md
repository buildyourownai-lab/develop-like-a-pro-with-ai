# 9장. 국내 증시와 궁금한 종목을 한눈에 봅니다

## 이 장을 시작할 때

[Study AI Lab MCP 연결](https://www.studyailab.com/develop/mcp#connect) 후 개발 AI에게 **“9장 시작해”**라고 요청하세요. 별도 튜터 설치는 필요하지 않습니다. AI가 현재 장·판본·작업 폴더를 확인하고 다음 행동 하나를 안내합니다. 책 작업 공간에 `ai-stock-briefing`을 만들고 이 장의 공식 데이터 준비부터 진행합니다. 이전 프로젝트는 보존합니다.

요청문·힌트 조회는 실행이나 완료 확인과 다릅니다. 실제 작업과 진도는 내 컴퓨터에서 확인하며, 필요한 [로컬 지원 파일](https://www.studyailab.com/develop/mcp#support-files)의 명령 옵션은 AI가 처리합니다. 아래 기존 검증 기록은 새 MCP 경로의 장별 전체 재현 완료를 뜻하지 않습니다.

## 이 장에서 만드는 것

9장에서 새 프로젝트 ai-stock-briefing을 시작합니다. 금융위원회가 공공데이터포털에 공개한
주식시세정보와 지수시세정보, KRX상장종목정보로 최근 시장이 어땠는지 보고, 궁금한 종목의
가격과 지난 1년의 흐름까지 한곳에서 확인하는 화면을 만듭니다.

이 장에서 확인하는 것은 네 가지입니다.

| 무엇 | 어떻게 확인하나 |
|---|---|
| 시장 전체를 한 화면에서 본다 | 기준일과 코스피·코스닥 현황, 상승률 상위와 하락률 상위가 함께 보이는지 확인합니다 |
| 궁금한 종목으로 들어간다 | 등락률 순위를 누르거나 종목명·종목코드로 검색해 종목 화면까지 갑니다 |
| 지난 1년의 흐름을 본다 | 종목 화면의 일봉 차트에서 시가·고가·저가·종가와 거래량을 확인합니다 |
| 숫자에 기준일이 붙어 있다 | 화면의 모든 숫자에 며칠 기준인지가 함께 표시되는지 확인합니다 |

화면에 보이는 숫자는 실행하는 날에 제공된 데이터에 따라 달라집니다. 완료 기준은 숫자가
같은지가 아니라, 언제 기준인지 알 수 있고 어떤 조건으로 고른 것인지 화면에서 설명되는지입니다.

종목코드 끝자리와 종목명의 `스팩`으로 구분했다면 공식 분류를 조회한 결과와 구분합니다.
Claude에게 공식 분류와 대조한 범위와 미확인 범위를 확인하고, 제외한 종목 수와 집계 대상 수도 대조합니다.
