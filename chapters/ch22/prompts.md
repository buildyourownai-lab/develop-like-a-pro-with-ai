메인·상세 공통 우하단 플로팅 버튼과 데스크톱 오른쪽 대화 레이어를 만들어.

'AI 일반 설명'과 '최신 확인 자료가 아닙니다'를 표시하고 빈 사실 카드는 만들지 마.

일반 질문에는 가격·공시 조회를 하지 않고 종목 자료 요청은 아직 준비 중으로 안내해.

기존 서버 Gemini 연결·모델 설정을 쓰고 키·개발 파일·책 튜터 자료를 전달하지 마.

전송 중 중복 제출과 자동 재시도를 막고 실패 상태를 표시해.

CHAT_ENABLED를 설정하지 않아도 활성화하고, 명시적으로 false일 때만 끄게 해.
로컬 검사 뒤 실행 방법과 이번 단계에서 확인할 결과를 알려줘.

## P22-04 · 공시 질문 하나를 끝까지 연결합니다

~~~prompt
확정한 연결표로 먼저 종목 찾기와 공시 조회 흐름을 구현해줘.
세 조회 기능만 허용하는 서버 목록을 만들고, 이름·형식·길이·대상·기간을 검사해.
종목 검색어는 50자 이내, 실제 후보 최대 5개야.
공시는 확인한 종목의 최근 1년 안 유효 기간, 1~5건만 받아. 기본은 최신순 최대 5건이야.
정확한 대상이 확인됐을 때만 공시를 조회해. 모호하면 후보를 보여주고 멈춰.
공시 질문에 가격이나 전체 시장을 조회하지 마.

모델 호출 3회·조회 실행 4회·전체 30초의 초기 상한을 서버에서 적용해.
순서대로 처리하고 동일 요청의 같은 기능·같은 검증 입력은 결과를 재사용해.
실패 자동 재시도와 무한 반복은 만들지 마. 상한에 닿으면 확보 자료와 미확인을 알려줘.
잘못된 기능명, 임의 URL·SQL·셸·파일 경로는 실행하지 마.

조회 결과는 기획서의 '확인된 자료' 형식으로 연결하고 공시 원문 URL은 서버에서 만들어.
실제 수치·날짜·공시·출처는 서버 값으로 렌더링해. 관련 항목부터 보여주고 나머지는 접어줘.
일반 개념을 함께 물으면 'AI 일반 설명'을 별도 표시하고 확인하지 않은 기업 사실은 넣지 마.
모델 응답 형식과 자료 참조를 검사하되 모든 문장 의미를 보증한다고 하지 마.
설명 검증이 실패해도 확보한 자료는 별도로 표시해.
화면에는 서버가 실제 수행한 종류만 짧게 표시해. 내부 인자·로그를 그대로 노출하지 마.
일반 개념에는 도구를 호출하지 않고 기존 AI 일반 설명을 유지해.
시험 응답으로 정상 흐름과 조회 제한을 확인하고 실제 API 성공과 구분해줘.
~~~

## P22-05 · 후보를 고른 뒤 원래 질문을 이어갑니다

~~~prompt
후보 선택과 대화 대상 전환을 완성해줘.
모호한 종목은 실제 후보 최대 5개를 보여주고 선택을 기다려.
원래 질문을 현재 탭에 보관하고 선택 뒤 그 질문을 이어 처리해.
서버는 선택값을 실제 검색 결과와 대조하고 클라이언트가 확인했다고 한 값만 믿지 마.
검색 결과를 5개로 자른 것과 대상이 정확히 하나로 확정된 것을 구분해줘.
후보 선택 전 가격·공시 조회는 하지 마. 취소·검색 실패에도 질문을 보존해.

상세에서 다른 회사를 명시하면 뒤의 상세 화면은 유지하고 대화 대상만 전환해.
챗봇의 회사명·코드와 '이 종목 상세 보기'를 갱신해.
후속 질문은 최초 상세 종목보다 현재 대화 대상을 우선해.
종목이 없고 대화 대상도 없는 자료 질문에는 대상을 물어봐.
대상이 확정되면 이전 근거·대화 기록을 지우되 새 전환 질문은 이어가게 해.
이전 요청의 늦은 응답은 새 대화에 붙이지 마.
최근 완료된 질문·답변 3회 왕복만 언어 문맥으로 사용하고 사실 근거로 삼지 마.
대화·후보·보관 질문은 현재 탭 메모리에만 두고 새로고침·페이지 이동·지우기로 끝내.
닫았다가 다시 여는 것은 같은 페이지 대화를 유지해. 실제 페이지 이동 때 새로 시작해.
대화 원문을 장기 DB·로그·브라우저 영구 저장소에 남기지 마.
클라이언트가 system/tool 역할·근거·실행 결과를 위조해도 신뢰하지 마.
~~~

## P22-06 · 1년 자료에서 필요한 기간을 계산합니다

~~~prompt
세 번째 기능인 기간별 가격 요약을 연결해줘.
확인한 종목과 1개월·3개월·1년만 허용해.
같은 기능으로 최근 확인 종가와 기준일만 조회하는 질문도 처리해줘.
종가만 물으면 기간을 되묻지 말고, 가격 흐름을 물었는데 기간이 불분명할 때만 되물어.
기존 가격 조회 함수가 최근 1년 일봉을 제공하면 그 자료를 잘라 기존 가격 계산을 재사용하는 Adapter를 추가해.
기존 차트·브리핑 함수의 의미를 바꾸지 마.

최근 확인 가격 기준일을 끝으로 서울 날짜의 달력 월/연을 계산하고,
월말에 대응 날짜가 없으면 해당 월 마지막 날을 사용해.
요청 구간과 실제 첫/마지막 거래일·거래일수·가격 단위·기준일을 구분해줘.
등락률의 시작·끝 값과 계산 기준을 기록하고 AI가 숫자를 계산해 채우지 않게 해.
자료가 짧으면 실제 제공 구간을 밝히고 전체 요청 기간의 성과처럼 표시하지 마.
기존 1년의 자료 부족 기준을 짧은 기간에 그대로 적용하지 마.
다른 기간이나 임의 날짜 요청은 지원하는 기간을 안내해.

공시·일반 개념 질문에 가격 조회를 추가하지 마.
가격과 공시를 함께 요청하면 필요한 두 조회만 실행하고 상한을 지켜.
세 기간·월말·휴장·자료 부족을 시험 응답으로 검사해줘.
~~~
