# 저자 공개 전 확인

1. 전22장의 튜터 문서와 같은 판본의 원고인지 확인합니다.
2. 공식 장별 소스 경로·기준 커밋과 START/FINISH의 실제 내용·범위를 결합합니다. 미래 기능이 START에 들어 있지 않은지 봅니다.
3. 이미 공개 가능한 이미지·디자인 자료만 연결합니다. 실제 키·Token·독자 상태·로컬 경로 파일은 올리지 않습니다.
4. 지원할 Claude Code/Codex 버전에서 설치→새 세션→힌트→진도→완료 확인을 실제 실행합니다. 힌트 전후 실습 파일이 같아야 합니다.
5. 실제 API·계정·기기 검증과 합성 테스트를 구분합니다. 원고에서 약속하는 공개 전환의 동일 ID 재개를 실제 소스와 대조합니다.
6. 실패·누락을 공개 안내에 명시하고 확인되지 않은 지원을 보장하지 않습니다. 공식 자료를 수정한 날짜와 실제 실습 확인일은 따로 기록합니다.
