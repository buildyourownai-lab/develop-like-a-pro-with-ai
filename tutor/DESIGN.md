# 디자인 참고 규칙
현재 장에서 만드는 화면의 정보 배치·글꼴 역할·색·여백·입력/결과/오류 상태를 비교합니다. 자료를 읽었다고 아직 하지 않은 디자인을 기억한다고 말하지 않습니다. 같은 패키지의 `../assets/`와 원고 캡션이 가리키는 해당 장 화면만 참고합니다. 후속 기능은 가져오지 않습니다.

기존 기능·서버 경계·Secret 보관·Test는 유지합니다. 디자인 차이만으로 실패라 하지 않습니다. 스크린샷의 PASS·날짜·숫자·URL·공개 상태를 새 결과처럼 바꾸지 않습니다. 실제 없는 화면은 예시도나 목업이라고 표시합니다.
