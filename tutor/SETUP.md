# 튜터 연결하기

책의 튜터를 지금 열어 둔 작업 폴더에 연결합니다. 책 준비편의 요청문 하나를 Claude에 붙여넣으면 아래 순서로 진행됩니다.

## 먼저 확인할 것

Claude에서는 **Code 탭 또는 Claude Code CLI**에서 작업 폴더를 열어야 합니다. 일반 Chat에 폴더를 연결한 화면에서는 튜터를 연결할 수 없습니다.

## 연결 순서

1. 공식 자료 저장소에서 `tutor` 폴더만 작업 폴더 안의 `book-reference` 폴더에 받습니다. 저장소 전체를 받지 않습니다. `git clone --depth 1 --filter=blob:none --sparse`로 받은 뒤 `git sparse-checkout set tutor`를 쓰면 됩니다. 받기 전에 위치를 사용자에게 보여 주고, 이미 받은 자료가 있으면 그대로 씁니다. 그 안의 `tutor` 폴더에 `install_tutor.py`가 있습니다. 작업 폴더의 경로와 `install_tutor.py`의 위치를 사용자에게 알려 줍니다.
2. `python3`으로 실행합니다. 안 되면 `python`으로 실행합니다. 둘 다 없으면 설치하지 않고 사용자에게 알립니다.
3. 먼저 `--apply` 없이 실행해서 만들거나 바꿀 파일 목록을 보여줍니다.
4. 사용자가 승인하면 같은 명령에 `--apply`를 붙여 실행합니다.
5. 바뀐 파일 목록, 새 대화를 여는 방법, 새 대화에서 입력할 문장을 알려줍니다.

아래의 `작업/폴더/경로`는 실제 작업 폴더의 전체 경로로 바꿔서 입력합니다. 사용하는 AI 하나만 연결합니다. `--tool`을 생략하면 두 AI가 모두 연결되므로 반드시 붙입니다.

```sh
python3 install_tutor.py --project "작업/폴더/경로" --tool claude
python3 install_tutor.py --project "작업/폴더/경로" --tool claude --apply
```

Codex를 쓰면 `--tool claude` 대신 `--tool codex`를 씁니다.

연결로 바뀌는 곳은 작업 폴더 안의 다음 파일뿐입니다.

- Claude: `.claude/skills/book-tutor/SKILL.md`, `CLAUDE.local.md`의 관리 블록, `.claude/settings.local.json`(한글이 깨지지 않게 `PYTHONUTF8=1` 한 줄만 더함. 기존 설정은 그대로 둠)
- Codex: `.agents/skills/book-tutor/SKILL.md`, `AGENTS.md`의 관리 블록
- 공통: `.gitignore`의 줄 추가(Claude는 세 줄, Codex는 두 줄), `.book-tutor-state/`

기존 지침, 다른 AI의 설정, 실습 코드, 진도는 바꾸지 않습니다. 예제 프로그램이나 Hook은 실행하지 않습니다.

## 승인 창이 나올 때

수동 모드에서는 명령을 실행하기 전에 승인 버튼이 나옵니다. 작업 폴더 안의 위 파일을 만드는 명령이면 승인합니다. 공식 자료 저장소를 받는 `git clone` 명령도 승인합니다. 그 밖에 작업 폴더 밖을 바꾸는 명령, 프로그램 설치, 다른 주소에 접속하는 명령은 승인하지 않습니다. 1장부터 프로젝트 폴더를 열고 진행하면 튜터가 같은 위치의 `book-reference` 폴더를 읽으려고 승인을 요청할 수 있습니다. 읽기만 하는 요청이므로 허용합니다.

자동 모드가 설치 명령을 막으면 같은 명령을 반복하거나 돌아가지 않습니다. Code 화면의 권한 모드를 **수동(Manual)**으로 바꾸고 다시 승인합니다. Desktop 앱에서는 이 문장대로 권한 모드만 바꾸면 되고, 아래 명령은 입력하지 않습니다. 터미널의 Claude Code CLI를 쓰는 경우에만 `/exit`로 나온 뒤 같은 폴더에서 이어갑니다.

```sh
claude --permission-mode manual --continue
```

## 새 대화에서 확인하기

연결이 끝나면 Claude에서 새 대화를 엽니다. 같은 작업 폴더에서 입력합니다.

```text
1장 시작해.
```

새 대화를 열기 전에는 튜터가 동작한다고 말하지 않습니다. 파일이 만들어진 것만으로 확인을 대신하지 않습니다.

## 막혔을 때

- 환경이 되는지 안 되는지는 판단하지 말고, 화면에 나온 오류 메시지를 그대로 사용자에게 알려 줍니다.
- 개인 계정으로 로그인했는데 회사 인증 화면이 뜨면 다시 설치하지 않고 사용자에게 알립니다. 인증 키와 토큰은 답변에 출력하지 않습니다.
- 설치가 중간에 멈췄으면 같은 명령을 다시 실행해도 됩니다. 이미 만든 파일은 사용자가 고친 것이 있으면 덮어쓰지 않습니다.

## 제거하기

튜터는 관리 Skill과 `BOOK-TUTOR-MANAGED` 블록을 확인해 제거합니다. 사용자가 고친 부분이 있으면 먼저 보여 주고 지우지 않습니다. `.gitignore`에 더해진 두 줄(`/.book-tutor-state/`, `/CLAUDE.local.md`)은 사용자가 직접 확인한 뒤 지웁니다. 다른 사용자 규칙, 실습 코드, 진도는 남깁니다. `.book-tutor-state/` 전체를 삭제하지 않습니다.
