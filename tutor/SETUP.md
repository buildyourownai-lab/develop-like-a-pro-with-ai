# 튜터와 선택 MCP를 함께 준비하기

준비 요청 하나로 현재 작업 폴더의 책 튜터를 연결하고, 지원하는 환경에서는 Study AI Lab MCP도 선택해서 추가할 수 있습니다. 튜터는 프로젝트의 실습과 실제 근거 확인을 돕고, MCP는 공개 자료 조회와 투자 계산을 제공합니다. 설치를 함께 안내해도 개인 진도나 프로젝트 파일을 서버로 옮기지는 않습니다.

## 시작 화면과 실행 권한을 먼저 확인합니다

Claude에서는 **Code 탭 또는 Claude Code CLI**로 현재 실습 폴더를 엽니다. 일반 Chat에 컴퓨터 폴더를 연결하는 것만으로 Code 환경이 되는 것은 아닙니다. Chat의 별도 실행 공간에서 만든 경로를 Mac의 튜터 설치 경로로 사용하지 않습니다.

설치 명령은 변경 내용을 확인하고 정상 권한 요청으로 승인합니다. 자동 모드가 설치 미리보기나 적용을 차단하면 같은 명령을 반복하거나 권한 검사를 우회하지 않습니다. Code 화면의 권한 모드를 **수동(Manual)**으로 바꾸고 실행 명령을 확인해 승인합니다. CLI에서는 먼저 `/exit`로 나와 같은 실습 폴더에서 아래 명령으로 이어갑니다. 2.1.296에서 확인한 옵션이며 다른 버전은 `claude --help`를 확인합니다.

```sh
claude --permission-mode manual --continue
```

개인 계정으로 로그인했는데 회사 인증이 뜬다면 다시 설치하지 않습니다. 앱 로그인과 Code의 모델 제공자 설정은 다를 수 있습니다. `claude auth status --json`에서 인증 방식과 제공자를 확인하고, 회사용 Bedrock·게이트웨이 설정이 적용되는 위치를 먼저 찾습니다. 회사 공통 설정 삭제나 변경은 사용자의 명시적 선택을 받아 진행하며, 인증 키·토큰은 답변이나 공유 기록에 출력하지 않습니다. 개인 인증이 정상인 CLI를 이미 따로 사용하고 있다면 해당 실행 옵션을 유지합니다. 조직의 관리 정책은 임의로 우회하지 않습니다.

## 책의 준비 요청으로 시작합니다

[Development Lab 준비편](https://www.studyailab.com/develop/getting-started#preparation-requests)의 ‘먼저 자료를 받고 연결합니다’를 현재 실습 AI에 입력합니다. 요청문은 책 준비편이 정본이며 웹에는 같은 문구를 제공합니다. 같은 공식 판본의 `tutor/release-manifest.json`으로 튜터 텍스트 파일의 SHA-256을 대조합니다. 사용하는 AI와 폴더, 받은 자료의 판본을 확인한 뒤 변경할 내용을 먼저 봅니다.

1. 튜터 설치 도우미로 사용하는 AI의 프로젝트 지침과 book-tutor Skill만 연결합니다.
2. 설치한 AI의 새 대화를 열어 튜터 지침의 실제 경로와 현재 장의 자료를 읽을 수 있는지 확인합니다. 설치 단계에서는 새 대화를 여는 방법과 확인 요청을 안내하며, 그 전에는 실제 동작 확인으로 표시하지 않습니다. 파일 생성만으로 연결 확인을 대신하지 않습니다.
3. 현재 환경이 지원 목록에 있고 MCP를 선택한 경우에만 등록 범위와 기존 연결을 확인합니다.
4. MCP 도구 목록과 공개 자료 한 건을 조회합니다. 개인 파일·키·진도를 시험 요청에 넣지 않습니다.
5. 결과를 ‘튜터 확인 / MCP 확인·미선택·실패·미확인’으로 나눠 보고 실습을 시작합니다.

MCP를 생략하거나 연결하지 못해도 정상 튜터와 Development Lab 요청문 복사로 이어갈 수 있습니다. 투자 독자는 [Investment Lab](https://www.studyailab.com/invest/parts/1)의 질문을 평소 쓰는 ChatGPT에 복사하고 웹 계산 도구를 사용합니다. 튜터나 MCP 설치는 필요하지 않습니다. AI 대화에서 자료·계산 도구를 직접 호출하고 싶을 때만 [선택 연결 안내](https://www.studyailab.com/mcp#chatgpt)를 확인합니다.

## 직접 CLI를 사용할 때만 등록합니다

아래 명령은 CLI에서 실행하는 등록 방법입니다. 2026년 10월 12일 macOS 개인 Pro 계정의 Desktop Code에서 설치된 튜터 읽기와 MCP 실제 자료 조회를 확인했습니다. 일반 Chat 폴더 연결과는 구분하며 다른 계정·운영체제에 결과를 그대로 적용하지 않습니다. 최신 실제 확인 범위는 [공통 안내의 지원표](https://www.studyailab.com/mcp#support)에서 확인합니다.

### Claude Code CLI

튜터는 현재 프로젝트에 사용하는 도구만 연결합니다. 받은 자료의 tutor 폴더에서 실행합니다.

```sh
python3 install_tutor.py --project "/실제/실습/프로젝트" --tool claude
```

미리보기 범위를 확인한 뒤 같은 명령에 `--apply`를 추가합니다. MCP 등록 전 현재 실습 프로젝트에서 기존 studyailab 등록을 확인합니다.

```sh
claude mcp get studyailab
```

같은 공식 주소의 HTTP 등록이 있다면 재사용합니다. 같은 이름이 다른 서버를 가리키면 덮어쓰지 않고 충돌을 해결합니다. 다른 이름으로 같은 주소가 등록돼 있는지도 확인합니다. 신규 등록일 때만 현재 프로젝트에서 local 범위를 명시합니다.

```sh
claude mcp add --scope local --transport http studyailab https://mcp.studyailab.com
```

local은 프로젝트별 개인 연결 범위이며 파일만 프로젝트에 저장한다는 뜻은 아닙니다. user는 사용자 공통, project는 공유 프로젝트 범위이므로 목적 없이 바꾸지 않습니다. 새 대화의 `/mcp`와 실제 공개 자료 조회로 연결을 확인합니다.

### Codex CLI

튜터 설치에는 `--tool codex`를 사용합니다. MCP 등록은 기존 설정과 등록 목록을 먼저 확인합니다.

```sh
codex mcp list
```

같은 공식 연결은 재사용합니다. 새로 등록할 때는 다음 명령을 사용합니다.

```sh
codex mcp add studyailab --url https://mcp.studyailab.com
```

이 CLI 등록은 기본 개인 설정 `~/.codex/config.toml`에 영향을 줍니다. 튜터의 프로젝트 설치와 범위가 다릅니다. 프로젝트 전용 설정으로 바꾸는 방법은 해당 버전의 실제 지원을 확인해야 합니다. 사용하는 AI만 설정하고 새 대화에서 각각 실제 동작을 확인합니다.

## 실패·재시도·제거

튜터가 준비됐지만 MCP에 연결하지 못한 경우 튜터를 삭제하지 않습니다. 등록 성공과 도구 호출 성공은 별개입니다. 실패 원인이 지원 환경·이름 충돌·서버 통신 가운데 어디인지 확인하고 해당 단계만 재시도합니다. 정상 등록을 반복 생성하지 않습니다.

이번 준비에서 새로 만든 등록만 이름·주소·범위를 대조해 제거할 수 있습니다. 기존 연결을 재사용했다면 이번 설치의 제거 대상이 아닙니다. 사용자 변경이 있다면 자동으로 덮어쓰거나 삭제하지 않습니다. 제거가 다른 프로젝트에 영향을 줄 수 있는 개인 공통 범위인지 먼저 확인합니다.

Claude CLI local 등록을 직접 제거할 때는 등록했던 프로젝트에서 실행합니다.

```sh
claude mcp remove --scope local studyailab
```

Codex CLI 등록 제거는 개인 공통 설정에 영향을 줍니다.

```sh
codex mcp remove studyailab
```

튜터는 관리 Skill과 BOOK-TUTOR-MANAGED 블록을 확인해 제거합니다. 다른 사용자 규칙·실습 코드·진도는 남깁니다. `.book-tutor-state/` 전체를 삭제해 설치 흔적을 정리하지 않습니다.

설치기는 파일별 원자적 교체를 사용하고 처리한 쓰기 실패에서 설치 메타데이터까지 복구합니다. 강제 종료·지속적인 파일시스템 장애·동시 편집까지 모든 파일의 일괄 원복을 보장하는 것은 아니며 빈 디렉터리가 남을 수 있습니다.

## 판본과 기록

튜터 자료의 위치·판본과 MCP의 자료 판본을 확인합니다. 설치한 튜터 자료를 옮기면 Skill이 참조하는 경로가 달라질 수 있어 다시 연결해야 합니다. 원격 체크리스트를 로컬 완료 계약 대신 쓰지 않습니다. 학습 근거는 기존 프로젝트의 `.book-tutor-state/`, Lab 사용자 기록은 브라우저 localStorage에 유지됩니다.

서버 주소는 `https://mcp.studyailab.com`, 사람이 읽는 안내 주소는 `https://www.studyailab.com/mcp`입니다. MCP에는 별도 API 키가 필요 없으며 사용하는 AI 서비스의 계정 조건과 이용료는 별개입니다.
