# Study AI Lab MCP 연결하기

책의 요청문과 힌트를 지금 사용하는 개발 AI에서 찾아 쓰고, 실제 프로젝트의 근거로 진도를 확인하는 흐름입니다. 별도 튜터나 필수 Skill을 설치하거나 두 번째 MCP를 등록하지 않습니다. 원격 자료 연결과 내 컴퓨터의 로컬 점검은 준비하는 시점이 다릅니다.

책 준비편의 요청문을 순서대로 사용하세요. 이 문서는 그 요청을 처리할 AI와 독자가 함께 확인하는 연결 안내입니다. 터미널 명령이나 옵션을 외울 필요는 없습니다.

## 1. 현재 작업 폴더에서 연결합니다

[공식 연결 안내](https://www.studyailab.com/develop/mcp#connect)를 확인합니다. 책은 Claude Desktop의 Code 탭에서 실습합니다. 다른 개발 AI를 사용한다면 원격 MCP와 현재 프로젝트 범위 연결을 지원하는지 해당 도구의 공식 안내에서 확인합니다. 일반 대화의 파일 첨부와 프로젝트 파일을 다루는 개발 환경은 구분합니다.

연결 주소는 **https://mcp.studyailab.com**입니다. 준비편의 연결 요청문을 현재 작업 폴더에서 보냅니다. AI는 다음 순서로 진행합니다.

1. 현재 AI·작업 폴더·기존 MCP 등록을 확인합니다. 같은 공식 주소는 재사용하고, 같은 이름에 다른 주소가 있으면 덮어쓰지 않고 알립니다.
2. 새 등록이 필요하면 현재 폴더에 적용할 설정과 만들거나 바꿀 파일 목록을 먼저 보여줍니다. 이 범위로 연결할 수 없다면 개인·조직 전체 설정으로 임의 변경하지 않습니다.
3. 독자가 변경 범위를 확인하고 승인한 뒤 연결합니다. 기존 지침·다른 AI 설정·실습 코드·기록을 보존합니다. 로그인과 추가 인증은 공식 화면에서 사람이 직접 처리합니다.
4. 변경한 내용과 같은 폴더에서 새 대화를 여는 방법을 안내합니다. 등록 표시만으로 실제 자료 조회까지 성공했다고 말하지 않습니다.

지금은 Python을 설치하지 않아도 됩니다. 예제 프로그램을 실행하거나 실습 결과물을 미리 만들지 않습니다. 프로젝트 경로·개인 파일·진도·인증값은 원격 조회 요청에 넣지 않습니다.

## 2. 새 대화에서 실제 자료를 확인합니다

같은 작업 폴더에서 준비편의 자료 확인 요청문을 보냅니다. 개발책 1장의 공개 요청문 목록뿐 아니라 그중 하나의 본문·출처·자료 판본까지 가져오는지 확인합니다.

AI는 요청한 책과 장이 맞는지 확인하고, 원격 자료를 읽은 것과 현재 파일·실행 결과를 확인한 것을 나눠 설명합니다. 확인하지 못한 준비는 미확인으로 남기고 다음 행동 하나를 안내합니다. 이 단계에서는 프로그램을 설치하거나 보고서를 만들지 않습니다.

자료가 있다는 이유로 내 프로젝트가 준비됐거나 장이 끝났다고 판정하지 않습니다. 같은 대화에서 이미 확인한 장은 다시 묻지 않되, 새 대화에서 장을 알 수 없다면 먼저 확인합니다.

## 3. 1장에서 Python을 준비한 뒤 로컬 점검을 연결합니다

먼저 1장에서 `movie-report` 프로젝트를 만들고 Python과 openpyxl을 사용할 수 있는지 확인합니다. 그다음 같은 프로젝트에서 준비편의 **「Python 준비 뒤 로컬 점검과 재개를 준비합니다」** 요청문을 보냅니다.

[공식 지원 파일 안내](https://www.studyailab.com/develop/mcp#support-files)에서 받을 위치·고정 판본·무결성 확인 방법과 현재 제공 상태를 확인합니다. 확인할 수 없는 주소를 만들어 내려받거나 파일 검증에 실패한 코드를 실행하지 않습니다. 안내가 아직 준비되지 않았다면 로컬 점검은 미실시로 남기고 다음 행동을 알립니다. 공개 자료 조회와 웹 요청문 복사는 계속 사용할 수 있습니다.

AI는 다음을 확인합니다.

- 실제 사용할 Python과 현재 프로젝트를 확인합니다. Python이 없으면 임의 설치하지 않고 1장의 환경 준비로 안내합니다. MCP를 다시 등록하지 않습니다.
- 받은 파일의 책·판본·개정·파일 목록과 해시를 공식 기준에 대조합니다. 압축 파일을 받았다는 사실과 압축 해제·내용 검증·실행 승인은 서로 구분합니다.
- 현재 폴더에서 만들거나 바꿀 파일과 사용할 지원 도구를 먼저 보여줍니다. 독자가 승인한 범위만 준비하며 기존 지침·코드·작업 기록을 덮어쓰지 않습니다.
- 현재 장과 실제 근거·미확인·다음 행동을 내 컴퓨터에 기록하는 위치와 새 대화에서 읽는 방법을 안내합니다. 개인 파일·진도·인증값을 원격 MCP로 보내지 않습니다.

지원 파일은 같은 상품 흐름의 로컬 보조 도구입니다. 별도 튜터나 Skill을 설치하는 단계가 아닙니다. 이 도구를 받았다고 실습 프로그램의 실행이나 장 완료가 승인되는 것도 아닙니다.

## 4. 요청문 보기·실행·기록을 구분합니다

장 번호를 알려주고 장 시작·다음 요청문·한 단계 힌트·현재 진도·장 완료 확인을 자연어로 요청합니다. “다음 요청문 보여줘”에는 정본 요청문 하나와 입력 위치를 안내하고 실행하지 않습니다. 내용을 확인한 뒤 “진행해” 또는 “실행해”라고 요청하면 허용된 그 작업만 수행합니다. 힌트 요청만으로 파일을 바꾸거나 해답을 적용하지 않습니다.

원격 MCP는 공개 자료와 기준을 제공합니다. 실제 파일 확인과 프로그램 실행은 개발 AI가 기존 사용자·조직 지침과 승인 범위 안에서 맡습니다. 로컬 지원은 확인한 파일과 관측 기록으로 진도를 대조하며, 저장을 요청한 경우에만 로컬 기록을 추가합니다. 조회나 미리보기만으로 진도를 저장하지 않습니다.

관측 기록은 독립 실행 인증이 아닙니다. 실제 실행·사람의 확인·모의 검사를 구분하고, 근거가 없거나 실패·변경·만료된 항목을 완료로 세지 않습니다. 완성 Source와 화면 예시는 비교·복구용이며 내 작업 위로 미리 덮어쓰지 않습니다.

## 5. 다음 대화에서도 실제 상태를 확인합니다

작업을 마칠 때 현재 장·확인한 근거·남은 것·다음 행동을 로컬에 남기도록 요청합니다. 저장할 파일과 변경 범위를 확인하고 승인합니다.

새 대화나 새 프로젝트에서는 장 번호와 현재 폴더를 확인하고, 기록과 실제 파일이 여전히 맞는지 다시 살펴봅니다. 기록을 읽지 못하면 이전 진도를 추측하지 않습니다. 파일·실행 환경·계정 조건이 달라졌다면 관련 근거를 다시 확인합니다. 이전 대화의 실행 승인이 자동으로 이어지는 것은 아닙니다.

## 연결이 막혔을 때

[연결 복구 안내](https://www.studyailab.com/develop/mcp#recovery)를 확인합니다. 오류 메시지와 실제 사용하는 앱·현재 폴더를 구분해 원인을 좁히며, 인증값과 개인정보는 가립니다. 설치 반복·권한 확대·기존 파일 삭제로 우회하지 않습니다.

연결하지 못해도 [Development Lab](https://www.studyailab.com/develop)에서 장별 요청문을 복사해 본문 실습을 이어갈 수 있습니다. 자료 조회 실패와 Python 부재, 프로그램 실행 실패는 서로 다른 문제로 다룹니다.

## 확인된 범위

현재 새 통합 경로의 실제 연결과 대표 응답은 로컬 후보 서버에 연결한 Codex CLI에서 확인했습니다. 이는 Claude Desktop Code 탭의 실제 지원·Windows 동작·장별 전체 실습·외부 계정/API 성공·공개 운영 배포 완료를 뜻하지 않습니다. 공식 안내에서 현재 제공 상태를 확인하며, 확인하지 않은 환경을 지원 완료로 표시하지 않습니다.
