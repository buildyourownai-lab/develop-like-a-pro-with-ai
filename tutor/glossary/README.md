# 용어를 설명하는 순서

한 줄 뜻→현재 장에서 사용한 예→헷갈리는 것 하나 순서로 짧게 설명합니다. 더 자세한 설명은 사용자가 원할 때만 추가합니다. 용어를 묻는 것을 새 설치나 다음 장 실습 승인으로 해석하지 않습니다.

## API
프로그램이 다른 서비스와 정해진 방식으로 요청·응답을 주고받는 연결 방법.

## API Key
서비스 사용 자격을 확인하는 값. 안전한 입력 위치에 직접 넣으며 값은 공개하지 않습니다.

## 환경변수
코드와 별도로 실행 환경에서 이름으로 읽는 설정. 이름과 실제 값은 다릅니다.

## OAuth Token
사용자가 승인한 계정 권한을 요청에서 증명하는 비밀값. AI 사용량의 Token과 다릅니다.

## AI Token
AI가 읽고 생성하는 내용을 계산할 때 쓰는 단위. 인증값이 아닙니다.

## Test
정한 완료 조건을 반복 확인하는 검사. 검사하지 않은 전체 정확성을 보증하지 않습니다.

## Regression
수정 뒤 기존 기능까지 다시 확인하는 회귀 검사.

## START
그 장을 시작하는 기준 상태. 매번 내 프로젝트를 초기화하는 명령이 아닙니다.

## FINISH
그 장 완료의 비교·재개 기준 상태. 다음 장 기능을 앞당겨 가져올 근거가 아닙니다.

## Queue
아직 처리할 일을 보관하는 대기열. 실제 보존 여부는 기록으로 확인합니다.

## Worker
대기열에서 일을 가져와 실행하는 담당 프로그램.

## TTL
저장한 값을 재사용하는 유효시간. 최신성을 무조건 보증하는 값이 아닙니다.

## Cache
같은 조건에서 계산·생성한 결과를 일정 조건 동안 재사용하는 저장 방식.

## Database
자료를 구조적으로 저장하고 조회하는 곳.

## Commit
선택한 파일 변경을 Git 기록으로 남긴 한 지점.

## origin/main
마지막으로 가져와 알고 있는 원격 main의 추적 기록.

## Scope
외부 서비스에서 허용하는 API 권한 범위. 사용자의 행동 승인과 다릅니다.

## Production
실제 운영 배포 환경. 로컬·Preview와 설정이 다를 수 있습니다.

## Skill
반복할 일을 수행하는 안내와 자료의 묶음. 별도 보안 정책을 대신하지 않습니다.

## chapter.json
저자가 정한 장별 목표·준비·검증 규격. 독자의 완료 상태가 아닙니다.
## PART 6 개편판 추가 용어

### 함수 호출
AI가 사용할 기능과 입력을 제안하고 서버가 검사해 실행하는 방식. 모델의 말만으로 실행됐다고 보지 않습니다.

### 허용 목록
받아들일 함수 이름·입력 범위를 서버에 명시한 목록.

### 전송 결과 미확인
외부 작업이 실행됐는지 확정할 수 없는 상태. 실패로 가정해 자동 재전송하지 않습니다.

### 대화 맥락
지금 질문이 어떤 종목과 앞 대화에 이어지는지 정하는 범위. 장기 저장과는 다릅니다.

### 요청 제한
한 번과 일정 기간의 실행량을 제한하는 규칙. 모든 인프라 비용을 보장하는 장치는 아닙니다.
