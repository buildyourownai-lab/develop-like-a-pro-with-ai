# 21장. 내 주식서비스의 챗봇을 기획합니다 — 완료 확인 규격

이 문서는 현재 범위의 검사 기준이며 실행 성공 기록이 아닙니다. 범위 축소 후 독자 재현은 미실시입니다.

기존 주식서비스·실행 방법·화면과 검색·차트·공시·브리핑·Database·Cache의 재사용 대상을 기획서에서 확인합니다.

필수: 예 / 증거: file-inspection / 선행: 없음

## ch21-plan-build-v2-g02 · 기능과 경계

대표 질문·지원/제외 범위·확인된 자료와 AI 일반 설명을 정합니다. 일반 설명 표시만으로 특정 기업의 최신 사실을 허용하지 않습니다.

필수: 예 / 증거: file-inspection / 선행: ch21-plan-build-v2-g01

## ch21-plan-build-v2-g03 · 사용 흐름

메인 질문 시작·실제 종목 확인·후보 최대 5개·선택 전 조회 금지·원래 질문 보관·상세 기본 대상과 대화 전환·최근 3회 왕복·늦은 응답 차단을 설계합니다.

필수: 예 / 증거: file-inspection / 선행: ch21-plan-build-v2-g02

## ch21-plan-build-v2-g04 · 화면과 모바일

플로팅 위치·데스크톱 오른쪽 레이어·모바일 웹 큰 레이어·현재 대상·답변 순서·키보드·안전 여백·닫기·포커스 복귀를 기존 디자인과 대조합니다. 설계도를 실행 화면으로 표시하지 않습니다.

필수: 예 / 증거: file-inspection / 선행: ch21-plan-build-v2-g03

## ch21-plan-build-v2-g05 · 기존 함수 연결

세 조회 기능의 실제 함수·입력·결과·실패·Cache를 조사한 뒤 AI용 이름을 정합니다. 서울 날짜의 달력 1·3·12개월, 월말·실제 거래일·자료 부족을 정의하고 브리핑 Cache를 대화 저장소로 전용하지 않습니다.

필수: 예 / 증거: file-inspection / 선행: ch21-plan-build-v2-g04

필수: 예 / 증거: file-inspection / 선행: ch21-plan-build-v2-g05
