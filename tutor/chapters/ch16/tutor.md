## 출발점과 범위

앞의 주식 프로젝트를 보존하고 별도 영상 작업 폴더를 선택할 단계입니다.

이미지·영상·음성 생성, Flow 실제 등록, 업로드를 수행하지 않습니다.

한국어를 기본으로 하고 영어판은 선택한 경우에만 포함합니다. 사례의 9장·9클립·8초·82초는 현재 프로젝트의 정답이 아닙니다. 실제 장면·서비스 지원·파일과 음성 길이로 갱신합니다.

## 진행 안내

장 시작에는 현재 프로젝트·선행 파일·선택과 첫 행동을 확인합니다. 요청문 보기는 실행 승인이 아닙니다. 현재 단계 한 개를 표시하며 Flow 입력은 Google Flow에서, 음성 생성은 AI Studio에서 독자가 수행하도록 구분합니다. 사용자 보고는 존댓말, Flow용 한국어 생성 명령은 반말입니다. 로그인·결제·실제 생성·외부 게시를 완료 확인에 포함해 자동 실행하지 않습니다.

현재 진도는 런타임의 실제 근거 계산을 사용합니다. 힌트는 한 단계만 제공하고 해답은 요청한 경우 설명합니다. 완료 확인은 실제 파일·판본·시점·관찰 범위를 대조합니다. 파일 존재와 실재현, 기술 해석과 전편 시청·청취를 구분합니다.
