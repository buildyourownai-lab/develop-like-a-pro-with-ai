# 16장. AI와 YouTube 영상을 만듭니다 — AI가 읽는 수업 안내

목표의 정본은 `chapter.json`, 순차 요청문의 정본은 `prompts.md`입니다. 본문과 요청문 판본이 맞는지 확인한 뒤 현재 단계 하나를 안내합니다. 공개 자료에는 독자의 프로젝트만 다루며 저작 내부 기록·계정·개인 경로를 넣지 않습니다.

## 도착점과 준비

선택한 소재의 원화·영상·대본·음성과 동적 설명을 단계별 검수하여 최종 영상을 완성합니다.

현재 프로젝트는 `ai-shorts-maker`입니다. 주식 프로젝트를 보존하고 별도 ai-shorts-maker 폴더를 만들어 현재 프로젝트로 선택한 뒤 제작 목표를 정할 단계입니다.

언어만 먼저 선택하고 시청자 등급은 묻지 않습니다. 대중성을 기본으로 소재 후보를 비교한 뒤 독자의 선택을 기다립니다. 본문 로켓을 선택한 경우와 다른 소재를 선택한 경우를 구분하고, 다른 소재에16장 원화 수나81초를 강제하지 않습니다. 이미지·영상 생성 전에 각각 현재 모델·지원 길이·비율·출력 수·기본 해상도와 업스케일·워터마크·이용 조건·비용 및 이미 승인한 범위를 확인합니다. 새 구독·결제를 자동 선택하지 않습니다.

## 제작 순서

언어 → 소재 후보와 독자 선택 → 근거·이야기 → 시각적으로 다른 장면 → 이미지 생성 전 조건·승인 → 독립 원화 생성·검수 → 실제 이미지 대응 스토리보드 → 영상 생성 전 검수 → 대표 어려운 컷 → 승인 범위의 나머지 영상 → 다운로드 대조·연결 영상 확정 → 실제 길이에 맞춘 대본 확정 → TTS → 설명·음향 합성 → 전편 확인 → 커버·재사용 자료입니다.

Google Flow 이미지·영상과 Google AI Studio 브라우저 TTS를 기본 예시로 안내합니다. 실제 연결된 MCP·브라우저 프로필·로그인·지원 기능을 확인하며 브라우저 로그인과 API 인증을 혼동하지 않습니다. API와 별도 음악 다운로드는 선택 경로입니다. 현재 구독을 API 무료 사용 권리로 설명하지 않습니다. 로그인과2차 인증은 독자가 합니다. 다른 프로필의 빈 History를 기록 삭제로 단정하지 않습니다.

생성 전에 설명의 앵커·등장·추적·퇴장과 글자 여백을 설계하지만 정확한 글자·선·화살표는 후합성합니다. 좋은 원본 효과음과 은은한 배경음은 보존합니다. 원치 않는 생성 음성은 필요한 구간만 조정합니다. TTS 전에 한국어 전체 존댓말·사실·문장 길이를 검사하고, 생성 후 실제 발음과 종결을 듣습니다. 발화 자체를 자르거나 무조건 배속하지 않습니다.

## 튜터 응답과 완료

`장 시작`, `현재 진도`, `힌트`, `장 완료 확인`의 공통 계약을 유지합니다. 다음 요청문을 보여 달라는 요청은 실행 승인이 아닙니다. 현재 대기 중인 요청 한 개에 대한 명확한 실행 요청만 수행합니다. Claude와 Codex의 실제 Skill 호출 경로를 구분하며 존재하지 않는 `/` 명령을 있다고 안내하지 않습니다.

진도는 런타임 근거를 조회하고 추측하지 않습니다. 힌트는 한 단계만 줍니다. 확인 요청을 새 유료 생성·결제·업로드 허가로 해석하지 않습니다. 파일 존재·정적 검사·실제 실행·사람 관찰은 서로 다른 증거입니다. 필요한 구현 차이는 재현 근거로 반환하고 테스트·기준을 몰래 바꾸지 않습니다. START/FINISH는 현재 프로젝트를 덮어쓰는 기본 경로가 아닙니다. source-registry의 실제 확보 상태를 확인하고 예전 완성 소스를 새 로켓 구현으로 소개하지 않습니다.
