# 16장 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 다음 힌트에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 실제 수정·생성은 별도 실행 범위를 확인합니다.

## H16-01 · 생성이 멈춤

**1단계:** 로그인 성공과 생성 완료는 다릅니다.

**2단계:** 생성 상태·남은 이용량·다운로드 파일을 확인합니다.

**3단계:** 어느 장면의 후보가 아직 없는지 제작 기록과 비교합니다.

**해결 설명을 요청했을 때:** 미완성 단계를 해결한 뒤 다음 편집으로 넘어갑니다. 승인 없이 유료 요금제를 선택하지 않습니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H16-02 · 최종 영상이 어색함

**1단계:** 문제 장면과 시간부터 특정합니다.

**2단계:** 화면·음성·자막·전환 중 어느 요소인지 나눕니다.

**3단계:** 해당 입력 파일과 조립 순서·길이를 대조합니다.

**해결 설명을 요청했을 때:** 필요한 요소만 수정해 다시 조립하고 전체 재생합니다. 사용 조건을 확인하지 않은 음악으로 교체하지 않습니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H16-03 · 소재를 정하기 전에 생성하려 함

**1단계:** 지금 소재가 독자가 선택한 것인지 봅니다.

**2단계:** 언어와 대중적 후보 비교까지만 진행했는지 봅니다.

**3단계:** 후보의 근거·시각적 사건을 비교하고 독자의 선택을 기다립니다.

**해결 설명을 요청했을 때:** 선택한 소재의 근거와 장면 설계부터 진행합니다. 로켓의16장이나81초를 다른 소재에 그대로 복사하지 않습니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H16-04 · 배치 이미지가 콜라주이거나 비슷함

**1단계:** 결과가 번호별 독립 이미지인지 봅니다.

**2단계:** 장소·거리·시점·조명·행동이 실제로 다른지 비교합니다.

**3단계:** 장면별 파일 대응과 이미지 프롬프트의 독립 출력 지시를 대조합니다.

**해결 설명을 요청했을 때:** 필요한 장면만 다시 설계하고 비용·범위 승인 안에서 수정합니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H16-05 · 요청한 영상 길이가 지원되지 않음

**1단계:** 현재 계정의 실제 지원 길이를 봅니다.

**2단계:** 사용할 편집 구간과 원본 생성 길이를 나눕니다.

**3단계:** 현재 모델·출력 수·차감액을 확인하고 지원 길이 생성 후 트림 계획을 세웁니다.

**해결 설명을 요청했을 때:** 임의 모델 변경이나 중복 배치 없이 확인된 조건과 기존 승인 범위 안에서 진행합니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H16-06 · TTS 말투나 발음이 어색함

**1단계:** 문제 문장과 실제 음성 구간을 찾습니다.

**2단계:** 대본의 존댓말 종결과 실제 발화를 따로 비교합니다.

**3단계:** 영상 확정→대본 확정→TTS 순서와 생성된 WAV의 실제 길이를 확인합니다.

**해결 설명을 요청했을 때:** 잘못된 음성 구간만 수정하고 실제 청취 후 다시 합성합니다. 자동 전사만으로 통과시키지 않습니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H16-07 · 다른 브라우저에서 History가 없음

**1단계:** 현재 로그인 프로필과 서비스를 봅니다.

**2단계:** 작업했던 계정·프로젝트가 같은지 확인합니다.

**3단계:** 기존 다운로드와 자산 대응표에서 실제 파일을 찾습니다.

**해결 설명을 요청했을 때:** 빈 History를 삭제로 단정하지 않습니다. 확인된 기존 자산을 보존하고 승인 없이 재생성하지 않습니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.
