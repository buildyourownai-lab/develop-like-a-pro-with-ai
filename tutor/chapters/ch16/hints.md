# 16장. AI와 YouTube 영상을 만듭니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H16-01 · 생성이 멈춤

**1단계 — 방향:** 로그인 성공과 생성 완료는 다릅니다.

**2단계 — 범위:** 생성 상태·남은 이용량·다운로드 파일을 확인합니다.

**3단계 — 위치·원인 후보:** 어느 장면의 후보가 아직 없는지 제작 기록과 비교합니다.

**정답을 요청했을 때:** 미완성 단계를 해결한 뒤 다음 편집으로 넘어갑니다. 승인 없이 유료 요금제를 선택하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H16-02 · 최종 영상이 어색함

**1단계 — 방향:** 문제 장면과 시간부터 특정합니다.

**2단계 — 범위:** 화면·음성·자막·전환 중 어느 요소인지 나눕니다.

**3단계 — 위치·원인 후보:** 해당 입력 파일과 조립 순서·길이를 대조합니다.

**정답을 요청했을 때:** 필요한 요소만 수정해 다시 조립하고 전체 재생합니다. 사용 조건을 확인하지 않은 음악으로 교체하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
