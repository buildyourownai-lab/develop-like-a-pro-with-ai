# 16장 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 해답은 명시 요청 때만 설명하며 설명만으로 파일을 수정하거나 서비스를 실행하지 않습니다.

## H16-P5-01 · 소재가 있지만 화면이 단조로움

**1단계:** 중심 질문에 답하는 시각 사건을 찾습니다.

**2단계:** 카메라 이동 전후 새로 드러나는 대상을 봅니다.

**3단계:** 거리·높이·방향·전경과 관찰 시간을 장면별로 대조합니다.

**해결 설명을 요청했을 때:** 사건을 먼저 배치한 뒤 장면 카드를 수정합니다. 길이를 먼저 고정하지 않습니다.

## H16-P5-02 · 자산 수와 길이가 헷갈림

**1단계:** 반복 대상과 일회성 배경을 나눕니다.

**2단계:** 기준 이미지·원화·클립·편집 구간을 따로 셉니다.

**3단계:** 공개 시간·관찰 시간·발화와 침묵으로 잠정 길이를 계산합니다.

**해결 설명을 요청했을 때:** 수량과시간.md에 근거와 실제 제작 후 바뀔 조건을 기록합니다.
