# 2장. Claude가 제대로 만들었는지 확인합니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H02-01 · Test는 통과했는데 불안함

**1단계 — 방향:** 무엇과 무엇을 비교했는지 먼저 봅니다.

**2단계 — 범위:** 공식 웹 원본 대조인지 로컬 기준본 대조인지 구분합니다.

**3단계 — 위치·원인 후보:** 검사 대상의 연도·행 수·필드와 기준 파일 출처를 확인합니다.

**정답을 요청했을 때:** 확인하지 않은 항목에 별도 완료 조건을 세웁니다. 기존 PASS를 전체 정확성 인증으로 확대하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H02-02 · 권한 화면에서 막힘

**1단계 — 방향:** 반복 작업인지 외부 상태를 바꾸는지 구분하세요.

**2단계 — 범위:** 하려는 명령의 대상과 변경 범위를 읽습니다.

**3단계 — 위치·원인 후보:** 허용·확인·금지 중 어떤 수준인지 실제로 한 작업을 기준으로 판단합니다.

**정답을 요청했을 때:** 예상하지 않은 설치·삭제·외부 전송이면 멈춰 이유를 묻습니다. 전체 권한 해제를 정답으로 사용하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
