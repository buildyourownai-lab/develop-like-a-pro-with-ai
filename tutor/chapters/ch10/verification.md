# 10장. 이 회사는 최근 무엇을 공시했을까? — 완료 검증 규격

검증은 사용자 요청 범위의 확인입니다. 실제 게시·삭제·결제는 별도 명확한 행동 승인 없이 실행하지 않습니다. 증거를 확보하지 않은 것을 PASS로 입력하지 않습니다.

|목표|확인 기준|근거 종류|기대 결과|
|---|---|---|---|
|ch10-g01|OpenDART 인증키와 안전한 입력 위치 확인|human-observation|pass|
|ch10-g02|종목코드와 고유 기업코드 매핑 확인|test-run|pass|
|ch10-g03|조회 기간·최근·전체 공시를 구분|live-api, live-ui|pass|
|ch10-g04|공식 공시 유형으로 범위를 선택|test-run|pass|
|ch10-g05|같은 공시의 원문과 날짜를 연결|human-observation|pass|
|ch10-g06|공시 없음과 조회 실패 및 기존 기능 확인|test-run|pass|

## 다시 확인할 때
코드·실행 환경·대상·인증 설정이 바뀌었으면 관련 근거를 다시 확인합니다. 파일 해시로 감지하지 못하는 외부 정책·권한·키 변화는 사람이 알려야 합니다. 기존 기록을 덮어쓰지 않고 새 기록을 추가합니다.
