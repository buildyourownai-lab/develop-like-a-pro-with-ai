# 1장. 영화 흥행 기록으로 첫 Excel 보고서를 만들어봅니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H01-01 · 파일을 찾지 못함

**1단계 — 방향:** AI의 완료 문장 대신 실제 파일 위치를 확인하세요.

**2단계 — 범위:** 현재 선택한 프로젝트가 movie-report인지 봅니다.

**3단계 — 위치·원인 후보:** 생성된 .xlsx의 전체 경로와 마지막 실행 결과를 확인합니다.

**정답을 요청했을 때:** 파일이 있으면 그 파일 하나를 열고, 없다면 생성 단계의 오류부터 확인합니다. 작업 폴더를 임의로 바꾸지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H01-02 · 보고서 모양이 예시와 다름

**1단계 — 방향:** 먼저 필요한 정보가 있는지 봅니다.

**2단계 — 범위:** 요청한 표·요약·차트와 출처를 각각 찾습니다.

**3단계 — 위치·원인 후보:** 모양 차이인지 파일 손상·항목 누락인지 구분합니다.

**정답을 요청했을 때:** 구성이 빠졌을 때만 해당 항목을 보완하고 다시 엽니다. 모양 차이를 숫자 오류로 판단하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
