# 1장. 영화 흥행 기록으로 첫 Excel 보고서를 만들어봅니다 — 완료 검증 규격

검증은 사용자 요청 범위의 확인입니다. 실제 게시·삭제·결제는 별도 명확한 행동 승인 없이 실행하지 않습니다. 증거를 확보하지 않은 것을 PASS로 입력하지 않습니다.

|목표|확인 기준|근거 종류|기대 결과|
|---|---|---|---|
|ch01-g01|movie-report 폴더와 생성 파일의 실제 위치를 확인|file-inspection|pass|
|ch01-g02|KOBIS의 기준 연도와 출처를 식별|official-source|pass|
|ch01-g03|생성 코드를 실행해 Excel 파일을 얻음|test-run|pass|
|ch01-g04|표·요약·차트와 요청한 시트를 확인|human-observation|pass|
|ch01-g05|완성 파일을 실제 뷰어에서 열고 깨짐 여부 확인|human-observation|pass|
|ch01-g06|파일 구성 확인과 숫자 정확성 검증이 다름을 설명|human-observation|pass|

## 다시 확인할 때
코드·실행 환경·대상·인증 설정이 바뀌었으면 관련 근거를 다시 확인합니다. 파일 해시로 감지하지 못하는 외부 정책·권한·키 변화는 사람이 알려야 합니다. 기존 기록을 덮어쓰지 않고 새 기록을 추가합니다.
