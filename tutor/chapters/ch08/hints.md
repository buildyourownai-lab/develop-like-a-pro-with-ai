# 8장. 누구나 사용할 수 있는 아파트 찾기 서비스를 만듭니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H08-01 · 로컬은 되는데 배포 후 실패

**1단계 — 방향:** 같은 코드라도 실행 환경의 설정은 별개입니다.

**2단계 — 범위:** Vercel 프로젝트·적용 환경·현재 배포를 확인합니다.

**3단계 — 위치·원인 후보:** 코드가 읽는 변수 이름과 Vercel Name이 같은지 봅니다.

**정답을 요청했을 때:** 실제 값은 공식 화면에 직접 넣고 새 배포 후 각 API가 필요한 검색을 다시 확인합니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H08-02 · 화면만 열리고 검색 안 됨

**1단계 — 방향:** 페이지 표시와 기능 성공은 별개입니다.

**2단계 — 범위:** 검색 요청이 서버까지 가는지 먼저 확인합니다.

**3단계 — 위치·원인 후보:** 브라우저 오류·서버 오류·외부 응답 오류를 구분합니다.

**정답을 요청했을 때:** 실패 구간을 고친 뒤 입력부터 결과까지 다시 실행합니다. Ready 표시만으로 장 완료라 하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
