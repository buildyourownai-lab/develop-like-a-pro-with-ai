## P15-02 · Xcode와 Simulator를 공식 경로로 준비합니다

~~~prompt
현재 Mac에서 iPhone 앱을 만들고 공식 Simulator로 실행할 준비가 되어 있는지 먼저 조사해줘.

현재 macOS에서 사용할 수 있는 공식 Xcode와 iPhone Simulator 환경을 Apple 공식 자료를 기준으로 확인해줘.

14장과 다른 Mac이라면 작업을 시작하기 전에 14장의 최신 Git 기록과 미기록 파일이
현재 프로젝트에 안전하게 옮겨졌는지, 올바른 프로젝트 폴더를 열었는지 확인해줘.
로컬 Secret과 도구 설정, 튜터 연결은 새 Mac에서 다시 준비할 항목만 알려주고,
Secret 값을 출력하거나 Git에 넣지 마. 같은 Mac이라면 이 이전 검사는 건너뛰어.

설치나 추가 다운로드가 필요하면 공식 출처, 필요한 이유, 예상 다운로드 용량과 여유 공간, Apple 계정이나 관리자 승인 필요 여부를 먼저 쉬운 말로 알려주고 멈춰줘.

내가 확인하고 승인한 뒤에만 설치를 진행해줘. 호환되지 않는 최신 버전을 억지로 설치하거나 비공식 경로를 사용하지 마.
~~~

## P15-03 · 같은 기능은 재사용하고 달라진 환경만 새로 만듭니다

~~~prompt
앞에서 정한 범위와 Android에서 검증한 기능을 바탕으로 같은 주식 서비스를 iPhone 앱으로 확장해줘.

기존 웹과 Android가 사용하는 서버 기능을 최대한 재사용하고, iPhone 때문에 주식 데이터·공시·Gemini·Database·Cache를 다시 만들지 마.

iPhone에서 실제 시장과 기준일, 종목 검색, 가격과 1개월·3개월·1년 차트, 최근 공시와 DART 원문, AI 브리핑의 근거·출처·한계를 확인할 수 있어야 해.

로그인·관심종목·Push 알림·매매·포트폴리오는 추가하지 마.

iPhone의 내부 기술과 구조는 현재 프로젝트와 Apple 공식 환경을 조사해 적절하게 선택해줘.

화면의 용어와 숫자 표기, 안내 문구는 웹서비스와 Android에서 쓴 것과 같게 맞춰줘. 제작 도구의 기본 화면을 그대로 두지 말고, 글꼴·여백·화면 전환은 iPhone에서 자연스러운 방식을 따라줘.

외부 서비스 Secret을 앱에 넣지 말고, 필요하지 않은 개인정보와 기기 권한도 요구하지 마.

Apple 계정 로그인, 설치나 관리자 승인처럼 내가 해야 하는 일이 나오면 그 지점에서 멈춰 안내해줘.

구현 뒤 Build와 필요한 자동 Test, 보안 검사, 기존 웹·Android와 공유하는 기능의 Regression을 수행해줘. 내부 명령과 로그 대신 통과 여부와 남은 문제를 쉬운 말로 요약해줘.

자동 검사만으로 끝내지 말고 공식 iPhone Simulator에서 실제 사용자 흐름을 확인할 준비를 해줘.
~~~

## P15-04 · iPhone Simulator에서 첫 화면을 엽니다

~~~prompt
완성한 iPhone 앱을 공식 Simulator에 설치하고 실행해줘.

앱 파일을 만들었다는 것으로 끝내지 말고 첫 화면이 실제로 나타나고 기존 주식 서비스의 자료를 받을 수 있는 상태까지 확인해줘.

설치나 실행 과정에서 내가 승인해야 하는 일이 나오면 멈춰서 알려줘.

준비가 끝나면 내가 Simulator에서 직접 확인할 흐름을 안내해줘.
~~~

## P15-05 · 연습용 연결 때문에 실제 앱의 안전을 낮추지 않습니다

~~~prompt
iPhone Simulator에서 개발 중인 앱을 확인할 연결과 실제 배포 앱의 연결을 구분해줘.

Release 앱의 네트워크 보안을 낮추지 말고, 저장소와 Vercel의 실제 상태를 확인해 현재 Production HTTPS 서버를 사용하게 해줘.

임의의 운영 주소를 만들거나 외부 API Key를 앱에 넣어 연결 문제를 우회하지 마.

실제 서버 응답을 확인하고 결과를 쉬운 말로 요약해줘.
~~~

## P15-06 · Secret과 기기 권한을 확인합니다

~~~prompt
완성한 iPhone 앱과 저장소에 외부 서비스 Secret이 들어 있지 않은지 검사해줘.

카메라·마이크·위치·연락처·사진처럼 이번 기능에 필요하지 않은 권한을 요청하지 않는지도 확인해줘.

실제 Secret 값이나 내부 검사 명령은 출력하지 말고 발견 여부와 남은 위험을 쉬운 말로 알려줘.

기존 서비스의 품질 기준과 iPhone의 실제 사용 흐름도 다시 확인하고, 통과하지 못한 것이 있다면 완료라고 하지 마.
~~~

~~~prompt
Android 앱과 iPhone 앱의 첫 화면 맨 위에 내가 고른 종목을 고정해서 보여줘. 삼성전자, 종목코드 005930이야.

사용자가 종목을 골라 저장하는 관심종목 기능은 만들지 마. 첫 화면이 처음 보여줄 종목 하나를 정해두는 것까지야.

두 앱이 같은 종목을 같은 방식으로 먼저 보여주게 하고, 웹 첫 화면에도 같은 종목을 고정했다면 웹과 어긋나지 않게 해줘.
~~~
