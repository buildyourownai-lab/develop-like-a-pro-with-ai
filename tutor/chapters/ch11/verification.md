# 11장. 주가부터 공시까지, AI가 한 번에 브리핑합니다 — 완료 검증 규격

검증은 사용자 요청 범위의 확인입니다. 실제 게시·삭제·결제는 별도 명확한 행동 승인 없이 실행하지 않습니다. 증거를 확보하지 않은 것을 PASS로 입력하지 않습니다.

|목표|확인 기준|근거 종류|기대 결과|
|---|---|---|---|
|ch11-g01|프로젝트·키·사용 모델·한도를 확인|human-observation|pass|
|ch11-g02|사실·기준일·공시·근거 ID를 준비|file-inspection|pass|
|ch11-g03|해당 근거로 실제 모델 응답을 받음|live-api, live-ui|pass|
|ch11-g04|구조·근거 ID·알 수 없는 것·금지 표현 검사|test-run|pass|
|ch11-g05|AI 실패에도 시세·공시 원래 기능 유지|test-run|pass|
|ch11-g06|실제 코드 변수명과 Vercel 환경 대응|human-observation|pass|
|ch11-g07|Production에서 시세→공시→브리핑→근거 확인|live-api, live-ui|pass|

## 다시 확인할 때
코드·실행 환경·대상·인증 설정이 바뀌었으면 관련 근거를 다시 확인합니다. 파일 해시로 감지하지 못하는 외부 정책·권한·키 변화는 사람이 알려야 합니다. 기존 기록을 덮어쓰지 않고 새 기록을 추가합니다.
