~~~prompt

자료를 준비해줘.

주식시세의 최근 거래일을 찾으려고 날짜를 하루씩 바꿔 반복 호출하지 마.
최근 기간을 한 번에 조회하고, 그 응답에서 이 종목의 최신 시세와 최근 1년
가격 흐름을 함께 만들어줘.

날짜와 출처를 함께 넣고, 가격 계산은 프로그램이 직접 하게 해줘.

Gemini에게 주지 않은 사실을 아는 것처럼 쓰게 하지 마.
~~~

## P11-06 · 확인된 사실과 AI 설명을 나눕니다

~~~prompt
프로그램이 확인한 사실과 AI가 정리한 설명을 화면에서 분리해줘.

정확한 숫자는 Gemini에게 계산시키지 말고 프로그램이 직접 계산해서 보여줘.

프로그램이 확인한 사실을 먼저 두고, 그 아래에 AI가 근거를 읽고 정리한
설명을 둬.

AI 설명에는 한 문장 제목과 핵심 브리핑을 먼저 두고, 그 아래에는 시장과
종목 비교, 최근 가격 흐름, 최근 1년간 회사 공시, 현재 근거만으로 알 수
없는 것을 구분해서 보여줘.

AI가 만든 각 항목에는 직접 근거가 된 ID를 연결해줘. 허용되지 않은 근거
ID, 근거에 없는 숫자, 정해진 형식 밖의 필드가 있으면 화면에 표시하지 마.

시장과 종목을 비교할 때는 숫자만 나열하지 말고, 실제 계산 결과를 이용해
종목이 시장보다 어느 정도 큰 폭으로 오르거나 내렸는지 바로 이해할 수 있게 설명해줘.
같은 기준일의 등락률만 비교하고, 기준일이 다르면 날짜 차이를 알리고 비교를 보류해줘.

최근 가격 흐름에는 모든 숫자를 넣지 말고 현재 가격과 등락률, 최근 1년의 시작 가격과
현재 가격 및 변화율, 같은 기간 최고가와 최저가처럼 의미 있는 숫자를 우선해줘.

OpenDART 공식 유형 A(정기공시)·B(주요사항보고)·I(거래소공시)와 접수일을
기준으로 대표 공시를 고르고, 날짜와
종류를 빠르게 읽을 수 있게 별도 표시해줘. DART 원문으로 가는 길과 사용한
모델, 생성 시각, 출처도 유지해줘.

Gemini가 새로운 숫자나 사실을 만들지 않게 하고, 공시와 가격 움직임의 인과관계도
근거 없이 만들지 마.
~~~

## P11-07 · 알 수 없는 것은 모른다고 말하게 합니다

~~~prompt
브리핑에 '현재 근거만으로 알 수 없는 것' 영역을 만들어줘.

공시와 가격 움직임의 인과관계, 미래 가격, 목표주가, 매수·매도 판단은 만들지 마.

공시 제목만으로 공시 내용 전체를 판단하지 말고, 필요한 경우 DART 원문을 확인할 수 있게 해줘.
~~~

## P11-08 · AI가 만든 답도 그대로 믿지 않습니다

~~~prompt
Gemini가 만든 결과를 바로 화면에 보여주지 말고 한 번 더 확인해줘.

우리가 주지 않은 숫자나 사실, 투자 추천, 목표주가, 미래 예측, 확인되지
않은 인과관계가 들어가면 결과를 보여주지 마.

숫자는 Gemini에게 실제로 제공한 자료와 문장을 기준으로 확인해줘.
제공한 표현을 근거 없는 숫자로 잘못 판단해 정상 답변을 막지 않게 해줘.

문장이 매번 똑같은지는 확인하지 말고, 우리가 정한 조건을 지켰는지
확인해줘.
~~~

## P11-09 · AI가 실패해도 주가와 공시는 그대로 봅니다

~~~prompt
Gemini가 실패해도 기존 시장·검색·종목·차트·공시 화면은 계속 사용할 수
있게 해줘.

너무 오래 응답이 없으면 계속 기다리지 말고 브리핑 영역에만 안내해줘.

오류 화면에도 API Key 같은 비밀값이 나오지 않게 해줘. 영어 오류 문구를 그대로
내보내지 말고 사람이 읽는 말로 알려줘.

인증이나 모델 설정 오류는 설정을 확인해야 한다고 알리고 생성 버튼을 막아줘.
일시적인 오류는 잠시 뒤 다시 시도할 수 있게 해줘.
~~~

## P11-10 · 문장보다 지켜야 할 조건을 확인합니다

~~~prompt
지금까지 만든 AI 브리핑 기능을 실제 SK하이닉스로 확인해줘.

프로그램이 계산한 숫자와 실제 공시가 맞는지 확인하고, Gemini가 우리가
금지한 내용을 만들지 않았는지 검사해줘.

이번 장에서 추가한 브리핑 기능은 Test로 남겨줘. 프로그램이 계산한 숫자,
근거 밖 내용을 걸러내는 검사, Gemini가 실패했을 때의 안내가 다음에도
동작하는지 자동으로 확인하게 해줘.

프로그램이 확인한 사실 → AI 설명의 핵심 브리핑 → 시장과 종목 비교 → 최근
가격 흐름 → 최근 1년간 회사 공시 → 현재 근거만으로 알 수 없는 것 → 대표
공시 → 출처 순서가 실제 화면에서 자연스럽게 읽히는지도 확인해줘.

구조화된 각 항목의 근거 ID와 숫자가 실제 근거에 있는지, A·B·I 대표 공시와
사용 모델·출처가 표시되는지, 허용되지 않은 필드와 근거 밖 내용이
거부되는지도 Test로 남겨줘.

DART 원문 확인 경로가 유지되는지, Gemini 실패 시 기존 주가·차트·공시 기능이
계속 동작하는지, Secret이 노출되지 않는지도 확인해줘.

기존 Test와 Regression을 실행하고 컴퓨터와 휴대전화 크기의 실제 화면에서도
직접 사용해본 뒤 문제가 없을 때 완료했다고 알려줘.
~~~

## P11-15 · 나중에 모델을 교체해야 한다면

~~~prompt
현재 모델의 공식 지원 여부와 내 계정의 사용 가능 모델·사용량·한도를 확인해줘.

모델 교체가 필요하면 사용할 수 있는 저비용 모델과 비용 조건을 알려줘.
내가 선택하면 이 프로젝트의 모델 설정을 바꾸고, 실제 브리핑이 정상적으로

기존 브리핑의 근거와 출처, 품질 기준은 유지하고 관련 Test도 확인해줘.
유료 전환이 필요하면 비용을 보여주고 내 판단을 기다려줘.
~~~
