# 7장. 내 조건에 맞는 아파트를 찾습니다 — 완료 검증 규격

검증은 사용자 요청 범위의 확인입니다. 실제 게시·삭제·결제는 별도 명확한 행동 승인 없이 실행하지 않습니다. 증거를 확보하지 않은 것을 PASS로 입력하지 않습니다.

|목표|확인 기준|근거 종류|기대 결과|
|---|---|---|---|
|ch07-g01|단지·최근 1년·정상 거래·포함 경계 정의|human-observation|pass|
|ch07-g02|행정동·법정동·도로명주소를 추측 없이 연결|test-run|pass|
|ch07-g03|면적 범위 거래 중 가격 조건을 판단|test-run|pass|
|ch07-g04|단지 식별과 직선거리 조건을 적용|test-run|pass|
|ch07-g05|전체 면적범위 집계와 가격건수·0건·오류를 구분|test-run|pass|
|ch07-g06|실제 자료의 결과와 검증 범위를 기록|live-api, live-ui|pass|

## 다시 확인할 때
코드·실행 환경·대상·인증 설정이 바뀌었으면 관련 근거를 다시 확인합니다. 파일 해시로 감지하지 못하는 외부 정책·권한·키 변화는 사람이 알려야 합니다. 기존 기록을 덮어쓰지 않고 새 기록을 추가합니다.
