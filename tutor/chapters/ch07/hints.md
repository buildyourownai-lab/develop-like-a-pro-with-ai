# 7장. 내 조건에 맞는 아파트를 찾습니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H07-01 · 가격 조건과 표시 범위가 다름

**1단계 — 방향:** 단지 선택과 결과 요약은 범위가 다를 수 있습니다.

**2단계 — 범위:** 면적 범위 안 전체 거래와 가격 조건에 맞는 건수를 나눕니다.

**3단계 — 위치·원인 후보:** 최신 가격·최저최고값이 어느 집합에서 계산됐는지 확인합니다.

**정답을 요청했을 때:** 같은 면적범위 거래를 기준으로 요약하고 가격 조건 건수만 따로 셉니다. 예시 숫자를 억지로 맞추지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H07-02 · 검색 0건

**1단계 — 방향:** 0건과 조회 실패부터 구분합니다.

**2단계 — 범위:** 주소가 확정됐는지, API 응답이 성공했는지 봅니다.

**3단계 — 위치·원인 후보:** 면적·가격·역·학교 조건에서 어떤 단계가 후보를 줄였는지 확인합니다.

**정답을 요청했을 때:** 정상 조회 후 조건에 맞는 단지가 없으면 0건이 맞습니다. 지역을 추측하거나 조건을 몰래 완화하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
