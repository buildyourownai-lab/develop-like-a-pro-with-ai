# 22장. 기획한 챗봇을 내 주식서비스에 구현합니다

21장 기획서대로 메인 자연어 질문부터 종목 확인·필요한 자료 조회·출처와 일반 설명 표시까지 작동하는 챗봇을 구현하고 실제 결과를 검증합니다.

- [수업 안내](tutor.md)
- [정본 명세](chapter.json)
- [단계별 힌트](hints.md)
- [완료 기준](verification.md)
- [책과 같은 요청문](prompts.md)

Code 탭의 제작 요청 P22-01~P22-09과 실제 서비스 대화창에 입력할 질문을 구분합니다.

START·FINISH는 [Source 연결표](../../source-registry.json)에서 실제 연결 여부를 확인합니다. 미연결 소스를 확보된 코드로 안내하지 않습니다. 이번 판본은 `plan-build-v2`이며 이전 목표의 완료 근거를 자동 승계하지 않습니다.

현재 범위는 로컬 실제 자료 검증까지입니다. 공개 운영 확장 실습·분산 사용량 저장소를 추가하지 않으며 기존 브리핑 Cache는 유지합니다. 범위 축소 후 독자 재현은 아직 실시하지 않았습니다.
