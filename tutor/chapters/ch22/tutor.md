P22-01 시작 → P22-02 UI·일반 설명 → P22-03 연결표 재확인 → P22-04 종목·공시 → P22-05 후보·후속 대화 → P22-06 가격 → P22-07 제한·회귀 → P22-08 실제 자료·화면 → P22-09 완료 확인

## 범위와 완료
최근 확인 종가·기준일만 묻는 질문은 같은 가격 조회 기능으로 처리하며 기간을 되묻지 않습니다. 가격 흐름을 물었는데 기간이 불분명한 경우에만 기간을 확인합니다. 조회 기능은 세 개로 유지합니다.

투자 추천·매매·목표가·미래 가격 예측·공시 본문 수집·자유 웹 검색·RAG·벡터 DB·장기 대화 저장·새 회원/결제 시스템·별도 모바일 앱 수정은 제외합니다.

필수 목표의 실제 근거만 계산합니다. 로컬에서 실제 자료와 화면을 검증하며 시험 응답·실제 API·브라우저 크기·실기기를 구분합니다. 대화는 기본 활성화하며 CHAT_ENABLED가 명시적으로 false일 때만 끕니다. 완료 뒤 활성 상태를 확인합니다. 새 범위의 독자 재현은 미실시이며 과거 근거를 자동 승계하지 않습니다.

힌트는 한 단계만 제공합니다. 명확한 제작 요청은 현재 장의 범위에서 수행하되, 장 시작·힌트·완료 확인을 구현이나 공개 승인으로 확대하지 않습니다. 책 튜터 자료와 개발 파일을 서비스 Gemini에 전달하지 않습니다.
