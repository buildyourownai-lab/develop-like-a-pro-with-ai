# 22장. 기획한 챗봇을 내 주식서비스에 구현합니다 — 완료 확인 규격

이 문서는 현재 범위의 검사 기준이며 실행 성공 기록이 아닙니다. 범위 축소 후 독자 재현은 미실시입니다.

## ch22-plan-build-v2-g01 · 기획서와 일반 대화

기획서·기존 코드·설정을 대조하고 플로팅/레이어·종목 없는 일반 설명을 구현합니다. 기존 화면·앱 API를 보존하고 관련 일반 질문에 조회 없이 설명과 고정 표시를 제공합니다.

필수: 예 / 증거: test-run / 선행: 없음

## ch22-plan-build-v2-g02 · 세 기능과 실제 실행

연결표 뒤 AI용 이름을 확정하고 종목 찾기·가격 요약·공시 목록만 서버에서 검증·실행합니다. 공시는 최근 1년 최신순 최대 5건과 서버 DART 링크이며, 공시 질문에 가격 조회가 없어야 합니다.

필수: 예 / 증거: test-run / 선행: ch22-plan-build-v2-g01

## ch22-plan-build-v2-g03 · 후보와 대화 대상

실제 후보 최대 5개·선택값 서버 대조·선택 전 가격/공시 조회 없음·원래 질문 보관을 검사합니다. 상세 화면은 유지하고 대화 대상만 전환하며 이전 근거/문맥/늦은 응답을 차단합니다. 최근 완료 3회 왕복은 탭 메모리의 언어 문맥으로만 사용합니다.

필수: 예 / 증거: test-run / 선행: ch22-plan-build-v2-g02

## ch22-plan-build-v2-g04 · 기간과 답변 경계

서울 날짜의 달력 1·3·12개월과 월말을 계산하고 요청 기간·실제 거래일·자료 수·단위·등락률 기준·짧은 자료를 구분합니다. 확인된 자료와 AI 일반 설명을 분리하고 공시 본문 미조회·잘못된 설명 참조·없는 출처를 검사합니다.

필수: 예 / 증거: test-run / 선행: ch22-plan-build-v2-g03

## ch22-plan-build-v2-g05 · 제한·실패·회귀

질문 1,000자·초기 모델 3회/조회 4회/30초를 대표·복합·후보 재개로 검증하고 확정값을 기록합니다. 동일 요청 재사용·중복 제출·위조 대상·악성 자료·외부 실패/0건/AI 실패·늦은 응답과 기존 웹/API 회귀를 검사합니다.

필수: 예 / 증거: test-run / 선행: ch22-plan-build-v2-g04

## ch22-plan-build-v2-g06 · 실제 자료 대조

선택한 종목의 필요한 조회를 최소로 실제 확인합니다. Gemini 제안·서버 실행·결과의 종목·기간·가격·기준일·DART 원문을 대조하며 공시 질문의 가격 조회 없음과 일반 질문의 조회 없음을 확인합니다.

필수: 예 / 증거: live-api / 선행: ch22-plan-build-v2-g05

## ch22-plan-build-v2-g07 · 화면과 모바일 웹

데스크톱과 모바일 웹 크기에서 대상·입력·답변·출처·닫기·포커스·스크롤·안전 여백·기존 화면 보존을 직접 확인합니다. 실제 모바일 기기와 키보드 검증은 별도로 실시 여부를 기록하며 미실시를 성공으로 표시하지 않습니다.

필수: 예 / 증거: live-ui / 선행: ch22-plan-build-v2-g06

## ch22-plan-build-v2-g09 · 최종 기록

로컬에서 실제 자료로 답변을 확인하고 결과와 다시 시작하는 방법을 기록합니다. 대화 활성 상태와 CHAT_ENABLED=false로 중단하는 방법을 확인합니다. 시험 응답으로 확인한 결과는 실제 API 결과와 구분합니다.

필수: 예 / 증거: file-inspection / 선행: ch22-plan-build-v2-g07

필수 목표의 실제 근거만 계산합니다. 로컬에서 실제 자료와 화면을 검증하며 시험 응답·실제 API·브라우저 크기·실기기를 구분합니다. 대화는 기본 활성화하며 CHAT_ENABLED가 명시적으로 false일 때만 끕니다. 완료 뒤 활성 상태를 확인합니다. 새 범위의 독자 재현은 미실시이며 과거 근거를 자동 승계하지 않습니다.
