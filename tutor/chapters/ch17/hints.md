# 17장 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 다음 힌트에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 실제 수정·생성은 별도 실행 범위를 확인합니다.

## H17-01 · 손상 사본이 NOT READY

**1단계:** 현재 검사 대상이 원본인지 사본인지 봅니다.

**2단계:** 검은 화면·무음·잘림을 의도적으로 넣었는지 확인합니다.

**3단계:** 실패 항목이 실제 넣은 결함을 가리키는지 대조합니다.

**해결 설명을 요청했을 때:** 예상 결함을 정확히 검출하면 해당 목표는 성공입니다. 영상을 고치지 말고 원본을 같은 기준으로 다시 검사합니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H17-02 · 검사는 PASS인데 사람이 보니 이상

**1단계:** 자동 검사 범위를 먼저 확인합니다.

**2단계:** 대표 화면과 전체 재생은 다른 확인입니다.

**3단계:** 자막 가독성·대상 잘림·연속 동작은 어디서 확인했는지 봅니다.

**해결 설명을 요청했을 때:** 자동·화면·사람 전체 재생 결과를 구분해 남깁니다. 하나라도 확인 못 했으면 업로드 준비 완료로 확대하지 않습니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H17-03 · 움직이는 설명선이나 라벨이 어긋남

**1단계:** 문제 컷과 시간을 특정합니다.

**2단계:** 대상 앵커·선·문구·화살표를 분리해 봅니다.

**3단계:** 시작·중간·끝과 가림 전후를 실제 재생하며 추적점·화살촉·라벨 충돌을 확인합니다.

**해결 설명을 요청했을 때:** 영상 자체가 정상이면 설명 레이어만 수정하고 영향 구간과 전편을 다시 확인합니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H17-04 · 소리 검사는 통과했는데 말투가 다름

**1단계:** 소리 신호 검사와 실제 말 확인을 구분합니다.

**2단계:** 대본과 실제 음성의 종결·발음·누락을 비교합니다.

**3단계:** 장면별 실제 WAV를 듣고 합성본에서 배경음·생성 목소리 겹침도 확인합니다.

**해결 설명을 요청했을 때:** 잘못된 음성·믹스 층만 수정하고 새 파일 해시로 검수합니다. 실제 청취가 없으면 미실시로 남깁니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.

## H17-05 · 수정본에 이전 PASS가 남음

**1단계:** 현재 파일 해시와 검사 대상 해시를 비교합니다.

**2단계:** 수정된 영상·음성·자막·믹스 층을 찾습니다.

**3단계:** 새 파일에 필요한 회귀검사와 사람 전편 확인 기록을 대조합니다.

**해결 설명을 요청했을 때:** 과거 결과는 보존하되 현재 파일의 통과 근거로 복사하지 않습니다. 빠진 확인부터 수행합니다.

이 설명만으로 실제 원인·수정·검증이 완료됐다고 하지 않습니다.
