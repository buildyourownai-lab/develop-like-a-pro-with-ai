# 17장. 올리기 전에 AI가 영상을 검사합니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H17-01 · 손상 사본이 NOT READY

**1단계 — 방향:** 현재 검사 대상이 원본인지 사본인지 봅니다.

**2단계 — 범위:** 검은 화면·무음·잘림을 의도적으로 넣었는지 확인합니다.

**3단계 — 위치·원인 후보:** 실패 항목이 실제 넣은 결함을 가리키는지 대조합니다.

**정답을 요청했을 때:** 예상 결함을 정확히 검출하면 해당 목표는 성공입니다. 영상을 고치지 말고 원본을 같은 기준으로 다시 검사합니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H17-02 · 검사는 PASS인데 사람이 보니 이상

**1단계 — 방향:** 자동 검사 범위를 먼저 확인합니다.

**2단계 — 범위:** 대표 화면과 전체 재생은 다른 확인입니다.

**3단계 — 위치·원인 후보:** 자막 가독성·대상 잘림·연속 동작은 어디서 확인했는지 봅니다.

**정답을 요청했을 때:** 자동·화면·사람 전체 재생 결과를 구분해 남깁니다. 하나라도 확인 못 했으면 업로드 준비 완료로 확대하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
