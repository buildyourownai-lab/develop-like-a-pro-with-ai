# 17장. 올리기 전에 AI가 영상을 검사합니다

정상 원본과 손상 사본을 같은 기준으로 검사하고 전편 확인 근거와 함께 다음 장에 인계합니다.

- AI 수업 맥락: `tutor.md`
- 정본 명세와 목표: `chapter.json`
- 단계별 도움: `hints.md`
- 완료 기준: `verification.md`
- 본문과 같은 독자 요청: `prompts.md`

현재 프로젝트를 이어갑니다. START/FINISH의 실제 확보 상태는 `../../source-registry.json`에서 확인합니다. 예전 소스가 있다고 새 로켓 경로를 재현한 것으로 안내하지 않습니다. 본문·요청문·가이드의 판본 정합은 함께 확인해야 합니다.
