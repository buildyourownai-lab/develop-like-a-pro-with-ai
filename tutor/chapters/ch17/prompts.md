# 17장 복사용 요청문

현재 단계에 해당하는 요청문 한 개를 Claude Code에 입력합니다.

## 1. 시작 전 확인

~~~prompt
17장 시작해.
~~~

## 2. 2. 검사 Skill을 만듭니다

~~~prompt
완성한 YouTube Shorts를 업로드 전에 반복 검사하는 Skill을 만들어줘.
이름은 정확히 `video-upload-review`로 해.

프로그램으로 다음 항목을 검사해.
- 파일 존재와 전체 재생 오류
- 40~90초 길이
- 1080×1920, 세로 9:16
- 영상과 소리의 존재, 실제 음성 신호
- 1.5초 이상 이어지는 뜻밖의 검은 화면

영상에서 5초마다 대표 화면을 뽑아 한 장에 모으고, 그 이미지를 보고 다음 항목을
각각 통과 또는 실패로 판단해.
- 한글 자막이 있고 읽을 수 있는가
- 중심 대상이 심하게 잘리지 않았는가
- 화면이 깨지거나 눈에 띄게 망가지지 않았는가

프로그램 검사와 화면 검사가 모두 통과할 때만 `UPLOAD READY`로 판정해.
하나라도 실패하거나 확인하지 못하면 `NOT READY`로 판정하고 근거를 보여줘.
영상을 자동으로 고치거나 업로드하지 마.

검사 기준은 프로젝트의 `prototypes/youtube-shorts/chapter-17/review-policy.json`에
저장하고, 대표 화면, 화면 판단과 최종 결과도 다음 검사에서 확인할 수 있게 기록해.
만든 Skill이 정상 영상은 통과시키고
명백한 불량 영상은 막는지도 검사해.

프로젝트의 `.claude/skills/video-upload-review/SKILL.md`에 저장하고,
파일 맨 위의 이름도 `video-upload-review`인지 확인해. 저장한 뒤 `/` 명령 목록에
나타나는지도 확인해줘.
~~~

## 3. 3. 정상 영상을 검사합니다

~~~prompt
/video-upload-review <최종 MP4 경로>에 있는 16장의 최종 영상을 검사해줘.
검사 근거와 최종 판정을 보여주고, 영상을 고치거나 YouTube에 올리지는 마.
~~~

## 4. 3. 정상 영상을 검사합니다

~~~prompt
검사 결과가 UPLOAD READY인 것을 확인했어.
내가 전체 영상을 소리와 함께 재생해 자막과 내레이션, 장면 전환까지 확인할 동안
기다려. 아직 업로드하지 마.
~~~

## 5. 4. 불량 사본도 같은 Skill로 검사합니다

~~~prompt
전체 영상을 처음부터 끝까지 확인했고 이상이 없었어.
이제 검사 Skill이 실패도 잡는지 확인할 사본을 만들어줘. 16장의 완성 원본은 바꾸지 마.

사본에는 다음 결함만 넣어.
- 첫 3초를 완전한 검은 화면으로 바꾸기
- 화면 중앙 절반만 남도록 잘라 크게 확대하기
- 모든 소리 지우기

손상된 사본은 원본과 다른 이름으로 저장하고, 아직 검사하지 마.
완성한 파일과 원본이 그대로 보존됐는지 보여줘.
~~~

## 6. 4. 불량 사본도 같은 Skill로 검사합니다

~~~prompt
/video-upload-review 방금 만든 손상 사본을 정상 영상과 똑같은 기준으로 검사해줘.
첫 실패에서 멈추지 말고 프로그램 검사와 화면 검사를 끝까지 수행해 모든 실패 항목을
보여줘. 영상을 고치거나 업로드하지 마.
~~~

## 7. 4. 불량 사본도 같은 Skill로 검사합니다

~~~prompt
/video-upload-review <최종 MP4 경로>에 있는 원본을 같은 기준으로 다시
검사해줘. 앞에서 검사한 손상 사본과 결과를 섞지 말고 새 결과를 보여줘.
~~~
