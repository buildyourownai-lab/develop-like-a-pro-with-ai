# 17장. 올리기 전에 AI가 영상을 검사합니다 — 완료 검증 규격

검증은 사용자 요청 범위의 확인입니다. 실제 게시·삭제·결제는 별도 명확한 행동 승인 없이 실행하지 않습니다. 증거를 확보하지 않은 것을 PASS로 입력하지 않습니다.

|목표|확인 기준|근거 종류|기대 결과|
|---|---|---|---|
|ch17-g01|길이·비율·음성·검은 화면·자막 기준 정의|human-observation|pass|
|ch17-g02|검사 전용 video-upload-review 확인|file-inspection|pass|
|ch17-g03|정상 원본 UPLOAD READY와 근거 확인|test-run|pass|
|ch17-g04|원본 보존 후 의도적 손상 사본 생성|file-inspection|pass|
|ch17-g05|사본 NOT READY와 실패 근거 확인|test-run|expected-failure-observed|
|ch17-g06|같은 기준으로 원본 다시 UPLOAD READY|test-run|pass|

## 다시 확인할 때
코드·실행 환경·대상·인증 설정이 바뀌었으면 관련 근거를 다시 확인합니다. 파일 해시로 감지하지 못하는 외부 정책·권한·키 변화는 사람이 알려야 합니다. 기존 기록을 덮어쓰지 않고 새 기록을 추가합니다.

## 과거 단계와 현재 상태
이 장의 일부 목표는 당시 수행한 과정의 증거입니다. 의도적 FAIL을 고친 뒤에도 당시 FAIL 관찰은 학습 기록으로 남습니다. 같은 대상의 현재 상태는 마지막 정상 검사에서 다시 확인합니다. 원본 증거 파일이 바뀌면 과거 기록도 재확인 대상입니다.
