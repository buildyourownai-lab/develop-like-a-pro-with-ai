# 6장. 아파트 실거래가와 위치 정보를 가져옵니다 — 완료 검증 규격

검증은 사용자 요청 범위의 확인입니다. 실제 게시·삭제·결제는 별도 명확한 행동 승인 없이 실행하지 않습니다. 증거를 확보하지 않은 것을 PASS로 입력하지 않습니다.

|목표|확인 기준|근거 종류|기대 결과|
|---|---|---|---|
|ch06-g01|폴더·Node.js·기본 프로젝트·Git 연결 확인|test-run|pass|
|ch06-g02|정확한 API 신청과 본인 서비스키 준비|human-observation|pass|
|ch06-g03|Local API용 앱과 REST API 키 준비|human-observation|pass|
|ch06-g04|코드가 읽는 이름과 로컬 보관 위치 확인|file-inspection|pass|
|ch06-g05|두 API를 실제 호출하고 응답 확인|live-api, live-ui|pass|
|ch06-g06|저장한 응답 예시로 파싱과 예외를 검사|test-run|pass|

## 다시 확인할 때
코드·실행 환경·대상·인증 설정이 바뀌었으면 관련 근거를 다시 확인합니다. 파일 해시로 감지하지 못하는 외부 정책·권한·키 변화는 사람이 알려야 합니다. 기존 기록을 덮어쓰지 않고 새 기록을 추가합니다.
