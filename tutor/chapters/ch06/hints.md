# 6장. 아파트 실거래가와 위치 정보를 가져옵니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H06-01 · 서비스키를 넣었는데 인증 오류

**1단계 — 방향:** 신청한 API와 현재 호출 API가 같은지 봅니다.

**2단계 — 범위:** 활용 승인·키 종류·실제 응답 코드부터 나눕니다.

**3단계 — 위치·원인 후보:** 원본 키와 요청 조립 단계의 인코딩 횟수를 값 노출 없이 확인합니다.

**정답을 요청했을 때:** 승인 상태와 코드의 키 처리 방식을 맞추고 최소 호출로 다시 확인합니다. 오류 메시지에 키가 있으면 가린 뒤 전달합니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H06-02 · Test PASS인데 실제 연결이 안 됨

**1단계 — 방향:** 어떤 입력으로 검사했는지 확인합니다.

**2단계 — 범위:** 저장한 응답 예시와 실제 네트워크 요청을 구분합니다.

**3단계 — 위치·원인 후보:** 현재 실행 환경의 변수 이름·값 존재·응답 코드를 확인합니다.

**정답을 요청했을 때:** 응답 처리 Test와 별도로 실제 API 연결을 확인합니다. 시험 응답 통과를 인증 성공으로 기록하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
