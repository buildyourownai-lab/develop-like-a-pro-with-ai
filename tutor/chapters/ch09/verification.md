# 9장. 국내 증시와 궁금한 종목을 한눈에 봅니다 — 완료 검증 규격

검증은 사용자 요청 범위의 확인입니다. 실제 게시·삭제·결제는 별도 명확한 행동 승인 없이 실행하지 않습니다. 증거를 확보하지 않은 것을 PASS로 입력하지 않습니다.

|목표|확인 기준|근거 종류|기대 결과|
|---|---|---|---|
|ch09-g01|주식용 프로젝트와 정확한 시세 API 준비|file-inspection|pass|
|ch09-g02|확인 가능한 거래일과 단위·출처 표시|live-api, live-ui|pass|
|ch09-g03|시장 정보와 상승·하락 목록 확인|test-run|pass|
|ch09-g04|종목명·종목코드로 원하는 회사를 찾음|test-run|pass|
|ch09-g05|조회 기간과 가격·거래량을 구분|human-observation|pass|
|ch09-g06|휴장·빈 응답·오류와 기존 화면을 검사|test-run|pass|

## 다시 확인할 때
코드·실행 환경·대상·인증 설정이 바뀌었으면 관련 근거를 다시 확인합니다. 파일 해시로 감지하지 못하는 외부 정책·권한·키 변화는 사람이 알려야 합니다. 기존 기록을 덮어쓰지 않고 새 기록을 추가합니다.
