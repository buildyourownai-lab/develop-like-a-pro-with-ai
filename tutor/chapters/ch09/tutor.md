# 9장. 국내 증시와 궁금한 종목을 한눈에 봅니다 — AI가 읽는 수업 안내

이 문서는 독자의 질문 목록이 아니라 이 장을 지도하기 위한 맥락·범위·판정 지침입니다. 수치와 목표의 정본은 같은 폴더의 `chapter.json`입니다.

## 도착점과 출발점
**도착점:** 공식 시세로 시장과 종목·차트 화면을 만듭니다.

**현재 프로젝트:** `ai-stock-briefing`  
**출발 상태:** 별도 주식 프로젝트를 시작하며 아파트 결과물은 그대로 둡니다.  
**이미 있는 것:** API·Secret·웹·배포의 작업 방식  
**이번에 더하는 것:** 금융위 시세·시장·검색·종목·차트·기준일

## 먼저 준비를 안내하는 순서
새 서비스를 한꺼번에 설치·가입하지 않습니다. 이번 장의 필요한 서비스 `data-go-kr, github`를 예고하고, 각 서비스 카드에서 공식 입구·발급할 항목·실제 입력 위치·비용·성공 확인을 설명합니다. 이미 준비한 계정·이전 기능은 그대로 재사용합니다. 필요한 프로그램은 Node.js, TypeScript, Next.js입니다. 설치돼 있는지와 실제 실행 가능한지는 구분합니다.

## 기본 구조를 만들 때의 완료 기준
`ai-stock-briefing`의 새 Next.js 기본 구조는 AI가 현재 공식 지원 구성에서 lint 도구를 고르고 이유와 검사 범위를 설명해야 합니다. 설치 뒤 의존성 보안 점검·lint·타입 검사·build를 각각 실제로 실행해 종료 결과를 확인합니다. 독자에게 도구 선택이나 복잡한 명령을 맡기지 않습니다.

선택한 검사 도구 때문에 높은 위험이 남으면 곧바로 멈추거나 독자에게 대기·위험 수용을 넘기지 않습니다. 먼저 지금 공식 지원하는 다른 호환 구성이 있는지 확인하고, 있으면 바꾼 이유·검사 범위·달라지는 규칙을 쉽게 설명한 뒤 검사를 전부 다시 실행합니다. 안전한 대안이 없거나 다른 원인으로 높은 위험이나 실패가 남을 때만 첫 정상 상태 기록과 GitHub 전송을 하지 않고, 원인과 다음 조치를 안내합니다. 의존성 감사에서 개발 도구를 빼서 통과시키거나 검사를 줄이거나 버전을 억지로 낮추지 않고, 도구와 관계없는 원인은 건드리지 않습니다. 위험 예외 승인을 기본 해결책으로 권하지 않습니다. Test가 설치돼 있지 않으면 Test 통과가 아니라 "Test 없음"으로 말합니다. 특정 버전·보안 권고·lint 도구를 정답으로 고정하지 않고 실제 실행 결과로 판단합니다.

## 학습 범위
실시간 가격으로 오해시키거나 없는 지수·거래를 0으로 채우지 않습니다.

공식 API의 기준일과 화면을 연 날짜는 다를 수 있습니다. 현재 장의 진도는 사용자의 실제 프로젝트 기준으로 확인합니다.

## 네 요청에 대한 이 장의 반응
“이번 장 시작해”에는 출발 조건과 실제 현재 폴더를 대조하고 준비/미확인/첫 행동을 알려줍니다. 어떤 준비를 요구하는 목록이 있다는 이유로 준비 완료로 표시하지 않습니다.

“현재 진도 알려줘”에는 아래 목표를 증거 기록과 대조합니다. 완료 개수는 런타임이 계산한 값을 사용합니다. “지금 뭐 하면 돼?”에는 의존 조건이 충족된 가장 앞 목표 하나만 안내합니다.

“힌트 줘”에는 `hints.md`에서 지금 문제와 같은 주제의 한 단계만 답합니다. 초점을 알 수 없다면 지금 시도한 것과 기대/실제 결과를 먼저 한 번 묻습니다. 먼저 실패해야 도움받는 조건을 만들지 않습니다.

“장 완료 확인해줘”에는 `verification.md`의 기준을 적용합니다. 고치거나 기준을 바꿔 합격시키지 않습니다. 실제 계정·기기 확인이 필요한 목표는 그 환경의 근거가 없으면 미확인으로 남깁니다.

## START·FINISH를 참고할 때
`source-registry.json`의 이 장 항목을 확인합니다. 실제 파일이 연결되지 않았다면 없는 것으로 말합니다. 원본 경로를 찾았다는 사실과 그 코드로 실습을 재현한 사실은 별개입니다. 현재 프로젝트를 계속 사용하는 것이 기본이며, 참고 파일을 독자 파일 위로 복사하지 않습니다.
