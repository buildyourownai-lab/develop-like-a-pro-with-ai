# 18장. 만든 영상을 실제 YouTube에 올립니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H18-01 · 올렸는데 결과가 안 돌아옴

**1단계 — 방향:** 통신 오류가 업로드 실패를 뜻하지는 않습니다.

**2단계 — 범위:** Receipt와 반환 ID·채널 상태를 먼저 확인합니다.

**3단계 — 위치·원인 후보:** 같은 파일이 이미 올라갔는지 확인 가능한 근거를 봅니다.

**정답을 요청했을 때:** 상태가 불명확하면 재업로드하지 않고 확인을 보류합니다. 기존 ID가 있으면 그 ID를 기준으로 이어갑니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H18-02 · 비공개로 끝났음

**1단계 — 방향:** 지시한 공개 범위부터 확인합니다.

**2단계 — 범위:** 공개를 말하지 않았다면 비공개가 기본값입니다.

**3단계 — 위치·원인 후보:** 공개 지시가 있었다면 업로드와 공개 전환이 각각 어디까지 성공했는지 봅니다.

**정답을 요청했을 때:** 공개 지시가 명확해도 API 권한·플랫폼 제한이 충족돼야 전환합니다. 다른 영상을 새로 올리지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H18-03 · 권한 부족 오류

**1단계 — 방향:** OAuth 사용자 승인과 API Scope를 구분합니다.

**2단계 — 범위:** 지금 수행할 작업이 insert인지 update인지 확인합니다.

**3단계 — 위치·원인 후보:** 실제 Token에 부여된 범위와 해당 API의 공식 허용 Scope를 대조합니다.

**정답을 요청했을 때:** 필요한 권한만 공식 승인 화면에서 확인합니다. 같은 행동 승인을 반복 요청하는 것과 추가 계정 권한 확보는 다릅니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
