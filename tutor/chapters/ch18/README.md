# 18장. 음성·음향·자막을 합쳐 영상을 완성합니다

선택한 언어의 음성·음향·동적 자막을 합성한 MP4와 편집 소스, 표지·게시 자료를 완성합니다. 실제 업로드는 별도 선택입니다.

- AI 수업 안내: `tutor.md`
- 현재 목표와 판정: `chapter.json`
- 한 단계 힌트: `hints.md`
- 실제 완료 확인: `verification.md`
- 본문 순서의 입력: `prompts.md`와 `prompt-guide.json`

현재 자기 프로젝트를 이어갑니다. 공개 본문 명세만으로 독자용 스킬을 만들며 비공개 저자 자료는 필요하지 않습니다. 구판 목표 기록은 새 수업 완료로 승계하지 않습니다. 파일 동기화는 생성·시청·실습 재현 성공의 증거가 아닙니다.
