# 4장. 같은 실수는 두 번 하지 않게 합니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H04-01 · 규칙 파일이 이미 있음

**1단계 — 방향:** 새 파일을 만들기 전에 기존 내용을 읽어야 합니다.

**2단계 — 범위:** 튜터 연결과 독자가 직접 정한 규칙을 구분합니다.

**3단계 — 위치·원인 후보:** 관리 블록 밖의 문장을 보존하는 변경안인지 확인합니다.

**정답을 요청했을 때:** 기존 파일 전체를 교체하지 않고 필요한 규칙을 병합합니다. 변경 뒤 튜터와 기존 규칙이 모두 남았는지 확인합니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H04-02 · 규칙을 적었는데 실행 안 함

**1단계 — 방향:** 파일 저장과 행동 적용은 별개입니다.

**2단계 — 범위:** 현재 프로젝트가 맞고 해당 지침이 읽혔는지 확인합니다.

**3단계 — 위치·원인 후보:** 새 대화에서 참고한 지침 경로를 알려달라고 요청합니다.

**정답을 요청했을 때:** 연결을 맞춘 뒤 작은 작업으로 다시 확인합니다. 실패를 숨기지 말고 실제로 한 검사와 안 한 검사를 나눕니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.
