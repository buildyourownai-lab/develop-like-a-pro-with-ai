## P04-02 · 공통 작업 원칙을 만듭니다

~~~prompt
지금까지 movie-report 프로젝트에서 사용한 작업 방식 가운데
다른 프로젝트에서도 계속 지킬 공통 원칙을
~/.claude/CLAUDE.md에 정리해줘.

작업을 끝내기 전에 관련 Test와 검사를 실행하고,
하나라도 실패하면 완료했다고 말하지 마.

문제가 생기면 바로 수정하지 말고
같은 문제를 확인한 뒤 증거로 원인을 좁혀줘.
원인을 확인하면 필요한 부분만 수정하고,
수정 뒤에는 실패했던 Test와 관련 기존 Test를 다시 실행해줘.

기존 공통 CLAUDE.md가 있다면 먼저 확인하고,
관련 없는 기존 내용은 지우거나 덮어쓰지 마.

문제가 생겼을 때 따를 자세한 절차는
현재 movie-report 프로젝트의
docs/debug-procedure.md에 따로 정리해줘.

절차는 이 순서로 적어줘.
고치지 않은 채로 같은 실패를 다시 확인하고,
보존한 기준 자료부터 값을 차례로 비교해
처음 달라지는 지점을 찾고,
확인된 사실과 아직 추측인 것을 나눠 적고,
증거로 원인을 확인한 뒤 필요한 부분만 고치고,
실패했던 Test와 기존 Test 전체를 다시 실행하는 순서야.
~~~

## P04-03 · 프로젝트에만 필요한 규칙은 따로 둡니다

~~~prompt
현재 movie-report 프로젝트의 맨 위에
CLAUDE.md가 있는지 먼저 확인하고, 기존 사용자 규칙과 튜터 연결을 보존하면서
필요한 프로젝트 규칙을 추가해줘. 파일 전체를 덮어쓰지 마.

이 프로젝트에서는 영화 흥행 데이터를
KOBIS 공식 자료를 기준으로 확인하고,
보고서에는 KOBIS 출처와 조회 기준 연도를 남겨줘.

데이터에서 직접 확인할 수 없는
흥행 원인이나 이유는 추측하지 않는다는 규칙도 넣어줘.

모든 프로젝트에서 사용할 Test, 문제 확인,
수정 후 재검사 같은 공통 작업 원칙은
여기에 중복해서 넣지 마.

한 번 있었던 오류나
다음 작업에 필요 없는 사건 자체도 규칙으로 남기지 마.
~~~
