# Google Cloud

공식 입구: https://console.cloud.google.com

## 이 책에서 맡는 일
기존 YouTube OAuth 앱의 계정·승인 관리

## 준비와 실제 확인
Google Chat 앱·서비스 계정은 새 PART 6의 필수 준비가 아닙니다. 외부 앱 Testing Token의 만료와 철회를 확인하고 무인 운영을 영구 보장하지 않습니다.

키·Token은 대화·Git·로그에 넣지 않습니다. 계정·프로젝트·코드의 변수명·입력 환경과 실제 응답을 대조합니다. 현재 가격과 사용 한도는 공식 계정 화면에서 확인합니다. 이 문서의 존재가 실제 연결 검증은 아닙니다.
