# GitHub

공식 입구: https://github.com

## 이 책에서 쓰는 목적
프로젝트 기록과 자료 배포

## 준비 순서
실습 대상 저장소의 접근·push 권한. 저장소 공개와 웹서비스·영상 공개는 다른 행동입니다.

## 값과 이름
실제 키·Token은 사람이 직접 안전한 입력 화면에 넣습니다. 튜터에게는 필요한 이름·입력 위치·값의 존재 여부만 보여줍니다. 저자 예제의 변수명을 내 코드에서도 쓴다고 가정하지 않습니다.

## 비용과 권한
현재 공식 플랜과 계정 화면에서 확인. 무료·무제한을 고정 보장하지 않음. 행동 승인, 도구 실행 권한, OS 권한, 외부 API Scope를 각각 확인합니다.

## 완료 판단
설정 존재와 실제 동작을 구분해 현재 프로젝트에서 필요한 최소 기능을 확인.

## 상태
이 파일은 공식 입구와 확인 절차를 제공합니다. 이 안내만으로 해당 계정·화면·요금·실제 연동이 확인된 것은 아닙니다. 튜터는 최신 조회가 필요하면 공식 자료를 확인하고 조회일과 실행일을 구분합니다.
