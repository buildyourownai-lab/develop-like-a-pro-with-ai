# 영상 생성 서비스

공식 입구(16장 대표 사례): https://labs.google/fx/tools/flow

16장은 선택한 서비스의 브라우저 제작을 기본으로 안내합니다. 특정 서비스의 구독을 모두에게 요구하지 않습니다. 현재 도구 연결이 없으면 독자가 실행할 복사용 프롬프트를 제공합니다.

이미지 생성 전과 영상 생성 전에 모델·출력 수·길이·비율·원본 해상도/업스케일·비용·워터마크·상업 이용 조건을 각각 확인합니다. 일괄 생성은 번호별 독립 자산인지 확인합니다. 어려운 대표 영상에 설명을 실제 합성해 본 뒤 나머지를 만듭니다.

로그인·권한·설정 존재와 실제 생성·다운로드 성공은 별도입니다. 기존 승인 범위 안에서 진행하고 추가 결제·서비스 전환·API 전환을 임의 수행하지 않습니다. 현재 조건은 계정 화면과 공식 안내로 확인하고 미확인은 남깁니다. 이 문서의 존재는 연결 검증이 아닙니다.
