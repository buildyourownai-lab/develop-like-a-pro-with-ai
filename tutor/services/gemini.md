## 준비와 실제 확인
기존 코드가 실제로 읽는 키·모델·SDK를 확인합니다. 함수 호출 지원을 현재 공식 문서로 대조하고 자동 모델 교체·과금 확대는 하지 않습니다. 댓글 데이터 처리 조건을 확인하고 민감한 자료는 보내지 않습니다.

키·Token은 대화·Git·로그에 넣지 않습니다. 계정·프로젝트·코드의 변수명·입력 환경과 실제 응답을 대조합니다. 현재 가격과 사용 한도는 공식 계정 화면에서 확인합니다. 이 문서의 존재가 실제 연결 검증은 아닙니다.

## 16장 브라우저 음성 제작

AI Studio 브라우저에서 현재 음성 모델과 Charon을 확인합니다. 브라우저 구독·무료 제공량과 API 과금은 다릅니다. API 키를 필수로 요구하거나 API 호출로 임의 전환하지 않습니다. 대본 승인 뒤 실제 음성을 생성하고 발음·말투·길이를 별도로 듣습니다. 이전에 로그인했다면 설정을 반복하기보다 현재 계정과 화면을 확인합니다.
