# 책 학습 자료와 Study AI Lab MCP

기존 책 튜터의 **장 시작·요청문 안내·단계별 힌트·진도·완료 확인**을 [Study AI Lab MCP](https://www.studyailab.com/develop/mcp#connect) 중심의 한 흐름으로 안내합니다. 독자에게 별도 튜터를 설치하거나 두 번째 MCP·필수 Skill을 등록하도록 요구하지 않습니다.

## 시작과 사용

[개발책 연결 안내](https://www.studyailab.com/develop/mcp#connect)를 따라 개발 AI에 공통 MCP를 연결합니다. 필요한 [로컬 지원 파일](https://www.studyailab.com/develop/mcp#support-files)은 판본을 확인해 받습니다. 다운로드·파일 확인과 Python 명령의 인자는 AI가 안내하고 처리합니다. Python이 아직 없으면 1장 환경 준비를 먼저 진행한 뒤 로컬 지원 검사를 이어갑니다.

**“이번 장 시작해 / 다음 요청문 보여줘 / 힌트 줘 / 현재 진도 알려줘 / 장 완료 확인해줘”**라고 요청하세요. AI는 장·판본·실제 작업 폴더와 앞 단계 조건을 확인합니다. 요청문을 보여주거나 힌트를 읽는 것만으로 파일·진도는 바뀌지 않습니다. 실행은 승인된 범위에서 진행하며, 다른 서비스의 입력창이나 사람이 확인할 부분은 구분해 안내합니다. 조건부 복구 요청문을 쓰려고 정상 상태를 일부러 실패시키지 않습니다.

## 원격 자료와 로컬 작업의 역할

공통 MCP는 고정 판본의 장 명세·요청문 원문·한 단계 힌트·공식 서비스 준비 자료를 제공합니다. 내 프로젝트에 접근하거나 실행·완료 판정을 하지 않습니다. 경로·증거·키·진도 기록을 원격 MCP에 보내지 않습니다.

개발 AI는 기존 사용자·조직 규칙을 존중하며 실제 프로젝트를 확인하고 허용된 작업을 실행합니다. [로컬 지원 도구](../support/)는 확인한 파일과 관측 근거를 대조하고, 저장을 요청한 진도만 `.studyailab`에 기록합니다. 이 기록은 독립 실행 인증이 아닙니다. 변경된 파일·만료된 관측·실패·모의 응답·미확인은 완료로 세지 않습니다.

한 작업 공간 안에서 장별 프로젝트를 만들고 누적합니다. 앞 장의 실제 완료 조건이 필요한 곳에서는 그 상태를 이어갑니다. `START`·`FINISH`·장별 완성 Source는 비교·복구나 명시적으로 요청한 재시작용이며 정상 실습을 대신해 미리 복사하지 않습니다. 비공개 개발 저장소나 저자 환경은 실습에 필요하지 않습니다.

## 기존 자료를 활용하는 방식

| 자료 | 통합 흐름에서의 역할 |
|---|---|
| `chapters/ch01`~`ch22`의 명세·tutor.md·verification.md | 장의 선행 조건·학습 행동·완료 기준 원본 |
| 장별 `prompts.md`·`prompt-guide.json` | 요청문 원문과 입력 위치·실행 조건·앞뒤 단계 연결 |
| `hints.md`·장별 힌트 명세 | 요청한 한 단계만 제공하는 힌트 원본. 해답은 명시 요청 때만 안내 |
| `services/`·`source-registry.json` | 공식 서비스 준비와 비교·복구 소스의 참조 정보 |
| `appendices/`·`glossary/` | 필요한 시점의 부록·용어 설명 |
| `TUTOR.md`와 기존 설치·런타임 파일 | 이전 자료의 이력과 참조. 새 독자 경로의 필수 설치가 아님 |

개발책 1~15장을 대상으로 새 bundle·원격 도구·로컬 지원을 정합하고 있습니다. 16~22장과 부록 원본은 보존하며 이번 검증을 해당 범위의 새 통합 지원 완료로 확대하지 않습니다. 원본이 존재하거나 파일이 연결됐다는 사실은 장별 실습 재현 성공을 뜻하지 않습니다.

## 확인한 범위와 미완료

새 통합 경로의 실제 MCP 연결과 첫 행동 안내는 Codex CLI에서 확인했습니다. 로컬 프로그램 테스트와 실제 원격 응답 조립 검사는 별도의 근거입니다. Claude Desktop Code 탭, Windows 실제 동작, 장별 전체 실습·외부 계정/API 성공은 아직 완료로 표시하지 않습니다. 최신 지원 상태와 연결법은 [공식 안내](https://www.studyailab.com/develop/mcp)에서 확인합니다.

새 지원 파일을 받으면 manifest의 책·판본·revision·해시를 먼저 확인합니다. 기존 사용자 지침·실습 파일·진도를 자동으로 덮어쓰거나 옛 설치 파일을 일괄 삭제하지 않습니다. 이전 설치를 사용 중이라면 현재 상태를 보존하고 실제 사용 파일을 확인한 뒤 필요한 변경만 안내받으세요.
