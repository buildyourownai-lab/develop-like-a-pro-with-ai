# 판본과 지원 자료 갱신
책 기준판은 고정합니다. 지원 개정판에는 호환되는 책 판본·바뀐 도움·공식 절차 확인일을 적습니다. 독자의 코드·키·진도는 갱신 대상이 아닙니다.

갱신 요청 때는 공식 출처→차이→영향→승인된 파일만 적용 순서로 진행합니다. 이 패키지는 원격 자동 갱신 서비스나 평생 유지보수 약속이 아닙니다. 새 패키지를 별도로 받고 기존 설치의 관리 파일 변경을 확인하는 방식으로 사용합니다.
