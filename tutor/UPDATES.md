# 지원 자료 변경 기록

## 다음 명령문 안내 · 2026-09-14

“다음 명령문 보여줘 → 진행해”를 추가했습니다. 현재 단계에 맞는 원문 한 개를 조회하고, “실행해”도 같은 진행 요청으로 처리합니다. 장별 요청문과 단계·입력 위치를 연결하며, 선택 도움과 수동 준비를 구분합니다. 조회는 실행이나 완료 기록을 만들지 않습니다. 기존 진도·실습 코드·계정 설정은 변경하지 않습니다.

## part6-services-v1 · 2026-09-13

19~22장 명세·AI 지도·힌트·검증·요청문을 댓글 자동화와 주식 대화로 교체했습니다. 기존 장 번호의 목표 ID도 r2로 바꾸고 원본 소스 결합을 해제했습니다. 이전 판의 관찰 결과와 소스를 새 완료 근거로 승계하지 않습니다.

# 판본과 지원 자료 갱신
책 기준판은 고정합니다. 지원 개정판에는 호환되는 책 판본·바뀐 도움·공식 절차 확인일을 적습니다. 독자의 코드·키·진도는 갱신 대상이 아닙니다.

갱신 요청 때는 공식 출처→차이→영향→승인된 파일만 적용 순서로 진행합니다. 파일 해시는 무결성 확인이며 배포자 신원 보증과 다릅니다. 이 패키지는 원격 자동 갱신 서비스나 평생 유지보수 약속이 아닙니다. 새 패키지를 별도로 받고 기존 설치의 관리 파일 변경을 확인하는 방식으로 사용합니다.

## 2026-09-22 · 본문 표현과 튜터 동작 구분

본문의 요청은 자연어 예시이며 정확한 문구를 외울 필요가 없습니다. 기존 명령을 유지하면서 같은 뜻의 표현을 함께 처리하도록 공통 지침과 설치 안내를 정리했습니다. 장별 완료 기준은 유지하고, 힌트·요청문 조회·실행을 구분합니다. 11·12·19장 모델 도움을 동기화하고 22개 장의 원고 해시와 요청문 사본을 맞췄습니다.

자동 테스트와 별도 AI 세션의 합성 상황 확인은 실제 독자의 Claude Code 환경 전체 검증과 구분합니다.
