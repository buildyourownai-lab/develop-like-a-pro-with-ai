# 부록 C 프롬프트

이 부록의 프롬프트는 **Claude Code**에 입력합니다.

책에 나오는 순서대로 담았습니다. 책을 읽으면서 그 자리에 왔을 때 사용하세요.
직접 타이핑해도 되고 복사해서 붙여넣어도 됩니다.

## 설치는 Claude Code에게 맡깁니다

```text
Git 기록을 화면으로 보고 싶어. Sourcetree를 내 컴퓨터에 설치하는
방법을 알려주고, 지금 이 프로젝트를 거기서 열려면 무엇을 해야 하는지
안내해줘. 내가 직접 해야 하는 단계가 있으면 왜 필요한지부터 알려줘.
```

내 컴퓨터에 맞는 설치 방법과 이 프로젝트를 여는 방법을 안내받을 때 사용합니다.
