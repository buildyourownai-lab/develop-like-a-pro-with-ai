# 부록 C. Git 기록을 눈으로 보고 싶다면 — Sourcetree

## 이 부록으로 하는 일

지금까지 남긴 Git 기록을 목록과 그림으로 봅니다. 명령을 외우는 자리가 아니고, 여러 기록을
한 번에 훑어보는 일만 화면으로 하는 자리입니다. 되돌리는 일은 여기서 하지 않습니다.

## 프롬프트

[prompts.md](prompts.md)에 이 부록에서 Claude Code에 입력하는 문장이 책의 순서대로
있습니다.

## 순서대로 합니다

**1. 설치는 Claude Code에게 맡깁니다** --- 내 컴퓨터에 맞는 설치 방법과 이 프로젝트를
여는 방법까지 안내받으면 됩니다. 요청문은 [prompts.md](prompts.md)의 「설치는 Claude
Code에게 맡깁니다」에 있습니다.

설치 화면과 메뉴 이름은 버전에 따라 다릅니다. 찾는 것은 하나입니다. 내 컴퓨터에 이미
있는 프로젝트 폴더를 등록하는 것이고, 새 저장소를 만드는 것이 아닙니다.

**2. 무엇을 보는 자리인지만 알고 넘어갑니다** --- 화면의 각 부분과 무엇을 확인하는지는
책 본문의 표에 있습니다. 기록 목록, 고른 기록에서 달라진 줄, 아직 기록하지 않은 변경,
GitHub에 올라간 지점 네 가지입니다.

**3. 되돌릴 일이 생기면 Claude Code로 돌아옵니다** --- 이 화면에서 직접 되돌리지
않습니다. 무엇을 되돌릴지 확인하는 것까지만 하고, 실제 복구는 부록 B의 순서를 따릅니다.
