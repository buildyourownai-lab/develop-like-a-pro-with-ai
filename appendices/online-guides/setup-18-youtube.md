# 18장 · YouTube API 준비와 이용 조건

[ 18장 실습으로 돌아가기](https://www.studyailab.com/develop/chapters/18) · 이 안내는 해당 장에서 계정·서비스를 준비할 때 사용합니다.

화면과 조건은 바뀔 수 있으므로 현재 공식 안내와 계정 조건을 확인합니다.

이 API는 사용료를 받지 않는 대신 **하루에 쓸 수 있는 양에 한도를 둡니다**. Project를 만들면 기본 사용량이 주어지고, 매일 초기화됩니다. 2026년 8월 확인 시점에 API를 켜고 이 장의 업로드를 진행하는 데 결제 정보를 요구받지 않았습니다.

현재 프로젝트의 할당량과 업로드에 필요한 비용 단위를 공식 안내에서 확인합니다. 과거의 기본 사용량을 현재 계정의 여유량으로 가정하지 않습니다.

~~~url
https://developers.google.com/youtube/v3/getting-started
~~~


현재 Google Cloud 프로젝트의 YouTube Data API v3 사용 설정을 확인합니다. OAuth 앱·Client·Scope는 책의 순서대로 구분하고, 새 업로드·공개 전환 전에 실제 권한·정책·계정 조건을 확인합니다.

준비가 끝나면 [18장 요청문](https://www.studyailab.com/develop/chapters/18#commands)으로 돌아갑니다. 인증값은 책에서 지정한 안전한 입력 위치에 직접 넣고, 실제 연결 결과는 장의 검사로 확인합니다.
