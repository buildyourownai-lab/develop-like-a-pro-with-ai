# 6장 · 국토교통부 서비스키 준비

[ 6장 실습으로 돌아가기](https://www.studyailab.com/develop/chapters/06) · 이 안내는 해당 장에서 계정·서비스를 준비할 때 사용합니다.

## 국토교통부 서비스키를 준비합니다

먼저 국토교통부 서비스키를 준비합니다.

Claude에게 사람이 해야 하는 일만 물어봅니다.

~~~prompt
공공데이터포털의 국토교통부_아파트 매매 실거래가 자료를 사용할 거야.
주소는 https://www.data.go.kr/data/15126469/openapi.do 야.
이름이 비슷한 다른 데이터가 있으니 이 주소의 데이터로만 진행해줘.
공공데이터포털에서 내가 직접 해야 하는 과정만 알려줘.
활용신청부터 서비스키를 확인할 때까지 처음 하는 사람도 따라 할 수 있게 설명해줘.
API를 연결하는 코드는 아직 작성하지 마.
~~~

### 1. 공공데이터포털로 이동합니다

공공데이터포털에 접속해 로그인하고 **국토교통부_아파트 매매 실거래가 자료** 페이지로 이동합니다.

**공공데이터포털**  
https://www.data.go.kr

**국토교통부_아파트 매매 실거래가 자료**  
https://www.data.go.kr/data/15126469/openapi.do

공공데이터포털에는 이름이 비슷한 데이터가 여러 개 있습니다. 그래서 요청문에 주소를 함께 적었습니다. 화면에서 데이터 이름이 위 주소의 이름과 같은지 확인한 뒤 **활용신청**을 선택합니다.

![공공데이터포털 국토교통부 아파트 매매 실거래가 자료 활용신청 화면](https://www.studyailab.com/develop/guides/chapter-06/screen-06-04-molit-apartment-trade-api.png)

[화면 6-4 | 공공데이터포털의 국토교통부_아파트 매매 실거래가 자료 페이지에서 데이터 이름과 활용신청 버튼을 확인하는 화면]

처음 보는 용어를 모두 공부할 필요는 없습니다. 지금 목표는 **이 데이터를 사용할 수 있는 서비스키를 준비하는 것**입니다.

이 API에서 가져오는 가격은 부동산 사이트에 올라온 현재 매물의 호가가 아닙니다. **실제로 신고된 아파트 매매 거래 정보**입니다.

### 2. 활용신청을 합니다

**활용신청**을 선택하면 신청 화면이 나타납니다.

책의 검증 시점에는 개발단계와 운영단계 모두 **자동승인**이었고,
무료 이용과 개발계정 신청 가능 트래픽 **10,000건**이 안내되어 있었습니다.
정책과 한도는 바뀔 수 있으므로 실제 신청할 때는 현재 화면의 조건을
확인합니다.

책의 화면과 조금 다르다면 Claude에게 현재 화면을 보여주고 물어볼 수 있습니다.

~~~prompt
지금 공공데이터포털의 아파트 매매 실거래가 API 활용신청 화면에 있어.
이 API를 사용하려면 이 화면에서 내가 해야 하는 것만 알려줘.
~~~

### 3. 서비스키를 확인합니다

활용신청을 마치면 **마이페이지 > 데이터 활용 > Open API > 활용신청 현황**에서 신청한 API를 선택합니다. **처리상태**가 **승인**이면 사용할 수 있는 상태입니다.

같은 화면을 아래로 내리면 **서비스 정보**가 있습니다. 이 책에서 서비스키라고 부르는 값이 여기에 **일반 인증키**라는 이름으로 표시됩니다.

![공공데이터포털의 승인 상태와 일반 인증키 위치](https://www.studyailab.com/develop/guides/chapter-06/screen-06-05-06-molit-approval-and-service-key.png)

[화면 6-5 | 같은 개발계정 화면에서 처리상태가 승인인지 확인하고, 아래 서비스 정보에서 일반 인증키 위치를 찾습니다. 실제 값은 가림 처리했습니다.]

**서비스키가 보이면 국토교통부 준비는 끝났습니다.**

아직 그 값을 Claude와의 대화에 붙여넣지는 마세요.

---

준비가 끝나면 [6장 요청문](https://www.studyailab.com/develop/chapters/06#commands)으로 돌아갑니다. 인증값은 책에서 지정한 안전한 입력 위치에 직접 넣고, 실제 연결 결과는 장의 검사로 확인합니다.
