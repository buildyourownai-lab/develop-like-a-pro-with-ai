# 11장 · 책 기준판의 Gemini 모델 선택

## 책의 기준 자료와 현재 선택을 구분합니다

이 책의 실습 자료 계열은 part6-services-v1입니다. 예제 소스에서 사용한 모델 ID는 `gemini-3.5-flash-lite`입니다. 이것은 **과거 예제의 기준값**이며 현재 공식 지원·무료량 또는 오늘 실제 호출 성공을 뜻하지 않습니다. 이 페이지의 문서 정리일은 2026-10-10입니다. 최신 Windows 환경·수정 요청문의 실제 재현은 검증 대기입니다.

## 사용할 ID를 정하는 순서

1. 내 책과 이 사이트 장별 자료의 판본이 맞는지 확인합니다.
2. 예제 기준 ID의 현재 지원 여부를 [Google 모델 안내](https://ai.google.dev/gemini-api/docs/models), [가격](https://ai.google.dev/gemini-api/docs/pricing), [호출 한도](https://ai.google.dev/gemini-api/docs/rate-limits)와 내 AI Studio 계정에서 확인합니다.
3. 해당 ID를 쓸 수 있으면 현재 비용·한도를 보고 선택합니다. 쓸 수 없으면 저비용 후보를 조사하되 독자의 선택 전에는 바꾸지 않습니다. 확인하지 못한 조건은 미확인으로 남깁니다.
4. 선택한 정확한 모델 ID·확인일·공식 근거·계정 조건을 프로젝트 기록에 남기고 중앙 설정 한 곳에서 사용합니다. 키 값은 기록하지 않습니다.
5. 11장의 브리핑 생성·출처·실패 처리·출력 검사를 실제로 확인합니다. 12장에서는 새 모델과 다른 모델의 Cache를 섞지 않습니다. 뒤의 음성·댓글·함수 호출은 기능별 지원 조건도 따로 확인합니다.

현재 지원을 확인할 수 없으면 ID를 지어내지 말고 멈춥니다. '최신 모델'이라는 이름만으로 대체하거나 한도·가격을 보장하지 않습니다.

## 교체할 때

11장 마지막의 모델 교체 요청을 사용합니다. 관련 Test 통과와 실제 새 모델 응답을 따로 기록합니다. 모델 선택을 바꿨다고 다른 라이브러리·프레임워크·자료 제공처까지 바꾸지는 않습니다.
