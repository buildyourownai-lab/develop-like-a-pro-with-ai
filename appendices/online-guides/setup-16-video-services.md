# 16장 · Kling 이미지·영상 제작 준비

[16장 실습으로 돌아가기](https://www.studyailab.com/develop/chapters/16)

기준 이미지와 움직이는 장면은 Kling에서 만듭니다. 내레이션과 음악은 별도로 준비합니다.

| 서비스 | 공식 주소 | 맡는 일 |
|---|---|---|
| Kling | https://kling.ai/ | 기준 이미지와 장면1·3·4·5·6 영상 후보 |
| Google AI Studio | https://aistudio.google.com/ | Gemini Charon 내레이션 |
| YouTube Studio | https://studio.youtube.com/ | 오디오 보관함의 Pulsar와 라이선스 |

Kling은 유료 제작을 전제로 합니다. 현재 플랜·잔여 크레딧, 모델·해상도·길이·native audio 설정별 차감량, 워터마크·공식 다운로드·상업 이용 조건을 확인합니다. 구독 요금과 생성 크레딧은 구분합니다. 전체 예산과 단계별 배치 계획을 승인한 다음 생성하며, 재생성 비용도 합산합니다. 추가 구매와 플랜 변경은 자동으로 하지 않습니다.

Google 로그인과 API 인증은 별개입니다. 공식 AI Studio에서 Charon WAV를 내려받거나 안전하게 인증한 API 경로를 사용합니다. 실제 키·Token·결제 정보는 대화·Git·캡처에 넣지 않습니다. 음악 파일은 공식 보관함에서 직접 받아야 하며 독자 자료에 단독 배포하지 않습니다.

구도·대상별 색상·질감·조명·카메라를 지정하고 움직임은 시작·변화·끝으로 나눕니다. 생성 전 카메라 지시와 재료 표현을 리뷰하고, 결과의 실제 형태·움직임·소리를 확인합니다. 과학 장면에는 설명용 시각화와 시간 압축을 표시합니다.
