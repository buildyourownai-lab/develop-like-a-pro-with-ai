# 10장 · OpenDART 인증키 준비

책의 상세 지원 자료입니다. 책에 없는 추가 안내는 필요할 때만 사용합니다. 화면과 정책의 과거 확인 기록은 현재 지원·요금·실행 성공을 보증하지 않습니다. 현재 계정의 공식 안내를 함께 확인하세요.

## OpenDART API Key를 준비합니다

먼저 OpenDART로 이동합니다.

**OpenDART**  
https://opendart.fss.or.kr

API Key를 처음 발급받는다면 **인증키 신청** 페이지로 이동합니다.

**OpenDART 인증키 신청**  
https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do

![OpenDART 인증키 신청 페이지](/develop/guides/chapter-10/10-02-opendart-key-application.png)

[화면 10-2 | OpenDART 인증키 신청 페이지 --- 사용자 구분에서 개인을 선택하고 이메일·API 사용환경·API 사용용도 등을 입력하는 항목이 보인다]

개인 자격으로 신청한다면 사용자 구분에서 **개인**을 선택합니다.

이메일과 비밀번호, API 사용환경과 사용용도 등 화면에서 요구하는 항목을 입력합니다.

무엇을 입력해야 할지 애매하다면 Claude에게 물어볼 수 있습니다. 신청 화면을
캡처해 Claude Code 창에 붙여 넣으면 화면을 함께 보고 답합니다.

~~~prompt
지금 OpenDART 인증키 신청 화면에 있어.

개인으로 이 책의 주식 공시 실습에 사용할 API Key를 신청하려고 해.

화면에서 내가 직접 입력하거나 선택해야 하는 항목을 하나씩 알려줘.
~~~

이 책을 검증한 시점에는 **개인 사용자는 신청을 완료하면 인증키가 즉시
발급**됩니다. 기업 사용자는 담당자의 승인을 거치므로 발급까지
1~2영업일이 걸릴 수 있습니다.

OpenDART는 금융감독원이 운영하는 공공 서비스입니다. 이 책을 검증할 당시에는
인증키 신청과 발급에 결제 정보가 필요하지 않았고 비용도 들지 않았습니다.
다만 하루에 요청할 수 있는 횟수는 정해져 있습니다. 실습 중에 한도를 넘을
가능성은 작지만, 같은 자료를 여러 번 받아오면 허용 횟수를 모두 쓸 수도
있습니다. 12장에서 같은 자료를 다시 받지 않는 방법을 다룹니다.

신청을 마친 뒤 발급된 인증키를 확인합니다. 신청 결과는 이메일로도 받을 수
있으며, OpenDART의 **인증키 신청/관리 → 오픈API 이용현황**에서도 확인할 수
있습니다. 이 화면에서는 인증키가 **API Key**라는 이름으로 표시됩니다.

![OpenDART 오픈API 이용현황 화면의 API Key](/develop/guides/chapter-10/10-03-opendart-api-key.png)

[화면 10-3 | 발급된 인증키가 API Key라는 이름으로 표시되는 화면 --- 실제 값은 가림 처리]

**인증키가 보이면 OpenDART API Key 준비는 끝났습니다.**

이제 앞에서 배운 것처럼 API Key를 코드에 넣지 않고 안전하게 사용하도록
준비합니다.

~~~prompt
OpenDART API Key를 발급받았어.

실제 키가 코드나 Git, 사용자의 브라우저에 노출되지 않게 안전하게 사용할
수 있도록 준비해줘.

실제 키 값은 내가 직접 입력할게. 어디에 입력하면 되는지만 알려줘.
~~~

Claude는 현재 프로젝트에 API Key를 안전하게 보관할 설정을 만든 뒤, 키를
입력할 위치를 알려줍니다.

~~~prompt
방금 입력한 OpenDART API Key가 코드나 Git에 포함되지 않는지 확인해줘.

사용자의 브라우저에도 노출되지 않게 되어 있는지 확인해줘.

실제 키 값 자체는 화면에 출력하지 마.
~~~

검사 결과 실제 API Key 값은 코드·Git·브라우저용 JavaScript에 노출되지 않았습니다.
서버 코드는 설정을 읽기 위해 `OPEN_DART_API_KEY`라는 변수 이름을 사용하지만,
이 이름 자체는 Secret이 아닙니다.
