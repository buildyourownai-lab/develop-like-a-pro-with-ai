# 5장 · GitHub 가입과 비공개 저장소 준비

화면과 조건은 바뀔 수 있으므로 현재 공식 안내와 계정 조건을 확인합니다.

## GitHub 계정과 저장소를 준비합니다

GitHub 계정이 없다면 공식 가입 페이지로 이동합니다.

~~~url
https://github.com/signup
~~~

![GitHub 공식 가입 페이지 QR 코드](https://www.studyailab.com/develop/guides/chapter-05/03-github-signup-qr.svg)

*그림 5-3. GitHub 계정이 없다면 QR 코드를 찍어 공식 가입 페이지를 열 수 있습니다.*

이미 GitHub 계정이 있다면 새로 만들 필요가 없습니다.

처음 가입한다면 화면 안내에 따라 계정을 만들고 필요한 인증을 마칩니다.

어디에서 무엇을 해야 할지 모르겠다면 현재 화면을 Claude에게 보여주고
안내받을 수 있습니다.

~~~prompt
지금 GitHub 회원가입을 진행하고 있어.

내가 직접 입력하거나 확인해야 하는 것만
현재 화면을 기준으로 하나씩 안내해줘.

비밀번호나 인증번호처럼 다른 사람에게 알려주면 안 되는 값은
너에게 보내지 않고 내가 직접 입력할게.
~~~

로그인이 완료되어 GitHub의 기본 화면이 나타나면 계정 준비가 끝났습니다.

GitHub에서는 프로젝트를 보관하는 공간을
**저장소(Repository)**라고 부릅니다. 줄여서 **Repo**라고도 합니다.

영화 보고서 프로젝트를 보관할 `movie-report`라는 비공개 Repository를
만들겠습니다.

**저장소 이름은 프로젝트 폴더와 같게 둡니다.** 이름을 맞춰두면 나중에
어느 저장소가 어느 프로젝트인지 찾기 쉽습니다.

~~~prompt
GitHub 가입과 로그인이 끝났어.

지금 작업 중인 movie-report 프로젝트를 보관할
비공개 GitHub 저장소를 만들어줘.

저장소 이름은 movie-report로 해줘.

로그인이나 GitHub 승인처럼 내가 직접 해야 하는 일이 나오면
그 지점에서 기다리고 무엇을 해야 하는지 안내해줘.

아직 프로젝트 파일은 올리지 말고,
저장소가 만들어졌는지만 확인해줘.
~~~

로그인이나 승인처럼 계정 주인이 해야 하는 단계는 직접 처리합니다.

저장소가 만들어지면 GitHub에서 `movie-report`라는 비공개 저장소가
생겼는지 확인합니다.

아직 프로젝트 파일은 올라가지 않았습니다.
