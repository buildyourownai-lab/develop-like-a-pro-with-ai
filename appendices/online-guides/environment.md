# 실습 환경·도구·서비스 확인표

## 출간 검증 기준일과 실행 환경

출간 검증 기준일은 **2026년 10월 10일**입니다. 도구의 현재 설치·이용 조건은 공식 안내에서, 책의 최신 실습 확인 결과와 변경 사항은 Development Lab의 업데이트에서 확인합니다. 앱 버전·CLI 버전·선택 모델은 서로 다른 항목입니다.

| 항목 | 무엇을 확인하나 |
|---|---|
| Claude Desktop / Claude Code | 본문은 Desktop의 Code 탭을 사용합니다. 앱 버전·모델·권한 모드와 현재 이용 조건을 확인합니다 |
| Codex | 책 튜터를 교차 확인할 때 사용합니다. 앱과 CLI의 버전·지침 발견 방식을 각각 확인합니다. 본문의 기본 실습에 추가 설치가 필요한 것은 아닙니다 |
| Python | PART 1의 Excel 제작에 사용합니다. 프로젝트에서 실제 실행되는 Python과 필요한 패키지를 확인합니다 |
| Node.js | 웹 프로젝트의 package.json·잠금 파일·지원 조건과 현재 실행 환경을 대조합니다 |
| Git | 현재 작업 폴더에서 기록·복구에 사용할 수 있는지 확인합니다 |
| Xcode | 15장의 iPhone 앱을 Mac에서 만들고 Simulator의 실제 실행 결과를 확인합니다 |
| FFmpeg | 영상 제작 단계에서 필요한 기능과 실제 실행 결과를 확인합니다 |
| 서비스 안의 AI | Gemini API를 브리핑·한국어 음성·댓글 분류·주식 대화에 사용합니다. 장에서 지정한 모델과 실제 사용 모델을 구분합니다 |

**버전이 더 높다는 이유만으로 호환된다고 단정하지 않습니다.** 공식 지원 조건과
현재 프로젝트의 검사를 확인합니다.

11장의 모델 선택은 [책 기준판 모델 안내](https://www.studyailab.com/develop/resources/model-guide)를 사용합니다. 과거 예제의 모델 ID와 현재 지원·선택·실제 응답을 구분합니다.

운영체제별 실습 범위는 「이 책을 읽는 법」을 따릅니다. 15장의 Xcode·iPhone Simulator
실습은 Mac에서 진행합니다.

## 사용한 외부 서비스

| 서비스 | 용도 | 처음 준비하는 장 |
|---|---|---:|
| GitHub | 기록을 컴퓨터 밖에 보관 | 5장 |
| 공공데이터포털·Kakao Developers | 실거래가와 위치, 금융위원회 주식 데이터 | 6·9장 |
| Vercel | 웹서비스 배포 | 8장 |
| OpenDART | 회사 공시 원문 | 10장 |
| Google AI Studio | AI 브리핑·음성·분류 | 11장 |
| Supabase·Upstash | 데이터와 Cache | 12장 |
| Kling·Vidu·Hailuo·PixVerse | 기준 이미지와 영상 장면 제작 | 16장 |
| YouTube Audio Library | 배경음악 확인과 내려받기 | 16장 |
| Google Cloud | YouTube API와 OAuth 설정 | 18~20장 |
| YouTube | 영상 업로드·댓글 조회·허용한 답글 | 18~20장 |

계정은 필요한 장에 도착했을 때 준비합니다. 인증값 관리 경로는 온라인 부록 D를,
환경과 정책의 변경 안내는 온라인 부록 F를 봅니다. 가격·무료량·권한 조건은 실제로
이용할 계정의 공식 화면에서도 확인합니다.



## 과거 Mac 실행 예시

15장 과거 실행에서는 Xcode 26.3, iPhone 17 Pro·iOS 26.3 Simulator를 사용했습니다. 현재 Mac에 맞는 추천 조합이나 오늘 재검증 결과가 아닙니다. Apple 공식 호환 조건과 실제 실행을 확인합니다.
