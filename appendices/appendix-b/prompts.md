# 부록 B 프롬프트

이 부록의 프롬프트는 모두 **Claude Code**에 입력합니다.

책에 나오는 순서대로 담았습니다. 책을 읽으면서 그 자리에 왔을 때 사용하세요.
직접 타이핑해도 되고 복사해서 붙여넣어도 됩니다.

위에서부터 시도하고, 해결되지 않으면 다음으로 내려갑니다. Git 명령을 외우거나 직접
입력할 필요는 없습니다.

## 1단계. 디버깅

```text
방금 무엇을 하려고 했고, 무엇을 기대했고, 실제로 무엇이 일어났는지 알려줄게.
바로 고치지 말고 같은 문제가 다시 일어나는지 먼저 확인해줘.
원인을 찾으면 그 부분만 고치고, 같은 문제가 해결됐는지 다시 확인해줘.
```

지금까지 작업하던 대화창에 그대로 붙여넣습니다.

## 2단계. 내 정상 기록으로 복구

```text
현재 작업을 먼저 안전하게 보존하고, 이 프로젝트에서 마지막으로 정상
동작했던 상태를 찾아줘.

현재 상태와 무엇이 다른지 확인한 뒤 마지막 정상 상태로 안전하게
복구해줘.

복구가 끝나면 관련 테스트를 다시 실행해 정상적으로 돌아왔는지 확인해줘.
```

같은 자리에서 두세 번 고쳐도 계속 막힐 때 사용합니다.

## 3단계. 장별 Source로 재시작

```text
이 책의 공식 실습 저장소
https://github.com/buildyourownai-lab/develop-like-a-pro-with-ai
에서 지금 진행 중인 장의 Source를 찾아줘.

내 현재 작업을 먼저 안전하게 보존해줘.

그 장을 끝낸 Source에서 다시 시작하고 관련 테스트를 실행해줘.
```

앞의 두 방법으로도 해결되지 않았을 때만 사용합니다.

## 보존한 작업은 사라지지 않았습니다

```text
되돌리기 전에 보존해둔 작업이 지금 어디에 있는지 알려줘.
Git에 기록되지 않았던 파일까지 포함해서 파일과 변경 목록을 보여줘.
인증값 파일은 위치와 존재 여부만 알려주고 실제 값은 출력하지 마.
그중에 지금 상태로 다시 가져올 만한 것이 있으면 알려줘.
```

되돌린 뒤에 살릴 것이 있는지 확인할 때 사용합니다.
