# 부록 자료

책 뒤쪽 부록에서 쓰는 요청문과 골격, 전체 목록, 출간 뒤 달라진 정보를 여기에
모았습니다.

| 지금 필요한 것 | 바로 가기 |
|---|---|
| 자료를 찾거나 막힌 실습을 되살리기 | 찾아서 복구하기 — [A](appendix-a/) · [B](appendix-b/) · [C](appendix-c/) · [D](appendix-d/) |
| 배운 기술을 정리하거나 달라진 환경 확인하기 | 배운 것 정리하기 — [E](appendix-e/) · [F](appendix-f/) |
| 결과물을 다른 사람에게 보여주기 | [결과물로 증명하기 — 부록 G](appendix-g/) |

폴더 안의 구성은 장별 폴더와 같습니다.

| 이름 | 무엇인가 |
|---|---|
| README.md | 그 부록에서 무엇을 어떤 순서로 하는지 |
| prompts.md | 그 부록에서 Claude Code에 입력하는 문장. 책에 나오는 순서 |
| templates/ | 내 저장소에 가져다 쓰는 골격 파일. 부록 E·G에 있습니다 |

| 부록 | 무엇을 하나 | 자료 |
|---|---|---|
| 부록 A. 책의 모든 자료를 한곳에 모았습니다 | 이 책의 자료를 찾고 저자가 만든 결과물과 비교합니다 | [appendix-a/](appendix-a/) |
| 부록 B. 막혔을 때 다시 시작하는 법 | 막힌 실습을 세 단계로 되살립니다 | [appendix-b/](appendix-b/) |
| 부록 C. Git 기록을 눈으로 보고 싶다면 — Sourcetree | 남겨둔 기록을 화면으로 확인합니다 | [appendix-c/](appendix-c/) |
| 부록 D. 이 책에서 사용한 API Key와 OAuth 다시 찾기 | 발급받은 값과 승인한 권한을 다시 찾고 정리합니다 | [appendix-d/](appendix-d/) |
| 부록 E. 실전으로 익힌 개발 용어 × Claude 스킬 | 내가 다룬 기술과 그 증거를 한 장으로 정리합니다 | [appendix-e/](appendix-e/) |
| 부록 F. 이 책의 실습 환경과 최신 업데이트 | 화면이 책과 다를 때 확인합니다 | [appendix-f/](appendix-f/) |
| 부록 G. 내가 만든 것을 AI 포트폴리오로 바꿉니다 | 만든 것을 다른 사람이 읽을 수 있게 정리합니다 | [appendix-g/](appendix-g/) |

폴더마다 README.md가 있고, 요청문이 있는 부록에는 prompts.md도 있습니다. 요청문은
그대로 복사해 Claude Code에 붙여 넣으면 됩니다. 부록 E에는 책의 표를 되풀이하지
않고, 고른 기술과 증거를 정리하는 워크시트만 두었습니다.

장별 자료는 [chapters/](../chapters/)에 있습니다.
