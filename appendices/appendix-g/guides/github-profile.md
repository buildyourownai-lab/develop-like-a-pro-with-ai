# GitHub에서 대표 프로젝트를 먼저 보이게 하기

README와 검증 기록을 완성한 뒤에 진행하는 선택 단계입니다.

## 저장소 목록

저장소 페이지 오른쪽 위 **About** 옆 톱니바퀴에서 세 가지를 채웁니다.

| 칸 | 넣는 것 |
|---|---|
| Description | README 맨 위의 한 줄 소개 |
| Website | 실제로 열리는 배포·결과물 주소 |
| Topics | 기술, 자료 종류, 결과물 종류를 나타내는 검색어 다섯 개 이내 |

## 프로필 README

내 GitHub 아이디와 같은 이름의 공개 저장소를 만들면 그 저장소의 `README.md`가 프로필
맨 위에 보입니다. 대표 결과물의 이름, 한 줄 소개, 저장소 주소, 열어보는 주소만 짧게
나열합니다. 없는 주소는 적지 않습니다.

다음은 책 본문에는 없는 온라인 선택 과제용 요청문입니다.

```text
내 GitHub 프로필에 올릴 README.md를 만들어줘.
내가 아래에 적어주는 것을 이름과 한 줄 소개, 열어보는 주소로 나열해줘.
〈이름 --- 무엇을 하는지 한 줄 --- 저장소 주소 --- 열어보는 주소〉
없는 주소는 적지 말고 자기 소개 문단은 넣지 마.
```

## 대표 저장소 고정

프로필의 **Customize your pins**에서 가장 자신 있는 공개 저장소 하나만 고릅니다. 공개하지
않은 저장소는 목록에 나오지 않습니다.

## 더 꾸밀 때의 선

Social preview처럼 결과를 열기 전에 요약해주는 것은 넣어도 됩니다. 잔디를 채우기 위한
Commit이나 실제로 자동 실행하지 않는 검사 배지는 넣지 않습니다.
