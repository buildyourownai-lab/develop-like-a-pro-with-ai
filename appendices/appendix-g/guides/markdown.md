# README에 쓰는 Markdown 여덟 형식

| 이렇게 쓰면 | 이렇게 보입니다 |
|---|---|
| `# 프로젝트 이름` | 가장 큰 제목이 됩니다. `##`, `###`으로 단계를 내립니다 |
| `- 항목` | 점이 붙은 목록이 됩니다 |
| `**중요**` | 굵은 글씨가 됩니다 |
| `[열어보기](https://...)` | 누르면 그 주소로 갑니다 |
| `![결과 화면](docs/screenshot.png)` | 그 자리에 이미지가 나옵니다 |
| 백틱 하나로 감싸기 | 명령이나 파일 이름을 그대로 표시합니다 |
| 백틱 세 개로 여러 줄 감싸기 | 명령과 실행 결과를 원문 그대로 보여줍니다 |
| 첫 줄 아래에 `|---|---|`를 두고 세로선으로 칸 나누기 | 표가 됩니다 |

파일 이름을 `.md`로 끝내고 GitHub에 올린 뒤 직접 열어 결과를 확인합니다.
