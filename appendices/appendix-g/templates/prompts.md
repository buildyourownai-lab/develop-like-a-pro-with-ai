# 이 프로젝트를 만들 때 시킨 것

세 개면 됩니다. 각 요청문 아래에 「이때 나온 결과에서 무엇이 부족했는지」를 한 줄로
적으면 다음 요청문으로 넘어간 이유가 읽힙니다.

## 1. 처음 무엇을 만들라고 시켰나

```text
〈요청문 그대로〉
```

이때 부족했던 것: 〈한 줄〉

## 2. 결과가 기대와 달랐을 때 원인을 찾게 시킨 것

```text
〈요청문 그대로〉
```

이때 찾은 원인: 〈한 줄〉

## 3. 완료 조건을 검사로 만들게 시킨 것

```text
〈요청문 그대로〉
```

만들어진 검사: 〈파일 이름과 검사 건수〉
