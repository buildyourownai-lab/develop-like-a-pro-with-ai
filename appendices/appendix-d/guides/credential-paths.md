# API Key와 OAuth 관리 경로

확인 기준일: 2026-09-09

화면 이름은 바뀔 수 있습니다. 메뉴 이름보다 내가 만든 프로젝트·애플리케이션 안의
인증값 목록을 찾습니다. 값은 대화창에 붙이지 않습니다.

| 서비스 | 관리할 것 | 시작 주소 | 찾을 자리 | 처음 쓴 장 |
|---|---|---|---|---:|
| 공공데이터포털 | 실거래가 API 인증키 | [data.go.kr](https://www.data.go.kr) | 마이페이지 > 데이터 활용 > Open API > 활용신청 현황 | 6장 |
| Kakao Developers | REST API 키 | [developers.kakao.com](https://developers.kakao.com) | 내 애플리케이션 > 앱 키 | 6장 |
| OpenDART | 인증키 | [opendart.fss.or.kr](https://opendart.fss.or.kr) | 인증키 신청/관리 > 오픈API 이용현황 | 10장 |
| Google AI Studio | Gemini API Key | [API Key 목록](https://aistudio.google.com/app/apikey) | Key 목록 | 11장 |
| Supabase | 데이터베이스 연결 정보 | [Supabase Dashboard](https://supabase.com/dashboard) | 프로젝트 > Settings > Database | 12장 |
| Upstash | Cache 연결 정보 | [Upstash Console](https://console.upstash.com) | 해당 데이터베이스의 연결 정보 | 12장 |
| Google Cloud | YouTube OAuth Client | [Google Cloud Console](https://console.cloud.google.com) | 프로젝트 > API 및 서비스 > 사용자 인증 정보 | 18장 |
| Google 계정 | 승인한 OAuth 권한 | [연결된 앱](https://myaccount.google.com/connections) | 이 책에서 만든 업로드 도구 | 18·20장 |
| Vercel | 배포 서비스의 환경변수 | [Vercel Dashboard](https://vercel.com/dashboard) | 프로젝트 > Settings > Environment Variables | 8장 이후 |

Key 교체 순서는 책의 부록 D를 따릅니다. `새 Key 발급 → 로컬과 배포 환경 변경 → 동작
확인 → 이전 Key 폐기` 순서를 바꾸지 않습니다.
