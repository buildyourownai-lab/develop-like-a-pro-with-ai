# 부록 D 프롬프트

이 부록의 프롬프트는 모두 **Claude Code**에 입력합니다.

책에 나오는 순서대로 담았습니다. 책을 읽으면서 그 자리에 왔을 때 사용하세요.
직접 타이핑해도 되고 복사해서 붙여넣어도 됩니다.

값 자체는 인증값 파일에만 둡니다. 대화창이나 다른 파일에 붙여넣지 않습니다.

## 값이 아니라 자리만 기억하면 됩니다

```text
이 프로젝트가 사용하는 인증값의 이름을 알려줘. 값은 보여주지 말고
어떤 이름으로 어디에 있어야 하는지, 지금 채워져 있는지만 알려줘.
```

값이 필요한 것 같을 때 먼저 사용합니다.

## 새 Key로 교체합니다

```text
이 서비스의 인증값을 새로 발급받은 것으로 바꿀 거야.
값을 보여주거나 대화창에 붙여넣게 하지 말고, 내가 직접 입력할 자리까지만 안내해줘.
로컬 프로젝트와 배포 환경에서 바꿔야 할 곳을 목록으로 알려줘.
내가 입력한 뒤 정상 동작을 확인하고, 이전 값을 폐기할 시점을 알려줘.
```

새로 발급받고 바꿔서 확인한 뒤에 이전 값을 폐기할 때 사용합니다.
