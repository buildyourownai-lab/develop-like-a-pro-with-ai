# 13장. 내 주식서비스의 챗봇을 기획합니다 — 단계별 힌트

한 번에 한 단계만 전달합니다.

## H21-PLAN · 기획서가 길어졌는데 무엇을 만들지 모르겠습니다.

### 힌트 1
대표 질문 하나와 이용자가 볼 결과를 먼저 연결해보세요.

### 힌트 2
기능 범위·사용 흐름·화면 배치에서 같은 질문을 따라가 보세요.

### 힌트 3
docs/chat-design.md에서 공시 질문의 종목 확인·후보 선택·답변·원문 링크·실패 시 행동이 연결되는지 확인합니다.

### 명시적으로 정답을 요청했을 때
기획서를 기능 목록으로 늘리지 말고 질문→흐름→화면 결과→기존 함수→14장 검증의 연결표로 정리합니다. 제품 구현은 14장에서 합니다.

## H21-REUSE · 기존 기능을 어디까지 재사용할지 모르겠습니다.

### 힌트 1
브리핑 전체보다 검색·가격·공시 하위 기능을 찾아보세요.

### 힌트 2
함수 위치와 입력·결과·실패·Cache를 한 줄씩 비교합니다.

### 힌트 3
1년 일봉 재사용과 1·3개월 계산 Adapter, 짧은 기간의 자료 부족 기준을 구분합니다.

### 명시적으로 정답을 요청했을 때
실제 코드를 확인한 부분과 추가 구현할 부분을 나누고 AI용 세 기능 이름은 연결표 뒤에 정합니다.


신판 계약의 완료에는 신판 실제 근거가 필요합니다. 구판 실행 결과를 자동 승계하지 않습니다.
