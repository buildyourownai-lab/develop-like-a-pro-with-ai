9–12장의 `ai-stock-briefing`입니다. 시장·검색·차트·공시·AI 브리핑과 Database·Cache를 이어 씁니다. 이 장에서는 웹 챗봇을 기획하고, 다음 장에서 구현합니다.

## 학습 경계

투자 추천·매매·목표가·미래 가격 예측·공시 본문 수집·자유 웹 검색·RAG·벡터 DB·장기 대화 저장·새 회원/결제 시스템·별도 모바일 앱 수정은 제외합니다. 제품 코드·Test·컴포넌트·작동하는 목업은 만들거나 수정하지 않습니다. 챗봇 공개 운영 확장 실습·분산 사용량 저장소는 만들지 않습니다. 기존 브리핑 Cache는 유지합니다.

요청문은 prompt-guide의 현재 단계와 입력 위치를 대조해 원문 한 개를 제공합니다. 표시한 것과 실행한 것은 구분합니다. 목표·의존·실제 근거를 대조하고 미실시를 완료로 세지 않습니다. 구판 실행 결과는 자동 승계하지 않습니다.

챗봇은 웹 전용입니다. Native 앱은 기존 시세·공시·브리핑 범위입니다. 영상 제작과 게시 자료 준비가 학습 범위입니다. 실제 등록은 사용자가 YouTube Studio에서 직접 선택합니다.
