# 16장. 만든 서비스를 Android 앱으로 만듭니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H14-01 · 웹은 되는데 Emulator는 연결 안 됨

**1단계 — 방향:** 어디에서 실행되는 localhost인지 봅니다.

**2단계 — 범위:** PC·Emulator·운영 서버 주소를 구분합니다.

**3단계 — 위치·원인 후보:** 앱 설정의 서버 주소와 실제 네트워크 접근을 확인합니다.

**정답을 요청했을 때:** 해당 환경에서 도달 가능한 주소를 사용하고 실제 앱 요청을 검사합니다. 키를 앱에 넣어 우회하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H14-02 · 키보드가 화면을 가림

**1단계 — 방향:** 자동 Test와 실제 사용성 확인은 다릅니다.

**2단계 — 범위:** 같은 검색 동작을 직접 반복합니다.

**3단계 — 위치·원인 후보:** 입력 완료 뒤 키보드·스크롤·결과 위치를 확인합니다.

**정답을 요청했을 때:** 관련 UI만 수정한 뒤 같은 기기 흐름과 기존 기능을 다시 확인합니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.


신판 계약의 완료에는 신판 실제 근거가 필요합니다. 구판 실행 결과를 자동 승계하지 않습니다.
