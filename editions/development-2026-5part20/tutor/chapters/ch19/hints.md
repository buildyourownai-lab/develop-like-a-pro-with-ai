# 19장 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 해답은 명시 요청 때만 설명하며 설명만으로 파일을 수정하거나 서비스를 실행하지 않습니다.

## H17-P5-01 · 다른 장면의 배가 달라짐

**1단계:** 현재 캐릭터 참조 선택을 봅니다.

**2단계:** 이름·실제 기준 이미지·불변 특징을 대조합니다.

**3단계:** 원화 번호와 실제 자산 참조가 연결됐는지 확인합니다.

**해결 설명을 요청했을 때:** 함선 외형 참조와 장면 구도 참조를 구분해 문제 장면만 수정합니다.

## H17-P5-02 · 원화나 영상이 서로 비슷함

**1단계:** 거리·높이·방향을 나란히 비교합니다.

**2단계:** 전경과 시각적 공개 사건을 비교합니다.

**3단계:** 가속 뒤 관찰 시간이 있고 다른 장면과 역할이 다른지 봅니다.

**해결 설명을 요청했을 때:** 차이를 구체적인 구도·빛·동작 명령으로 고치고 좋은 자산은 보존합니다.

## H17-P5-03 · 두 이미지가 자연스럽게 이어지지 않음

**1단계:** 배 방향과 주변 물체를 비교합니다.

**2단계:** 카메라 이동만으로 이어질 수 있는지 봅니다.

**3단계:** 사람·받침·배경의 불연속을 확인합니다.

**해결 설명을 요청했을 때:** 형태를 녹여 이어 붙이지 않고 각 채택 원화를 시작 이미지로 쓴 독립 클립을 준비합니다.

## H17-P5-04 · 글자나 현대식 배가 생김

**1단계:** 문제 클립의 번호와 시간을 찾습니다.

**2단계:** 대응 원화에도 같은 문제가 있는지 봅니다.

**3단계:** 깨끗한 실제 구간과 재생성 범위·비용을 비교합니다.

**해결 설명을 요청했을 때:** 문제가 있는 자산만 대상으로 재생성 또는 실제 구간 사용을 제안하고 사용자 생성 결과를 기다립니다.


신판 계약의 완료에는 신판 실제 근거가 필요합니다. 구판 실행 결과를 자동 승계하지 않습니다.
