# 18장. 질문 하나로 영상 제작을 설계합니다 — 학습 안내

판본: development-2026-5part20.

## 이번 장 목표

선택한 소재의 질문·결론, 근거, 화면 설계, 자산 수와 잠정 시간을 제작 인계로 묶습니다.

## 이어갈 상태

Windows 파일 탐색기 또는 Mac Finder에서 ai-shorts-maker 새 폴더를 직접 만들고, Claude Desktop Code 탭의 로컬에서 엽니다. 기존 폴더가 있으면 작업을 확인하고 이어 사용합니다. 튜터는 학습 순서를 안내하고 Code 탭 AI가 프로젝트 하위 폴더와 파일을 만듭니다.

## 학습 경계

이미지·영상·음성 생성, Flow 실제 등록, 업로드를 수행하지 않습니다.

요청문은 prompt-guide의 현재 단계와 입력 위치를 대조해 원문 한 개를 제공합니다. 표시한 것과 실행한 것은 구분합니다. 목표·의존·실제 근거를 대조하고 미실시를 완료로 세지 않습니다. 구판 실행 결과는 자동 승계하지 않습니다.

챗봇은 웹 전용입니다. Native 앱은 기존 시세·공시·브리핑 범위입니다. 영상 제작과 게시 자료 준비가 학습 범위입니다. 실제 등록은 사용자가 YouTube Studio에서 직접 선택합니다.
