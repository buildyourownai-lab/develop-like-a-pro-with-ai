# 20장 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 해답은 명시 요청 때만 설명하며 설명만으로 파일을 수정하거나 서비스를 실행하지 않습니다.

## H18-P5-01 · 음악이나 효과음을 찾을 수 없음

**1단계:** 정확한 곡명과 제공자를 봅니다.

**2단계:** 공식 링크와 현재 검색 결과를 대조합니다.

**3단계:** 실제 받은 파일과 이용 조건을 확인합니다.

**해결 설명을 요청했을 때:** 없는 곡을 있다고 하지 말고 현재 확보 가능한 대안을 정확히 골라 사용자가 받게 안내합니다.

## H18-P5-02 · 목소리가 장면보다 길음

**1단계:** 실제 WAV 길이를 측정합니다.

**2단계:** 장면의 발화 창과 침묵을 확인합니다.

**3단계:** 답을 먼저 말하거나 끝말이 잘리는지 비교합니다.

**해결 설명을 요청했을 때:** 대본 축약·침묵 창·실제 유효 구간의 재배치를 검토하고 정지화면·반복·극단적 음성 가속으로 채우지 않습니다.

## H18-P5-03 · 자막이 산만함

**1단계:** 상하에 같은 내용이 반복되는지 봅니다.

**2단계:** 대표 구간에서 두 줄의 진입·독서·퇴장을 봅니다.

**3단계:** 발화·대상·화면 여백과 실제 겹침을 비교합니다.

**해결 설명을 요청했을 때:** 중복을 덜고 장면마다 효과를 선택합니다. 원과 설명선을 넣지 않고 채택 음향은 보존합니다.

## H18-P5-04 · 업로드를 하지 않아 완료할 수 없음

**1단계:** 현재 장의 필수 결과를 읽습니다.

**2단계:** 완성 MP4와 편집 소스·표지·게시 자료를 봅니다.

**3단계:** 실제 시청·청취와 남은 미확인을 구분합니다.

**해결 설명을 요청했을 때:** 제작과 게시 준비 목표를 근거로 마감하며 OAuth와 실제 업로드를 필수 조건으로 추가하지 않습니다.


신판 계약의 완료에는 신판 실제 근거가 필요합니다. 구판 실행 결과를 자동 승계하지 않습니다.
