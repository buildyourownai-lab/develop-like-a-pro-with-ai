# 17장. 같은 서비스를 iPhone 앱으로 만듭니다 — 단계별 힌트

한 요청에는 한 단계만 답합니다. 같은 주제의 “다음 힌트”에서 깊이를 올립니다. 해결 설명은 명시 요청 때만 제시하고 파일 수정은 별도 요청입니다.

## H15-01 · Mac이 없음

**1단계 — 방향:** 이 장의 실행 환경 조건부터 확인합니다.

**2단계 — 범위:** 읽기 학습과 Simulator 실행을 나눕니다.

**3단계 — 위치·원인 후보:** 현재 가능한 환경과 실제 실행이 필요한 항목을 표시합니다.

**정답을 요청했을 때:** 설명은 계속 읽을 수 있으나 iPhone 실행은 환경 대기로 남깁니다. 다른 OS에서 성공했다고 꾸미지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.

## H15-02 · Simulator 화면만 뜨고 기능 안 됨

**1단계 — 방향:** 앱 시작과 서버 기능 사용을 구분합니다.

**2단계 — 범위:** 현재 앱의 서버 주소와 인터넷 접근을 확인합니다.

**3단계 — 위치·원인 후보:** 실패한 요청의 단계·응답 코드·오류 화면을 확인합니다.

**정답을 요청했을 때:** 주소·환경 원인을 고친 뒤 전체 흐름을 다시 사용합니다. 앱이 켜졌다는 이유로 완료 처리하지 않습니다.

**검증 주의:** 이 설명만으로 원인이 확인됐거나 수정됐다고 말하지 않습니다. 현재 프로젝트의 근거를 먼저 대조합니다.


신판 계약의 완료에는 신판 실제 근거가 필요합니다. 구판 실행 결과를 자동 승계하지 않습니다.
