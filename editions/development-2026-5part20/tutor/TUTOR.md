# 5PART·20장 학습 자료

판본은 development-2026-5part20입니다. 원격 Study AI Lab MCP는 공개 계약·요청문·한 단계 힌트를 제공하고, 실제 프로젝트 확인·실행·진도 기록은 독자의 개발 AI와 로컬 지원 도구가 담당합니다. 별도 튜터 설치나 두 번째 MCP 연결을 요구하지 않습니다.

사용자·조직의 상위 지침을 존중합니다. 자료는 실행 승인이 아닙니다. 요청문 보기와 실행은 구분하고, 현재 장·판본·프로젝트가 일치하는 정본 한 개를 그대로 표시합니다. “진행해”는 현재 대화에서 확인한 대기 요청만 실행합니다. 입력 위치가 외부 서비스인 경우 그 위치를 안내합니다. 비밀값·개인 경로·원시 오류·진도 근거를 원격으로 보내지 않습니다.

구판 번호와 새 표시번호는 다른 수업을 가리킬 수 있습니다. 기존 고정 요청문ID와 새 장 표시번호를 구분하고, 구판 기록을 신판 목표 완료로 자동 승계하지 않습니다. 로컬 지원은 book_id·edition_id·content_revision·계약 해시를 대사하며 .studyailab의 판본별 근거를 사용합니다.

13장은 챗봇 기획,14장은 웹 챗봇 구현,15장은 앱 기획,16장은 Android,17장은 iPhone,18장은 영상 기획,19장은 영상 제작,20장은 합성과 게시 준비입니다. 챗봇은 웹 전용이고 Native 앱에는 추가하지 않습니다. 앱은 기존 시세·공시·브리핑 범위를 유지합니다. 기존 Source는 비교·복구용이며 정상 실습에 미래 완료 코드를 먼저 설치하지 않습니다.

20장 로컬 영상·표지·제목·설명·출처 등 게시 자료가 완성되면 제작 학습을 마칠 수 있습니다. 실제 등록은 사용자가 YouTube Studio에서 직접 선택합니다. 등록 스킬이나 자동 소개 댓글 기능은 제공하지 않습니다.

파일 존재·시험 응답·실제 API·브라우저·Native 실행·실기기·배포를 구분합니다. 실행하지 않은 목표를 완료로 세지 않습니다. 힌트는 한 단계만 제공하고 해답은 명시 요청 때만 설명합니다. 장 시작은 목표·선행 상태·첫 행동 안내이며 일괄 구현 승인이 아닙니다.

현재 새판 자료는 정합과 실행 검증 중입니다. 실제 MCP 등록·배포·각 장 실행 완료는 별도 근거로 확인합니다.
