~~~prompt
내가 확인하고 승인한 뒤에만 설치를 진행해줘. 다른 프로젝트의 환경은 임의로 바꾸지 마.
~~~

## P14-03 · Claude에게 Android 앱 구현을 맡깁니다

~~~prompt
앞에서 정한 범위대로 기존 주식 서비스를 Android 앱으로 확장해줘.

앱에서 실제 시장과 기준일을 보고, 종목명이나 종목코드로 검색하고, 종목 가격과 1개월·3개월·1년 차트, 최근 공시와 DART 원문, AI 브리핑의 근거·출처·한계를 확인할 수 있어야 해.

로그인·관심종목·Push 알림·매매·포트폴리오는 추가하지 마.

현재 프로젝트를 먼저 조사하고, 주식 데이터·공시·Gemini·Database·Cache는 기존 서버 기능을 최대한 재사용해줘. 내부 기술과 구조는 현재 환경에 맞게 선택해줘.

15장에서 앱에 포함하기로 한 기능은 빠짐없이 구현해줘. 같은 의미의 항목은
용어와 숫자 표기, 단위·기준일·출처, 안내 문구를 웹서비스와 맞춰줘.
최근 공시 표시 수는 앱 화면에 맞게 정해줘.

제작 도구의 기본 화면을 그대로 두지 마. 지수와 종목은 흰 카드에 담고 카드 사이에 여백을 줘. 상승은 빨강, 하락은 파랑으로 웹과 같게 쓰고 색을 못 보는 사람도 알 수 있게 기호나 부호를 함께 써줘. 누르는 곳에는 강조색을 하나만 정해서 쓰고, 같은 정보를 한 화면에 여러 번 반복하지 마.

정상 결과만 보여주지 말고, 자료를 가져오는 중일 때와 검색 결과가 없을 때, 서버에 연결되지 않을 때를 사용자가 구분할 수 있게 해줘. 오류 화면에 내부 오류 문구를 그대로 내보내지 말고 사람이 읽는 말로 알려줘.

외부 서비스 Secret을 앱에 넣지 말고, 위치·카메라·마이크·연락처·사진처럼 필요하지 않은 권한도 요청하지 마.

사람의 설치 승인이나 계정 입력이 필요하면 그 지점에서 멈춰 안내해줘.

구현 뒤 Build와 필요한 자동 Test, 보안 검사, 기존 웹 기능 Regression을 수행해줘. 내부 명령과 로그를 나열하지 말고 통과 여부와 남은 문제를 쉬운 말로 요약해줘.

자동 검사만으로 끝내지 말고 공식 Emulator에 설치해 실제 사용자 흐름까지 확인할 준비를 해줘.
~~~

## P14-04 · Emulator에 앱을 설치하고 첫 화면을 엽니다

~~~prompt
준비한 Android 앱을 공식 Emulator에 설치하고 실행해줘.

앱 파일을 만들었다는 것으로 끝내지 말고 첫 화면이 실제로 나타나고 기존 주식 서비스의 자료를 받을 수 있는 상태까지 확인해줘.

설치나 실행 과정에서 내가 승인해야 하는 일이 나오면 멈춰서 알려줘.

준비가 끝나면 내가 Emulator에서 무엇을 직접 확인하면 되는지 안내해줘.
~~~

## P14-05 · 연습용 연결과 실제 서비스 연결을 모두 확인합니다

~~~prompt
Emulator에서 확인할 연습용 연결과 실제 배포 앱의 연결을 구분해줘.

개발 편의를 위해 실제 배포 앱의 네트워크 보안을 낮추지 마.

Release 앱은 저장소와 Vercel의 실제 배포 상태를 확인해 현재 Production HTTPS 서버를 사용하게 해줘. 임의의 운영 주소를 만들지 마.

이번에 앱을 위해 서버에 새로 만든 기능이 있으면 배포에도 반영해줘. 그러지 않으면 Release 앱이 실제 주소에 연결돼도 자료를 받지 못해.

외부 API Key를 앱에 넣어 연결 문제를 우회하지 말고, 두 환경에서 실제 응답을 확인한 뒤 결과를 쉽게 요약해줘.
~~~

## P14-06 · 앱과 웹을 나란히 놓고 대조합니다

~~~prompt
앱과 웹을 같은 종목으로 나란히 열고, 15장에서 앱에 포함하기로 한 기능을
대상으로 같은 것을 다르게 부르거나 다르게 적은 곳을 목록으로 알려줘.

앱 화면에 맞게 정한 최근 공시 표시 수 차이는 오류로 보지 마.

이 범위에서 다르면 웹을 기준으로 앱을 고쳐줘. 웹과 서버는 바꾸지 마.
~~~

## P14-07 · 자동 검사가 찾지 못한 불편을 발견합니다

~~~prompt
Android 앱에서 종목 검색은 성공했는데 검색 뒤에도 키보드가 계속 열려 있어 상세 화면과 스크롤을 가려.

그리고 화면 맨 위에서 시장 화면의 제목과 상세 화면의 첫 줄이 시계와 배터리가 보이는 상태 표시줄 글자와 겹쳐.

사용자가 검색을 마치면 키보드가 자연스럽게 닫히고, 바로 상세 화면을 보며 차트·공시·AI 브리핑까지 내려갈 수 있게 고쳐줘. 앱의 모든 화면이 위아래 시스템 영역을 침범하지 않게 해줘.

기존 검색 결과와 서버 기능은 바꾸지 말고, 원인은 Claude가 조사해 필요한 부분만 수정해줘.

수정 뒤 자동 Test와 기존 기능 재검사를 수행하고, Emulator에서 같은 검색 흐름을 다시 확인해줘.
~~~

## P14-08 · 앱에 Secret과 불필요한 권한이 없는지 확인합니다

~~~prompt
완성한 Android 앱과 저장소에 외부 서비스 Secret이 들어 있지 않은지 검사해줘.

위치·카메라·마이크·연락처·사진처럼 이번 기능에 필요하지 않은 권한을 요청하지 않는지도 확인해줘.

실제 Secret 값이나 내부 검사 명령은 출력하지 말고, 발견 여부와 앱이 사용하는 권한을 쉬운 말로 알려줘.

기존 웹 기능 Regression과 이번 Android 핵심 흐름도 다시 확인한 뒤, 통과하지 못한 것이 있다면 완료라고 하지 마.
~~~
