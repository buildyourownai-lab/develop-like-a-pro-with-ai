이 폴더는 신판13~20장의 요청문·학습 계약과 [장 대응·고정 참조 명세](migration-manifest.json)입니다. 구판 `chapters/ch13`~`ch22`와 튜터·검증 링크는 그대로 보존합니다. 1~12장은 기존 공개 고정 revision에서 읽으며 작업 중인 다른 변경을 포함하지 않습니다. 다섯 PART의 명시 원고 경로·제목·해시는 part-sources.json에 기록하고 비공개 원고 전문은 배포하지 않습니다.

Source 중복 복사는 하지 않았습니다. 고정 Git revision으로 가리키는 구판 Source는 이력과 비교용이며 새판 실행 검증을 뜻하지 않습니다. 새로운 시작/완료판 연결과 공개 MCP의 신구판 동시 조회는 별도 검증 대기입니다. 20장은 제작과 게시 자료 준비까지이며 실제 등록은 사용자가 YouTube Studio에서 선택합니다. 등록·첫댓글 자동화는 제공하지 않습니다. 저자 비공개 스킬이나 저장소는 독자 의존성이 아닙니다.
